    Tipos de dados em C++¶

    Em C++, toda variável tem um tipo, que define o que ela pode armazenar, quanto espaço ocupa na memória e quais operações podem ser feitas com ela. O tipo é definido na declaração da variável e não muda durante a execução do programa: uma variável declarada como int vai guardar números inteiros do início ao fim. Por isso, dizemos que C++ tem tipagem estática. A vantagem é que muitos erros (como somar um número com um texto) são detectados pelo compilador, antes mesmo de o programa ser executado.

    A linguagem oferece tipos aritméticos básicos (inteiros, reais, caracteres e lógicos), formas de construir tipos compostos a partir deles (arranjos, estruturas e enumerações) e, na biblioteca padrão, tipos prontos para tarefas comuns, como std::string para textos e std::vector para sequências de tamanho variável.

    Tipos principais¶

    A linguagem C++ fornece os tipos aritméticos bool, char, int, float e double, e os modificadores signed, unsigned, short e long. A combinação dos tipos com os modificadores produz os seguintes tipos de dados.

Para ponto flutuante, 32 e 64 bits são tamanhos usuais de float e double, não exigências universais do padrão; a garantia é sobre propriedades e intervalos mínimos representáveis.     Veja bem, preste atenção!

    Nas plataformas usuais de 64 bits, long tem 64 bits no Linux e 32 bits no Windows; isso não descreve todas as plataformas Linux. Um programa que guarda um valor grande em um long pode funcionar no computador de um colega e falhar no seu. Quando precisar de inteiros de 64 bits, use long long, que tem pelo menos 64 bits em qualquer sistema.

    Na prática, os tipos mais usados são int para inteiros (cerca de \(\pm 2{,}1 \times 10^9\)), long long para inteiros maiores (cerca de \(\pm 9{,}2 \times 10^{18}\)), double para números reais, char para caracteres e bool para valores lógicos. O tipo float tem pouca precisão (cerca de 7 dígitos significativos, contra cerca de 15 do double) e deve ser evitado, a menos que haja um bom motivo para economizar memória.

    Outros tipos de caractere

    Além de char, a linguagem tem os tipos wchar_t, char8_t, char16_t e char32_t, usados como unidades de código em representações de texto. char8_t, char16_t e char32_t estão associados a UTF-8, UTF-16 e UTF-32; um caractere pode exigir várias unidades, e a representação de wchar_t depende da implementação. Eles são necessários em programas que manipulam textos em vários idiomas de forma mais sofisticada, e não são usados neste texto.

    O tipo bool¶

    O tipo bool representa valores lógicos e tem apenas dois valores possíveis, true e false. Ele é o resultado de todas as comparações e operações lógicas, e é o tipo esperado nas condições de if, while e for.

    Valores lógicos podem ser convertidos em números e vice-versa: true vira 1 e false vira 0; no sentido contrário, zero vira false e qualquer outro valor vira true. Por padrão, std::cout escreve os valores lógicos como 1 e 0; o manipulador std::boolalpha faz com que sejam escritos como true e false.

    Estouro de capacidade¶

    Veja bem, preste atenção!

    O que acontece se tentarmos colocar em uma variável um número maior que o maior valor que o tipo dela pode armazenar? É como tentar colocar um tênis tamanho 45 numa caixa de sapato feita para tamanho 38. Esse problema se chama overflow (estouro de capacidade), e nem sempre há diagnóstico. O estouro aritmético de inteiros com sinal tem regras diferentes da conversão de um valor para outro tipo; os itens abaixo tratam das operações aritméticas.

    • Nos tipos sem sinal (unsigned), o comportamento é bem definido: os valores "dão a volta". Somar 1 ao maior unsigned int resulta em 0, e subtrair 1 de 0 resulta no maior valor do tipo;
    • Nos tipos com sinal (int, long long...), o estouro tem comportamento indefinido. Na maioria das máquinas o resultado parece "dar a volta" para os negativos, mas o compilador tem o direito de assumir que o estouro nunca acontece e otimizar o programa com base nisso, produzindo resultados imprevisíveis.

    Um erro muito comum é fazer uma conta cujo resultado não cabe em int, mesmo guardando o resultado em um long long:

    Incorreto

    int n = 100000;
long long errado = n * n;  // a conta é feita em int e estoura

    Correto

    int n = 100000;
long long certo = 1LL * n * n;  // a conta é feita em long long: 10000000000

    Como vimos na seção de expressões, a conta é feita com o tipo dos operandos, e só depois o resultado é convertido para o tipo da variável que o recebe. Multiplicar primeiro por 1LL (o número 1 do tipo long long) faz com que toda a conta seja feita em 64 bits.

    Uma forma prática de evitar o problema é estimar o tamanho dos valores antes de escolher o tipo: se algum valor intermediário puder passar de dois bilhões, use long long.

    Escrevendo valores literais¶

    Valores escritos diretamente no código são chamados de literais. Inteiros podem ser escritos em decimal, em hexadecimal (com o prefixo 0x), em octal (com o prefixo 0) e em binário (com o prefixo 0b). Para facilitar a leitura de números grandes, os dígitos podem ser separados com apóstrofos, que são ignorados pelo compilador. Números reais podem ser escritos com ponto decimal ou em notação científica, em que 6.022e23 significa \(6{,}022 \times 10^{23}\).

    Um zero à esquerda transforma o número em octal: int x = 010; guarda o valor 8, e não 10. Nunca use zeros à esquerda para "alinhar" números no código.

    Tipos de tamanho fixo¶

    O cabeçalho <cstdint> oferece famílias de tipos inteiros com requisitos de largura definidos. Os tipos de largura exata, como std::int32_t, são opcionais: só existem quando a implementação fornece um tipo com essa largura e sem bits de preenchimento. As famílias de largura mínima e rápida têm garantias diferentes:

    • std::int\(b\)_t: inteiro com exatamente \(b\) bits e com sinal (por exemplo, std::int32_t, std::int64_t);
    • std::uint\(b\)_t: inteiro com exatamente \(b\) bits e sem sinal (por exemplo, std::uint8_t, std::uint64_t);
    • std::int_least\(b\)_t e std::uint_least\(b\)_t: o menor tipo com pelo menos \(b\) bits;
    • std::int_fast\(b\)_t e std::uint_fast\(b\)_t: o tipo mais rápido com pelo menos \(b\) bits.

    As larguras padronizadas são \(b \in \{8, 16, 32, 64\}\). Esses tipos ajudam quando a largura importa, mas não definem sozinhos um formato binário portátil: a ordem dos bytes e a representação dos demais dados também precisam ser especificadas. Consulte a referência dos tipos inteiros.

    Declaração e inicialização de variáveis¶

    Declarar uma variável é informar ao compilador o tipo e o nome dela; inicializar é dar a ela um valor inicial. Em C++, há três formas de inicializar uma variável na declaração:

    int a = 7;   // com sinal de igual
int b(7);    // com parênteses
int c{7};    // com chaves (inicialização uniforme)
int d{};     // chaves vazias: valor zero

    As três primeiras formas produzem o mesmo resultado neste caso. As chaves também podem inicializar arranjos, estruturas e contêineres, mas seu significado depende do tipo: std::vector<int>{5} contém um elemento de valor 5, enquanto std::vector<int>(5) contém cinco zeros. Outra propriedade das chaves é impedir conversões classificadas como estreitamento (narrowing), como a conversão de double para int: ambas as linhas abaixo com estreitamento tornam o programa inválido e exigem um diagnóstico do compilador. Algumas opções do compilador aceitam a primeira como extensão, emitindo apenas um aviso.

    double e = 3.7;
int f = e;      // aceito: f recebe 3, e a parte fracionária se perde sem aviso
int g{e};       // inválido: conversão de estreitamento
int h{3.7};     // erro de compilação

    Veja bem, preste atenção!

    Uma variável local automática de tipo fundamental, como int x;, pode ter valor indeterminado; usar esse valor em uma conta tem comportamento indefinido em C++20. Isso não se aplica a toda declaração sem inicializador: variáveis globais e static recebem inicialização zero antes das demais etapas, e std::string s; constrói uma cadeia vazia. Inicialize os valores locais, por exemplo com int x{};.

    Dedução de tipo com auto¶

    Em vez de escrever o tipo de uma variável, podemos usar a palavra auto e deixar que o compilador deduza o tipo a partir do valor usado na inicialização:

    auto quantidade = 10;     // int
auto preco = 19.90;       // double
auto inicial = 'D';       // char
auto ativo = true;        // bool
auto populacao = 8'100'000'000LL;  // long long

    A variável continua tendo um tipo fixo, definido na compilação: auto apenas poupa o trabalho de escrevê-lo. Por isso, uma variável auto precisa ser inicializada na declaração.

    O auto é muito útil quando o tipo é longo ou óbvio pelo contexto, situação comum ao trabalhar com contêineres e iteradores da biblioteca padrão. Por outro lado, usado em excesso, ele esconde informações importantes de quem lê o código. Uma boa regra é usar auto quando o tipo estiver claro na própria linha, ou quando ele for longo demais para ajudar na leitura.

    Veja bem, preste atenção!

    auto texto = "abc"; não cria uma std::string, e sim um ponteiro para caracteres constantes (const char*), que não tem nenhum dos recursos de std::string. Quando quiser uma cadeia de caracteres, declare o tipo explicitamente: std::string texto = "abc";.

    Constantes¶

    Uma constante é uma variável cujo valor não pode ser alterado depois de definido. Ela é definida uma única vez, na declaração, e permanece fixa durante toda a execução do programa. Usar constantes no lugar de valores "soltos" no código (os chamados números mágicos) deixa o programa mais legível e mais fácil de modificar: para mudar o número máximo de alunos de uma turma, basta alterar a constante em um único lugar.

    C++ tem duas palavras-chave para declarar constantes, const e constexpr:

    • const indica que o valor não pode ser modificado depois da inicialização. O valor pode ser calculado durante a execução, por exemplo a partir de algo digitado pelo usuário;
    • constexpr indica que o valor, além de não poder ser modificado, precisa ser conhecido durante a compilação. Isso permite que a constante seja usada em lugares onde o compilador precisa saber o valor de antemão, como no tamanho de um arranjo.

    #include <iostream>

constexpr double PI = 3.14159265358979;
constexpr int MAX_ALUNOS = 40;

int main()
{
    const double raio = 2.0;
    const double area = PI * raio * raio;

    int notas[MAX_ALUNOS] = {};  // o tamanho precisa ser conhecido na compilação

    std::cout << "Posições no arranjo: " << sizeof(notas) / sizeof(notas[0]) << '\n';
    return 0;
}

    Tentar alterar uma constante gera um erro de compilação. E tentar inicializar uma constante constexpr com um valor que só é conhecido durante a execução também:

    int n;
std::cin >> n;
const int dobro = 2 * n;       // permitido: o valor é fixado durante a execução
constexpr int erro = 2 * n;    // erro: n não é conhecido durante a compilação

    E o #define?

    Também é possível definir constantes com a diretiva #define do pré-processador (#define PI 3.14159). Nesse caso, o pré-processador apenas substitui o texto PI por 3.14159 em todo o código antes da compilação: a macro não cria um objeto nem respeita os escopos da linguagem, embora o literal que a substitui tenha um tipo. Em C++, prefira sempre constexpr ou const.

    Enumerações¶

    As enumerações (ou enums) são tipos definidos pelo programador que consistem em um conjunto de constantes inteiras com nomes. Elas permitem escrever Semaforo::Vermelho em vez de um número qualquer, deixando o código mais legível e evitando números mágicos.

    C++ tem dois tipos de enumerações: as enumerações com escopo (enum class), que são as recomendadas, e as enumerações tradicionais (enum).

    Enumerações com escopo (enum class)¶

    Uma enumeração com escopo é declarada com as palavras-chave enum class, seguidas do nome do tipo e da lista de valores entre chaves:

    enum class Semaforo { Verde, Amarelo, Vermelho };

    Por padrão, o primeiro valor corresponde a 0, o segundo a 1, e assim por diante. Os valores são usados sempre com o nome da enumeração como prefixo (Semaforo::Verde), o que evita conflitos: outra enumeração pode ter um valor chamado Verde sem problema algum.

    #include <iostream>

enum class Semaforo { Verde, Amarelo, Vermelho };
enum class Direcao : char { Norte = 'N', Sul = 'S', Leste = 'L', Oeste = 'O' };

int main()
{
    Semaforo s = Semaforo::Amarelo;

    switch (s) {
        case Semaforo::Verde:    std::cout << "Siga\n";    break;
        case Semaforo::Amarelo:  std::cout << "Atenção\n"; break;
        case Semaforo::Vermelho: std::cout << "Pare\n";    break;
    }

    std::cout << static_cast<int>(s) << '\n';                  // 1
    std::cout << static_cast<char>(Direcao::Leste) << '\n';    // L
    return 0;
}

    O exemplo mostra mais duas características das enumerações com escopo:

    • Elas não são convertidas automaticamente para inteiros. Uma linha como int x = s; não compila. Isso evita erros como comparar um semáforo com um número qualquer ou somar duas direções. Quando o valor numérico for realmente necessário, a conversão é feita explicitamente, com static_cast;
    • É possível escolher o tipo usado para guardar os valores (por padrão, int), escrevendo-o depois do nome, como em enum class Direcao : char. Também é possível atribuir valores específicos às constantes.

    C++23

    O C++23 acrescentou a função std::to_underlying, do cabeçalho <utility>, que converte um valor de enumeração para o tipo usado para guardá-lo sem que seja preciso escrever esse tipo: std::to_underlying(Direcao::Leste) resulta no char 'L'. Em C++20, o equivalente é static_cast<char>(Direcao::Leste).

    Enumerações tradicionais (enum)¶

    As enumerações tradicionais são declaradas apenas com enum. Seus valores podem ser usados sem o prefixo do nome da enumeração e são convertidos automaticamente para inteiros:

    enum Direcao {
    NORTE = 10,
    SUL = 20,
    LESTE = 30,
    OESTE = 40
};

Direcao d = LESTE;  // sem prefixo
int x = d;          // conversão automática: x recebe 30

    Essa conversão automática é justamente o que torna as enumerações tradicionais mais propensas a erros, e é por isso que, em código novo, as enumerações com escopo são preferidas. Há, porém, um uso em que a conversão é conveniente: as enumerações usadas como flags (sinalizadores). Nesse caso, cada constante é definida como uma potência de 2, para que várias delas possam ser combinadas em um único inteiro com os operadores de bit:

    As enumerações são particularmente úteis quando:

    • Você tem um conjunto de valores relacionados que não mudarão, como dias da semana, meses, naipes de cartas ou estados de um sistema;
    • Você precisa de constantes com nomes para melhorar a legibilidade do código;
    • Você está trabalhando com flags e precisa combinar múltiplos valores;
    • Você quer evitar o uso de números mágicos no código.

    Sequências de escape¶

    Alguns caracteres podem ser representados como sequências de escape: conjuntos de dois ou mais caracteres que, na realidade, representam apenas um. Um exemplo é o \n, usado para indicar uma quebra de linha em uma cadeia de caracteres.

    Qualquer caractere pode ser representado pela sequência de escape \ooo, onde ooo é o número octal do caractere na tabela ASCII1, ou pela sequência \xhh, onde hh é o número hexadecimal. As sequências mais comuns já têm uma forma própria:

    Sequência Significado
    \a Alerta (bipe, sino)
    \b Retrocesso (backspace)
    \f Avanço/quebra de página
    \n Avanço de linha
    \r Retorno de carro
    \t Tabulação horizontal
    \v Tabulação vertical
    \\ Barra invertida (backslash)
    \' Apóstrofo, ou aspas simples
    \" Aspas duplas
    \? Ponto de interrogação
    \ooo O byte cujo valor numérico está representado como o número octal ooo
    \xhh O byte cujo valor numérico está representado como o número hexadecimal hh

    Quando um texto tem muitas barras invertidas ou aspas, como caminhos de arquivos no Windows ou expressões regulares, as sequências de escape deixam o código difícil de ler. Para esses casos, existem as cadeias cruas (raw string literals), escritas no formato R"(...)". Tudo o que estiver entre ( e ) é usado exatamente como foi escrito, sem interpretar sequências de escape:

    Arranjos (arrays)¶

    Um arranjo é uma coleção de valores do mesmo tipo, armazenados de forma contígua na memória e acessados por um índice. Os elementos de um arranjo de \(N\) elementos são numerados de \(0\) a \(N-1\): o primeiro elemento tem índice 0, e o último, índice \(N-1\).

    C++ tem duas formas de arranjos de tamanho fixo: os arranjos nativos da linguagem e o tipo std::array, da biblioteca padrão. Para sequências cujo tamanho muda durante a execução, usa-se std::vector, apresentado na seção sobre a biblioteca padrão.

    Arranjos nativos¶

    Um arranjo nativo é declarado com o tamanho entre colchetes depois do nome. O tamanho precisa ser uma constante conhecida durante a compilação.

    #include <iostream>
#include <iterator>

int main()
{
    int faltas[5] = {2, 0, 1, 4, 3};

    faltas[3] = 5;  // o quarto elemento recebe 5

    int total = 0;
    for (int i = 0; i < 5; ++i) {
        total += faltas[i];
    }
    std::cout << "Total de faltas: " << total << '\n';  // 11

    for (int f : faltas) {      // percorre todos os elementos
        std::cout << f << ' ';
    }
    std::cout << "\nElementos: " << std::size(faltas) << '\n';  // 5
    return 0;
}

    O segundo laço for do exemplo é o laço baseado em intervalo (range-based for): a variável f assume, a cada repetição, o valor de um dos elementos do arranjo, do primeiro ao último. Ele é apresentado em detalhes na seção de controle de fluxo. A função std::size, do cabeçalho <iterator>, devolve o número de elementos do arranjo.

    Na inicialização, se houver menos valores que elementos, os elementos restantes recebem zero. Assim, int contagem[26] = {}; cria um arranjo de 26 inteiros, todos iguais a zero.

    Veja bem, preste atenção!

    Arranjos nativos não verificam os índices. Acessar faltas[5] ou faltas[-1] em um arranjo de 5 elementos não gera erro de compilação, e o programa vai ler ou escrever em uma posição de memória que não pertence ao arranjo. O resultado é comportamento indefinido: o programa pode funcionar por acaso, produzir valores sem sentido, corromper outras variáveis ou ser encerrado pelo sistema operacional.

    Além disso, arranjos nativos não podem ser copiados por atribuição com =. A expressão a == b normalmente compara os endereços obtidos pelo decaimento dos arranjos, não seus elementos. Ao recebê-los como ponteiros em funções, o tamanho não é preservado. Em código novo, prefira std::array para tamanho fixo e std::vector para tamanho variável.

int main()
{
    std::array<int, 5> notas = {7, 8, 5, 10, 9};
    std::array<int, 5> copia = notas;     // cópia completa com =

    copia[0] = 0;

    std::cout << "Tamanho: " << notas.size() << '\n';
    std::cout << "Primeiro: " << notas.front() << ", último: " << notas.back() << '\n';
    std::cout << "notas[0] = " << notas[0] << ", copia[0] = " << copia[0] << '\n';
    std::cout << std::boolalpha << "Iguais? " << (notas == copia) << '\n';

    try {
        std::cout << notas.at(7) << '\n';  // índice inválido
    } catch (const std::out_of_range& e) {
        std::cout << "Índice inválido!\n";
    }
    return 0;
}

    O acesso com colchetes (notas[i]) funciona como nos arranjos nativos, sem verificação. Já o método at(i) verifica o índice e, se ele for inválido, lança uma exceção do tipo std::out_of_range, que pode ser tratada com try/catch (o tratamento de exceções é apresentado na seção de controle de fluxo). Use at() quando houver qualquer dúvida sobre a validade do índice.

    Uma matriz de tamanho fixo pode ser declarada como um std::array de std::array: std::array<std::array<int, 4>, 3> m{}; declara uma matriz de 3 linhas e 4 colunas, com todos os elementos iguais a zero.

    Cadeias de caracteres¶

    Textos são representados em C++ pelo tipo std::string, do cabeçalho <string>. Uma std::string pode ser atribuída com =, concatenada com +, comparada com == e <, e cresce automaticamente conforme necessário:

    std::string nome = "Ada";
std::string saudacao = "Olá, " + nome + "!";  // "Olá, Ada!"
if (nome == "Ada") {
    std::cout << saudacao << '\n';
}

    As cadeias de caracteres têm uma seção própria, com todas as operações disponíveis.

    Aspas simples ou duplas?

    Em C++, caracteres individuais são cercados por aspas simples (') e cadeias de caracteres por aspas duplas ("). 'a' é um valor do tipo char; "a" é um arranjo de dois const char: a letra e o terminador nulo \0.

    Estruturas¶

    Estruturas agregam vários dados, de tipos iguais ou diferentes, em uma única variável. Elas são usadas para representar entidades que têm várias características, como uma pessoa (nome, idade, telefone), um ponto no plano (coordenadas x e y) ou uma data (dia, mês e ano). O exemplo abaixo cria uma estrutura chamada Aniversario para armazenar o nome e a data de nascimento de uma pessoa:

    struct Aniversario {
    std::string nome;
    int dia;
    int mes;
    int ano;
};

    Depois de definida, Aniversario é um tipo como outro qualquer, e pode ser usado para declarar variáveis. Cada variável do tipo Aniversario tem seus próprios membros nome, dia, mes e ano, que são acessados com o operador ponto (.):

struct Aniversario {
    std::string nome;
    int dia;
    int mes;
    int ano;

int main()
{
    // Atribuindo os membros um a um
    Aniversario abelardo;
    abelardo.nome = "Abelardo Silva";
    abelardo.dia = 15;
    abelardo.mes = 3;
    abelardo.ano = 1985;

    // Inicializando na declaração, na ordem dos membros
    Aniversario beatriz = {"Beatriz Souza", 2, 11, 1990};

    // Inicialização designada (C++20): os nomes dos membros deixam claro cada valor
    Aniversario carlos{.nome = "Carlos Lima", .dia = 30, .mes = 6, .ano = 2001};

    std::cout << abelardo.nome << ": " << abelardo.dia << '/' << abelardo.mes << '/' << abelardo.ano << '\n';
    std::cout << beatriz.nome << ": " << beatriz.dia << '/' << beatriz.mes << '/' << beatriz.ano << '\n';
    std::cout << carlos.nome << ": " << carlos.dia << '/' << carlos.mes << '/' << carlos.ano << '\n';

    Aniversario copia = beatriz;   // copia todos os membros
    copia.nome = "Outra pessoa";
    std::cout << beatriz.nome << " / " << copia.nome << '\n';  // Beatriz Souza / Outra pessoa
    return 0;
}

    Na inicialização designada, disponível a partir do C++20, os membros precisam aparecer na mesma ordem em que foram declarados na estrutura, mas alguns podem ser omitidos (e recebem o valor padrão). A atribuição de uma estrutura a outra (copia = beatriz) copia todos os membros, e as duas variáveis continuam independentes.

    Estruturas e classes

    Em C++, estruturas podem ter, além de dados, funções que operam sobre esses dados, e são praticamente iguais às classes. Esse assunto é tratado na seção de orientação a objetos. Ali também é mostrado como permitir que estruturas sejam comparadas com == e <, o que não acontece automaticamente.

    Sinônimos de tipos (using e typedef)¶

    Às vezes um tipo tem um nome longo, ou queremos dar a ele um nome que deixe mais clara a sua finalidade. Para isso, podemos criar um sinônimo (alias) com a palavra-chave using:

    using <novo_nome> = <tipo_existente>;

    Veja bem, preste atenção!

    Um sinônimo não cria um tipo novo: ele apenas permite que um tipo existente seja chamado por outro nome. Para o compilador, ll e long long são exatamente o mesmo tipo.

    O uso de sinônimos melhora a legibilidade do código ao simplificar declarações complexas, e facilita a manutenção, porque permite alterar um tipo em um único lugar. Em programação competitiva, por exemplo, é muito comum encontrar using ll = long long; no início dos programas.

    A forma mais antiga de criar sinônimos usa a palavra-chave typedef, com a ordem invertida (typedef <tipo_existente> <novo_nome>;). As duas formas são equivalentes, mas using é mais legível e é a forma recomendada em código novo.
