    Expressões e operadores¶

    Nas subseções a seguir, letras minúsculas como a e b representam valores literais ou nomes de variáveis, o que for apropriado no contexto. Ao avaliar uma expressão, os seguintes operadores podem ser usados. T indica um tipo de dados.

    Expressões e operadores aritméticos¶

    Uma expressão aritmética é construída a partir de operadores aritméticos e de variáveis ou constantes numéricas.

    Operador Sintaxe Exemplo e/ou observações
    Adição a + b
    Subtração a - b
    Mais unário +a
    Menos unário (inverso aditivo) -a
    Multiplicação a * b O produto será do tipo com maior precisão entre os fatores
    Divisão a / b O quociente será do tipo com maior precisão entre o dividendo e o divisor. Se ambos forem inteiros, a divisão é inteira
    Módulo a % b Resto da divisão inteira de a por b. Só pode ser usado com operandos inteiros
    Pré-incremento ++a Incrementa de um o valor de a, e depois utiliza o valor
    Pós-incremento a++ Utiliza o valor de a, e depois incrementa de um o valor
    Pré-decremento --a Decrementa de um o valor de a, e depois utiliza o valor
    Pós-decremento a-- Utiliza o valor de a, e depois decrementa de um o valor

    Quando os dois operandos da divisão são inteiros, o resultado também é inteiro: a parte fracionária é descartada (o resultado é truncado em direção a zero). O resto da divisão, obtido com %, tem sempre o mesmo sinal do dividendo, de forma que a relação (a / b) * b + a % b == a vale sempre.

    Divisão inteira e resto com números negativos
    std::cout << 7 / 2 << ' ' << 7 % 2 << '\n';    // 3 1
std::cout << -7 / 2 << ' ' << -7 % 2 << '\n';  // -3 -1
std::cout << 7 / -2 << ' ' << 7 % -2 << '\n';  // -3 1

    No pré-incremento (++x) ou pré-decremento (--x), o valor da variável é alterado antes de ser utilizado na expressão. Já no pós-incremento (x++) ou pós-decremento (x--), o valor original da variável é usado na expressão antes que o incremento ou decremento ocorra. Essa diferença, embora sutil, produz resultados distintos quando o operador faz parte de uma expressão maior, como uma atribuição:

    #include <iostream>

int main()
{
    int a = 5;
    int b = ++a;  // a passa a valer 6, e b recebe 6
    std::cout << "a = " << a << ", b = " << b << '\n';

    int c = 5;
    int d = c++;  // d recebe 5, e depois c passa a valer 6
    std::cout << "c = " << c << ", d = " << d << '\n';

    return 0;
}

    Quando usados isoladamente, em uma linha como contador++; ou ++contador;, as duas formas têm exatamente o mesmo efeito.

    Veja bem, preste atenção!

    Nunca modifique a mesma variável mais de uma vez na mesma expressão. Observe a linha abaixo:

    int a = 5;
int b = 10;
int c = a++ + --b + ++a - b--;  // NÃO FAÇA ISSO

    Pode parecer que basta avaliar os termos da esquerda para a direita, mas a linguagem não define em que ordem os operandos de + e - são avaliados, nem em que momento exato os incrementos e decrementos são aplicados. Como a e b são modificadas duas vezes cada, a expressão tem comportamento indefinido: o padrão da linguagem não diz qual deve ser o resultado, e compiladores diferentes (ou o mesmo compilador com opções diferentes) podem produzir valores diferentes. O GCC avisa sobre o problema quando compilamos com -Wall:

    warning: operation on 'a' may be undefined [-Wsequence-point]
warning: operation on 'b' may be undefined [-Wsequence-point]

    A solução é separar as operações em várias linhas, deixando claro o que deve acontecer e em que ordem.

    Quando os operandos são de tipos diferentes, mas compatíveis, o C++ faz uma conversão de tipo implícita, também conhecida como coerção. Nesse caso, o operando de tipo "menor" é convertido para o tipo "maior" antes da operação. Por exemplo, se um int for somado a um double, o int é implicitamente convertido em double e o resultado será do tipo double. Tipos menores que int, como char, short e bool, são sempre convertidos para int antes de qualquer operação aritmética.

    Veja bem, preste atenção!

    A conversão implícita só acontece quando os tipos são diferentes. Então, ao efetuar a divisão de um inteiro por outro, o resultado será inteiro, a menos que seja feita a conversão explícita do dividendo ou do divisor para double. 5 / 2 não é 2.5, e sim 2, pois 5 e 2 são do mesmo tipo (int), então o resultado será, também, do mesmo tipo. Para que seja 2.5, é preciso fazer 5.0 / 2 ou 5 / 2.0.

    Não importa o tipo da variável que vai receber o resultado: a divisão é feita primeiro, com os tipos dos operandos, e só depois o resultado (já truncado) é convertido para o tipo da variável.

    Quando os operandos são variáveis, a conversão explícita é feita com static_cast<T>(valor), que converte valor para o tipo T.

    Incorreto

    int a = 5;
int b = 2;
double r = a / b;  // r = 2.0, pois a divisão é inteira

    Correto

    int a = 5;
int b = 2;
double r = static_cast<double>(a) / b;  // r = 2.5

    Arredondamento exato com aritmética inteira¶

    Para calcular e formatar uma razão \(A/B\) (ou um percentual \(100 \times A/B\)) com exatamente \(K\) casas decimais, evitando os erros de precisão do tipo double e a regra de arredondamento para o par mais próximo (round half to even) usada por padrão na formatação da saída, utilizamos aritmética inteira escalonada.

    Definimos o fator de escala como \(S = 10^K\) para razões simples, ou \(S = 10^{K+2}\) para valores percentuais. Ao multiplicar o valor exato por \(S\), reduzimos o problema a encontrar o inteiro \(q\) mais próximo de \(\frac{S \cdot A}{B}\), arredondando empates exatos na metade (\(0,5\)) para cima (round half up).

    A fórmula geral utilizando divisão inteira é:

    \[q = \left\lfloor \frac{2 \cdot S \cdot A + B}{2B} \right\rfloor\]

    Na aritmética modular, escrevendo \(S \cdot A = aB + r\) com \(0 \le r \lt B\), a expressão garante que:

    • \(q = a\), se \(2r \lt B\);
    • \(q = a + 1\), se \(2r \ge B\).

    É preciso atenção aos limites dos tipos inteiros. Como o numerador \(2 \cdot S \cdot A + B\) frequentemente ultrapassa o limite de um inteiro de 32 bits (\(\approx 2 \times 10^9\)), é indispensável utilizar inteiros de 64 bits (long long ou std::int64_t), ou até o tipo __int128 (uma extensão do GCC) caso \(S \cdot A\) exceda \(10^{18}\). Para imprimir o resultado (assumindo \(K \gt 0\)), separa-se a parte inteira (q / S) e a parte fracionária (q % S), preenchendo esta última com zeros à esquerda até completar \(K\) dígitos.

    #include <iomanip>
#include <iostream>

int main()
{
    long long A = 1;
    long long B = 128;
    int K = 4;

    // Fator de escala para K casas decimais
    long long S_exibicao = 1;
    for (int i = 0; i < K; ++i) {
        S_exibicao *= 10;
    }
    long long S_calculo = S_exibicao * 100;  // Fator extra de 100 para percentual

    // Fórmula de arredondamento exato
    long long q = (2 * S_calculo * A + B) / (2 * B);

    // Impressão separando parte inteira e fracionária
    std::cout << q / S_exibicao << '.'
              << std::setfill('0') << std::setw(K) << q % S_exibicao << '\n';

    return 0;
}

    O valor exato é \(100 \times 1/128 = 0,78125\), e o programa imprime 0.7813. Os manipuladores std::setfill('0') e std::setw(K), do cabeçalho <iomanip>, fazem com que a parte fracionária seja escrita com exatamente K dígitos, completando com zeros à esquerda quando necessário. Eles são apresentados em detalhes na seção de entrada e saída.

    Operadores lógicos¶

    Operadores lógicos operam sobre valores do tipo bool e retornam um valor do tipo bool, indicando o resultado da operação.

    Operador Sintaxe Forma alternativa Exemplo e/ou observações
    NOT (\(\lnot\)) !a not a Nega o valor de a
    AND (\(\land\)) a && b a and b Será verdadeiro apenas quando a e b forem verdadeiros; em todos os outros casos, falso
    OR (\(\lor\)) a || b a or b Será falso apenas quando a e b forem falsos; em todos os outros casos, verdadeiro
    a AND b
    Verdadeiro Verdadeiro Verdadeiro
    Verdadeiro Falso Falso
    Falso Falso Verdadeiro
    Falso Falso Falso
    a OR b
    Verdadeiro Verdadeiro Verdadeiro
    Verdadeiro Verdadeiro Falso
    Falso Verdadeiro Verdadeiro
    Falso Falso Falso
    NOT a
    Falso Verdadeiro
    Verdadeiro Falso

    As formas alternativas and, or e not são palavras reservadas da linguagem e têm exatamente o mesmo significado dos símbolos. Algumas pessoas as preferem por deixarem as condições mais próximas da linguagem natural:

    if (chovendo and not tenho_guarda_chuva) {
    std::cout << "Vou me molhar!\n";
}

    A forma com símbolos (&&, || e !) é, de longe, a mais usada, e é a que aparece no restante deste texto.

    A avaliação dos operadores && (E lógico) e || (OU lógico) segue uma estratégia conhecida como curto-circuito: a avaliação de uma expressão lógica é interrompida assim que o resultado final pode ser determinado de forma inequívoca.

    No caso do operador &&, a avaliação ocorre da esquerda para a direita. Se o primeiro operando for falso, o resultado final será necessariamente falso, independentemente do valor do segundo operando. Portanto, o segundo operando não é avaliado. Isso permite escrever condições em que a segunda parte só é segura se a primeira for verdadeira, como a verificação de um ponteiro antes de acessar a memória para a qual ele aponta:

    #include <iostream>

int main()
{
    int valor = 10;
    int* ptr = &valor;

    if (ptr != nullptr && *ptr == 10) {
        std::cout << "O ponteiro é válido e aponta para 10\n";
    }

    ptr = nullptr;
    if (ptr != nullptr && *ptr == 10) {  // *ptr não é avaliado
        std::cout << "Esta linha não é executada\n";
    }

    return 0;
}

    Quando ptr é nulo, a segunda parte da condição (*ptr == 10) não é avaliada, evitando um acesso a uma posição de memória inválida, que provavelmente encerraria o programa com erro. (Ponteiros são apresentados em detalhes em uma seção própria.)

    De forma semelhante, o operador || também utiliza o curto-circuito. Se o primeiro operando for verdadeiro, o resultado final será necessariamente verdadeiro, e o segundo operando não é avaliado. Um exemplo comum é a verificação de várias alternativas: em if (opcao == 'a' || opcao == 'b' || opcao == 'c'), se opcao for igual a 'a', as outras comparações não são realizadas.

    O curto-circuito não apenas melhora a eficiência do código, mas também permite escrever expressões mais seguras, prevenindo erros que poderiam ocorrer se todos os operandos fossem avaliados indiscriminadamente.

    Operadores relacionais¶

    Os operadores relacionais retornam um valor do tipo bool que indica se a relação é verdadeira ou falsa.

    Operação Sintaxe Exemplo e/ou observações
    Igual a a == b a igual a b
    Não igual a
    (diferente de)    		 a != b a não igual (diferente) a b
    Maior que a > b a maior que b
    Menor que a < b a menor que b
    Maior ou igual a a >= b a maior ou igual a b
    Menor ou igual a a <= b a menor ou igual a b

    Em C++, o operador de igualdade é um sinal de igual duplo (==), enquanto o sinal de igual simples (=) é utilizado para atribuição. No início, é comum confundir os sinais, então cuidado e atenção! Se você acidentalmente usar = em vez de == dentro de uma condição, o programa vai compilar, mas o resultado não será o esperado.

    A expressão abaixo não verifica se a é igual a b: ela atribui o valor de b a a. Como a atribuição produz o valor atribuído, e qualquer número diferente de zero é considerado verdadeiro em uma condição, o bloco será executado sempre que b for diferente de zero (e a terá perdido seu valor original):

    if (a = b) {  // ERRO: deveria ser "a == b"
    std::cout << "A condição é verdadeira!\n";
}

    Para verificar a igualdade corretamente, sempre use ==:

    if (a == b) {  // Comparação correta
    std::cout << "A condição é verdadeira!\n";
}

    Compilando com -Wall, o GCC avisa quando encontra uma atribuição usada como condição (suggest parentheses around assignment used as truth value). Mais um motivo para nunca ignorar os avisos do compilador.

    Veja bem, preste atenção!

    Se você quer saber se um número está entre outros dois, a expressão usada na matemática (\(10 < n < 50\)) não vai funcionar em C++. Ela compila, mas o compilador avalia primeiro 10 < n, que resulta em true ou false; esse resultado é convertido para 1 ou 0 e então comparado com 50. Como tanto 0 quanto 1 são menores que 50, a condição é sempre verdadeira, qualquer que seja o valor de n.

    A forma correta envolve o operador AND (&&): 10 < n && n < 50.

    Veja bem, preste atenção!

    Números reais (float e double) são armazenados de forma aproximada, e pequenos erros de arredondamento se acumulam nas operações. Por isso, comparar dois números reais com == raramente é uma boa ideia:

    double x = 0.1 + 0.2;

std::cout << (x == 0.3) << '\n';                  // 0 (falso!)
std::cout << (std::abs(x - 0.3) < 1e-9) << '\n';  // 1 (verdadeiro)

    A forma correta é verificar se a diferença entre os dois valores é menor que uma tolerância pequena, escolhida de acordo com o problema. A função std::abs, que calcula o valor absoluto, está no cabeçalho <cmath>.

    O operador de comparação de três vias (C++20)

    O C++20 introduziu o operador <=>, apelidado de "nave espacial" (spaceship operator). Em vez de responder sim ou não, ele diz de uma só vez se a é menor, igual ou maior que b: o resultado de a <=> b pode ser comparado com zero ((a <=> b) < 0 significa que a é menor que b). Seu principal uso é na definição de comparações para tipos criados pelo programador, assunto da seção de orientação a objetos.

    Operadores de bit¶

    Você sabia?

    Os operadores de deslocamento podem ser usados para efetuar multiplicação e divisão por potências de 2.

    Suponha que temos um número inteiro a = 5. Em representação binária, 5 é 00000101. Um deslocamento à esquerda de 2 bits (a << 2) "empurra" os bits de a duas posições para a esquerda, resultando em 00010100. Os bits vazios à direita são preenchidos com zeros. Como 00010100 em binário corresponde a 20 em decimal, 5 << 2 resulta em 20.

    Usando o mesmo número a = 5 (binário 00000101), um deslocamento à direita de 1 bit (a >> 1) resulta em 00000010, que é 2 em decimal. Ou seja, 5 >> 1 resulta em 2.

    Resumo:

    • a << b: multiplica a por \(2^b\).
    • a >> b: divide a por \(2^b\) (com comportamento diferente para números negativos).

    Os operadores de bit operam sobre a representação binária dos valores inteiros.

    Operação Sintaxe Exemplo e/ou observações
    NOT ~a Inverte os bits de a
    AND a & b Efetua a operação AND bit a bit sobre os operandos a e b
    OR a | b Efetua a operação OR bit a bit sobre os operandos a e b
    XOR a ^ b Efetua a operação XOR (OU exclusivo) bit a bit sobre os operandos a e b
    Deslocamento à esquerda a << b Desloca os bits de a para a esquerda por b posições. Os bits à direita são preenchidos com zeros
    Deslocamento à direita a >> b Desloca os bits de a para a direita por b posições. Se a for unsigned, os bits à esquerda são preenchidos com zeros (deslocamento lógico); se a for um número com sinal, o bit de sinal é replicado (deslocamento aritmético)

    O operador XOR (OU exclusivo) retorna verdadeiro apenas quando a != b.

    a XOR b
    Verdadeiro Falso Verdadeiro
    Verdadeiro Verdadeiro Falso
    Falso Verdadeiro Verdadeiro
    Falso Falso Falso

    Veja bem, preste atenção!

    Os símbolos << e >> têm dois usos em C++: são os operadores de deslocamento de bits e os operadores de saída e entrada de dados (std::cout << x, std::cin >> x). Como a precedência deles é maior que a de &, | e ^, uma operação de bit no meio de uma saída precisa estar entre parênteses:

    Incorreto

    std::cout << a & b << '\n';  // erro de compilação

    Correto

    std::cout << (a & b) << '\n';

    O mesmo vale para os próprios deslocamentos: para escrever o valor de a deslocado duas posições, use std::cout << (a << 2).

    Operadores de atribuição¶

    Para operadores combinados na forma \(a~ \circledcirc= b\), a operação equivalente é \(a = a \circledcirc b\).

    Operação Sintaxe Exemplo e/ou observações
    Atribuição a = b Atribui o valor de b à variável a
    Adição combinada a += b Equivalente a a = a + b
    Subtração combinada a -= b Equivalente a a = a - b
    Multiplicação combinada a *= b Equivalente a a = a * b
    Divisão combinada a /= b Equivalente a a = a / b
    Módulo combinado a %= b Equivalente a a = a % b (resto da divisão)
    AND bit a bit combinado a &= b Equivalente a a = a & b
    OR bit a bit combinado a |= b Equivalente a a = a | b
    XOR bit a bit combinado a ^= b Equivalente a a = a ^ b
    Deslocamento à esquerda combinado a <<= b Equivalente a a = a << b
    Deslocamento à direita combinado a >>= b Equivalente a a = a >> b

    Membros, ponteiros e escopo¶

    Acesso a membro a.b Membro b do objeto a
    Acesso a membro via ponteiro a->b Membro b do objeto apontado por a; equivalente a (*a).b
    Indireção *a Objeto apontado por a

    Outros¶

    Operação Sintaxe Exemplo e/ou observações
    Condicional (ternário) c ? a : b Resulta em a se a condição c for verdadeira, ou em b caso contrário
    Tamanho de sizeof a
    sizeof(T)    		 Tamanho do objeto a ou do tipo T, em número de chars. Como sizeof(char) é sempre 1, e um char tem 8 bits em praticamente todas as máquinas atuais, o resultado é o tamanho em bytes
    Conversão explícita static_cast<T>(a) Converte o valor de a para o tipo T, com verificação feita pelo compilador
    Conversão explícita (forma antiga) (T) a Converte o valor de a para o tipo T, sem as verificações de static_cast; evite
    Alocação dinâmica new T
    delete a    		 Cria um objeto do tipo T na memória dinâmica / destrói o objeto apontado por a
    Vírgula a, b Avalia a, descarta o resultado, e depois avalia b

    O operador condicional (ou ternário) é uma forma compacta de escolher entre dois valores dentro de uma expressão:

    int nota = 7;
std::cout << (nota >= 6 ? "Aprovado" : "Reprovado") << '\n';  // Aprovado

    A conversão explícita com static_cast deixa clara a intenção do programador e é verificada pelo compilador, que recusa conversões sem sentido (como transformar um ponteiro em um número real). Ela é usada, por exemplo, para forçar uma divisão real entre inteiros, para descartar a parte fracionária de um número real ou para obter o código numérico de um caractere:

    double media = 7.8;
int parte_inteira = static_cast<int>(media);    // 7 (a parte fracionária é descartada)

char letra = 'A';
std::cout << static_cast<int>(letra) << '\n';         // 65 (código do caractere 'A')
std::cout << static_cast<char>(letra + 2) << '\n';    // C

    A linguagem tem ainda outras três formas de conversão explícita (const_cast, reinterpret_cast e dynamic_cast), usadas em situações bem específicas. A forma antiga, (T) a, tenta todas elas até encontrar uma que funcione, o que pode esconder erros. Por isso, prefira sempre static_cast.

    Precedência dos operadores¶

    Na hora de avaliar uma expressão, seja ela aritmética, de bit ou lógica, os diversos operadores presentes precisam ser avaliados na ordem correta de precedência. Já fazemos isso quando resolvemos uma expressão aritmética no papel: primeiro as potências e raízes, depois os produtos e quocientes, e assim sucessivamente.

    A tabela abaixo mostra os operadores mais usados, ordenados de forma decrescente de prioridade (primeiro os do início, depois os do final), quantos operandos possuem, e se são avaliados da esquerda para a direita (→) ou da direita para a esquerda (←).

    Operador Operandos Sentido da avaliação

    Na dúvida, use parênteses

    Ninguém precisa decorar a tabela inteira. Quando uma expressão misturar operadores de grupos diferentes e houver qualquer dúvida sobre a ordem de avaliação, use parênteses: eles deixam a intenção explícita para o compilador e, principalmente, para quem for ler o código depois.
