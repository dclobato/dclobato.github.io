    Pilhas, filas e filas de prioridade¶

    Pilhas, filas e filas de prioridade são estruturas de dados clássicas em que o acesso aos elementos é restrito: não é possível acessar qualquer elemento, apenas aquele que a política da estrutura determina. Em uma pilha, só o último elemento colocado; em uma fila, só o primeiro; em uma fila de prioridade, só o de maior prioridade. Essa restrição, longe de ser uma limitação, é justamente o que torna essas estruturas úteis: elas modelam diretamente muitas situações do mundo real e de algoritmos importantes.

    A biblioteca padrão oferece essas estruturas em dois cabeçalhos: <stack>, com a pilha (std::stack), e <queue>, com a fila (std::queue) e a fila de prioridade (std::priority_queue).

    Adaptadores de contêineres

    std::stack, std::queue e std::priority_queue são chamados de adaptadores: eles não guardam os elementos por conta própria, e sim usam outro contêiner por baixo (por padrão, std::deque para a pilha e a fila, e std::vector para a fila de prioridade), expondo apenas as operações permitidas pela sua política de acesso. Por isso, eles não têm iteradores, não têm o operador [] e não podem ser percorridos com um laço for baseado em intervalo. A única forma de ver todos os elementos é retirá-los, um a um.

    <stack>: pilhas¶

    Uma pilha segue a política LIFO (Last In, First Out): o último elemento a entrar é o primeiro a sair, como em uma pilha de pratos. Os elementos são colocados e retirados sempre do mesmo lado, chamado de topo.

    #include <iostream>
#include <stack>

int main()
{
    std::stack<int> pilha;

    pilha.push(10);
    pilha.push(20);
    pilha.push(30);          // topo: 30

    std::cout << "Topo: " << pilha.top() << ", tamanho: " << pilha.size() << '\n';   // 30, 3

    while (!pilha.empty()) {
        std::cout << pilha.top() << ' ';   // lê o topo...
        pilha.pop();                       // ...e depois remove
    }
    std::cout << '\n';                     // 30 20 10
    return 0;
}
    Operação Descrição Complexidade
    p.push(x) Coloca x no topo \(O(1)\)
    p.emplace(args...) Constrói um elemento no topo, a partir dos argumentos \(O(1)\)
    p.top() Elemento do topo \(O(1)\)
    p.pop() Remove o elemento do topo \(O(1)\)
    p.empty() Verdadeiro se a pilha estiver vazia \(O(1)\)
    p.size() Número de elementos \(O(1)\)

    Veja bem, preste atenção!

    O método pop() não devolve o elemento removido: ele apenas o descarta. Para usar o elemento, leia-o com top() antes de chamar pop(). E chamar top() ou pop() em uma pilha vazia tem comportamento indefinido: sempre verifique empty() antes, quando houver qualquer chance de a pilha estar vazia. As mesmas regras valem para a fila e para a fila de prioridade.

    Pilhas aparecem sempre que é preciso "lembrar" de coisas para tratar depois, na ordem inversa: desfazer as últimas ações de um editor, voltar às páginas anteriores de um navegador, avaliar expressões matemáticas, percorrer labirintos e grafos em profundidade. Um exemplo clássico é verificar se os parênteses, colchetes e chaves de uma expressão estão balanceados: cada símbolo de abertura é empilhado e, a cada símbolo de fechamento, o topo da pilha precisa ser o símbolo de abertura correspondente.

    #include <iostream>
#include <stack>
#include <string>

bool balanceada(const std::string& expressao)
{
    std::stack<char> abertos;

    for (char c : expressao) {
        if (c == '(' || c == '[' || c == '{') {
            abertos.push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (abertos.empty()) {
                return false;                 // fechou algo que não foi aberto
            }
            char topo = abertos.top();
            abertos.pop();
            if ((c == ')' && topo != '(') || (c == ']' && topo != '[') || (c == '}' && topo != '{')) {
                return false;                 // fechou com o símbolo errado
            }
        }
    }
    return abertos.empty();                   // sobrou algo aberto?
}

int main()
{
    std::string exemplos[] = {"(a + b) * [c - d]", "{[()]}", "(a + b))", "([)]", "((a)"};
    for (const auto& e : exemplos) {
        std::cout << e << " -> " << (balanceada(e) ? "balanceada" : "não balanceada") << '\n';
    }
    return 0;
}
    Saída
    (a + b) * [c - d] -> balanceada
{[()]} -> balanceada
(a + b)) -> não balanceada
([)] -> não balanceada
((a) -> não balanceada

#include <queue>
#include <string>

int main()
{

    atendimento.push("Ana");
    atendimento.push("Bruno");
    atendimento.push("Carla");

    std::cout << "Primeiro: " << atendimento.front() << ", último: " << atendimento.back() << '\n';

    while (!atendimento.empty()) {
        std::cout << "Atendendo " << atendimento.front() << '\n';
        atendimento.pop();
    }
    return 0;
}

    #include <iostream>
#include <queue>

int main()
{
    int n = 7;
    std::queue<int> pilha_de_cartas;
    for (int i = 1; i <= n; ++i) {
        pilha_de_cartas.push(i);         // carta 1 no topo
    }

    std::cout << "Descartadas:";
    while (pilha_de_cartas.size() > 1) {
        std::cout << ' ' << pilha_de_cartas.front();   // descarta a carta do topo
        pilha_de_cartas.pop();
        pilha_de_cartas.push(pilha_de_cartas.front()); // a próxima vai para o fundo
        pilha_de_cartas.pop();
    }
    std::cout << "\nCarta restante: " << pilha_de_cartas.front() << '\n';
    return 0;
}
    Saída

    Fila ou std::deque?

    Um std::deque também pode ser usado como fila (com push_back e pop_front). Quando o programa só precisa do comportamento de fila, prefira std::queue: o nome do tipo já informa a quem lê o código como a estrutura vai ser usada, e o compilador impede operações que não fazem sentido para uma fila. Use std::deque quando realmente precisar das duas pontas, ou de acesso pelo índice.

    <queue>: filas de prioridade e heaps¶

    Em uma fila de prioridade, cada elemento tem uma prioridade, e o próximo a sair é sempre o de maior prioridade, independentemente da ordem em que os elementos entraram. É o que acontece em um pronto-socorro, onde os pacientes mais graves são atendidos primeiro, ou em um sistema operacional, que escolhe o próximo processo a executar pela importância.

    O que é uma heap¶

    A fila de prioridade da biblioteca padrão é implementada com uma estrutura chamada heap (monte). Uma heap é uma árvore binária (cada elemento tem no máximo dois "filhos") quase completa, com uma propriedade especial: em uma max-heap, todo elemento é maior ou igual aos seus filhos; em uma min-heap, todo elemento é menor ou igual aos seus filhos. Com isso, o maior elemento (ou o menor, na min-heap) está sempre na raiz, o topo da árvore.

    A árvore não precisa de ponteiros: ela é guardada em um vetor, nível por nível, e os filhos do elemento na posição \(i\) ficam nas posições \(2i + 1\) e \(2i + 2\). O diagrama abaixo mostra uma max-heap com os valores 1, 1, 2, 3, 4, 5, 6 e 9, e o vetor correspondente, [9, 6, 4, 1, 5, 3, 2, 1]:

    graph TD
  A["9<br/><small>posição 0</small>"] --> B["6<br/><small>posição 1</small>"]
  A --> C["4<br/><small>posição 2</small>"]
  B --> D["1<br/><small>posição 3</small>"]
  B --> E["5<br/><small>posição 4</small>"]
  C --> F["3<br/><small>posição 5</small>"]
  C --> G["2<br/><small>posição 6</small>"]
  D --> H["1<br/><small>posição 7</small>"]

    Repare que a heap não está ordenada: o 5 está abaixo do 6, mas acima do 1; o 4 está acima do 3 e do 2, mas abaixo do 9. A única garantia é que cada elemento é maior ou igual aos seus filhos e, portanto, que a raiz é o maior de todos. Essa organização "parcial" é muito mais barata de manter que uma ordenação completa: depois de inserir um elemento ou de retirar a raiz, basta trocar alguns elementos de lugar ao longo de um único caminho da árvore, cujo comprimento é \(O(\log n)\), para restaurar a propriedade.

    std::priority_queue¶

    Por padrão, std::priority_queue é uma max-heap: o maior elemento fica no topo. Para que o menor elemento fique no topo, usamos o terceiro parâmetro do template, que é o critério de comparação, com std::greater<int> (do cabeçalho <functional>). Como o terceiro parâmetro só pode ser indicado depois do segundo, também é preciso escrever o contêiner usado por baixo, std::vector<int>:

    #include <functional>
#include <iostream>
#include <queue>
#include <vector>

int main()
{
    std::priority_queue<int> maior_primeiro;
    for (int x : {5, 3, 1, 4, 2}) {
        maior_primeiro.push(x);
    }
    std::cout << "Topo: " << maior_primeiro.top() << '\n';    // 5

    std::cout << "Retirando:";
    while (!maior_primeiro.empty()) {
        std::cout << ' ' << maior_primeiro.top();
        maior_primeiro.pop();
    }
    std::cout << '\n';                                         // 5 4 3 2 1

    std::priority_queue<int, std::vector<int>, std::greater<int>> menor_primeiro;
    for (int x : {5, 3, 1, 4, 2}) {
        menor_primeiro.push(x);
    }
    std::cout << "Retirando:";
    while (!menor_primeiro.empty()) {
        std::cout << ' ' << menor_primeiro.top();
        menor_primeiro.pop();
    }
    std::cout << '\n';                                         // 1 2 3 4 5
    return 0;
}
    Operação Descrição Complexidade
    pq.push(x) Insere x \(O(\log n)\)
    pq.emplace(args...) Constrói e insere um elemento, a partir dos argumentos \(O(\log n)\)
    pq.top() Elemento de maior prioridade \(O(1)\)
    pq.pop() Remove o elemento de maior prioridade \(O(\log n)\)
    pq.empty() Verdadeiro se a fila estiver vazia \(O(1)\)
    pq.size() Número de elementos \(O(1)\)
    Construção a partir de um intervalo: std::priority_queue<int> pq(v.begin(), v.end()); Monta a heap com todos os elementos de uma vez \(O(n)\)

    Retirar todos os elementos de uma fila de prioridade, um a um, produz os elementos em ordem, como mostra o exemplo. Mas, se o objetivo for apenas ordenar, std::sort é mais simples e mais rápido. A fila de prioridade é útil quando elementos entram e saem intercaladamente, e a cada momento é preciso saber qual é o maior (ou o menor) dos que estão presentes.

    #include <iostream>
#include <queue>
#include <string>
#include <utility>

int main()
{
    std::priority_queue<std::pair<int, std::string>> tarefas;   // (prioridade, descrição)

    tarefas.push({2, "responder e-mails"});
    tarefas.push({5, "corrigir falha no servidor"});
    tarefas.push({3, "preparar relatório"});
    tarefas.push({5, "atender cliente"});

    while (!tarefas.empty()) {
        auto [prioridade, descricao] = tarefas.top();
        tarefas.pop();
        std::cout << prioridade << " - " << descricao << '\n';
    }
    return 0;
}
    Saída
    5 - corrigir falha no servidor
5 - atender cliente
3 - preparar relatório
2 - responder e-mails

    Veja bem, preste atenção!

    Repare no empate entre as duas tarefas de prioridade 5: "corrigir falha no servidor" saiu antes de "atender cliente", embora tenha entrado depois. O motivo é o desempate pelo segundo campo: como a fila coloca o maior par no topo, e "corrigir..." é maior que "atender..." em ordem alfabética, ela vem primeiro. A fila de prioridade não preserva a ordem de chegada entre elementos de mesma prioridade.

    Quando o desempate importa (por exemplo, para atender primeiro quem chegou antes), ele precisa fazer parte da comparação, como no próximo exemplo.

    #include <iostream>
#include <queue>
#include <string>
#include <vector>

struct Paciente {
    std::string nome;
    int gravidade;      // quanto maior, mais urgente
    int chegada;        // ordem de chegada
};

struct MenosUrgente {
    bool operator()(const Paciente& a, const Paciente& b) const
    {
        if (a.gravidade != b.gravidade) {
            return a.gravidade < b.gravidade;   // menor gravidade = menor prioridade
        }
        return a.chegada > b.chegada;           // empate: quem chegou depois tem menor prioridade
    }
};

int main()
{
    std::priority_queue<Paciente, std::vector<Paciente>, MenosUrgente> pronto_socorro;

    pronto_socorro.push({"Ana", 2, 1});
    pronto_socorro.push({"Bruno", 5, 2});
    pronto_socorro.push({"Carla", 3, 3});
    pronto_socorro.push({"Daniel", 5, 4});
    pronto_socorro.push({"Eva", 2, 5});

    while (!pronto_socorro.empty()) {
        const Paciente& p = pronto_socorro.top();
        std::cout << p.nome << " (gravidade " << p.gravidade << ")\n";
        pronto_socorro.pop();
    }
    return 0;
}
    Saída
    Bruno (gravidade 5)
Daniel (gravidade 5)
Carla (gravidade 3)
Ana (gravidade 2)
Eva (gravidade 2)

    Veja bem, preste atenção!

    O critério de comparação da fila de prioridade funciona "ao contrário" do que a intuição sugere: ele responde à pergunta "a tem menor prioridade que b?", e o elemento que fica no topo é o maior segundo esse critério. É por isso que std::less (o padrão, equivalente a a < b) deixa o maior elemento no topo, e std::greater (a > b) deixa o menor. Ao escrever um critério próprio, pense: "devolvo true quando a deve sair depois de b".

    Outras duas formas de definir o critério são: definir o operador < na própria estrutura (e usar a fila sem o terceiro parâmetro), ou usar uma expressão lambda. No caso da lambda, o tipo é obtido com decltype, e a lambda é passada também para o construtor da fila:

    #include <iostream>
#include <queue>
#include <string>
#include <vector>

int main()
{
    auto mais_longa_depois = [](const std::string& a, const std::string& b) {
        return a.size() > b.size();          // a cadeia mais curta tem a maior prioridade
    };

    std::priority_queue<std::string, std::vector<std::string>, decltype(mais_longa_depois)>
        palavras(mais_longa_depois);

    for (const char* p : {"maratona", "de", "programação", "competitiva", "C++"}) {
        palavras.push(p);
    }
    while (!palavras.empty()) {
        std::cout << palavras.top() << ' ';  // de C++ maratona competitiva programação
        palavras.pop();
    }
    std::cout << '\n';
    return 0;
}

    #include <iostream>
#include <queue>
#include <string>
#include <utility>

int main()
{
    std::priority_queue<std::pair<int, std::string>> herois;   // (força, nome)
    herois.push({80, "Raio"});
    herois.push({50, "Sombra"});
    herois.push({65, "Tempestade"});

    for (int rodada = 1; rodada <= 4; ++rodada) {
        auto [forca, nome] = herois.top();       // o mais forte luta
        herois.pop();
        std::cout << "Rodada " << rodada << ": " << nome << " luta com força " << forca << '\n';
        herois.push({forca / 2, nome});          // volta para a fila mais fraco
    }
    return 0;
}

Sempre que ela passar de \(k\), retiramos o menor. Ao final, sobram exatamente os \(k\) maiores, com custo \(O(n \log k)\):

    #include <functional>
#include <iostream>
#include <queue>
#include <vector>

int main()
{
    std::vector<int> pontuacoes = {45, 92, 13, 78, 66, 99, 51, 87, 30, 71};
    std::size_t k = 3;

    std::priority_queue<int, std::vector<int>, std::greater<int>> melhores;   // min-heap
    for (int p : pontuacoes) {
        melhores.push(p);
        if (melhores.size() > k) {
            melhores.pop();          // descarta o menor dos que estão guardados
        }
    }

    std::cout << "Os " << k << " maiores (do menor para o maior):";
    while (!melhores.empty()) {
        std::cout << ' ' << melhores.top();     // 87 92 99
        melhores.pop();
    }
    std::cout << '\n';
    return 0;
}

    #include <functional>
#include <iostream>
#include <queue>
#include <tuple>
#include <vector>

int main()
{
    std::vector<std::vector<int>> listas = {
        {1, 4, 9},
        {2, 3, 10, 12},
        {5, 6},
    };

    // (valor, índice da lista, posição na lista), com o menor valor no topo
    using Item = std::tuple<int, std::size_t, std::size_t>;
    std::priority_queue<Item, std::vector<Item>, std::greater<Item>> heap;

    for (std::size_t i = 0; i < listas.size(); ++i) {
        if (!listas[i].empty()) {
            heap.push({listas[i][0], i, 0});
        }
    }

    std::vector<int> resultado;
    while (!heap.empty()) {
        auto [valor, lista, pos] = heap.top();
        heap.pop();
        resultado.push_back(valor);
        if (pos + 1 < listas[lista].size()) {
            heap.push({listas[lista][pos + 1], lista, pos + 1});
        }
    }

    for (int x : resultado) {
        std::cout << x << ' ';       // 1 2 3 4 5 6 9 10 12
    }
    std::cout << '\n';
    return 0;
}

    #include <algorithm>
#include <iostream>
#include <vector>

void mostra(const char* rotulo, const std::vector<int>& v)
{
    std::cout << rotulo;
    for (int x : v) {
        std::cout << ' ' << x;
    }
    std::cout << '\n';
}

int main()
{
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

    std::make_heap(v.begin(), v.end());          // organiza como max-heap
    mostra("heap:        ", v);
    std::cout << "maior: " << v.front() << '\n';

    v.push_back(7);                               // 1) acrescenta no final
    std::push_heap(v.begin(), v.end());           // 2) restaura a heap
    mostra("após inserir:", v);

    std::pop_heap(v.begin(), v.end());            // 1) leva o maior para o final
    int maior = v.back();
    v.pop_back();                                 // 2) remove do vetor
    std::cout << "retirado: " << maior << '\n';
    mostra("após retirar:", v);

    std::cout << std::boolalpha << "é heap? " << std::is_heap(v.begin(), v.end()) << '\n';

    std::sort_heap(v.begin(), v.end());           // ordena (a heap deixa de existir)
    mostra("ordenado:    ", v);
    return 0;
}

    Função Descrição Complexidade
    std::make_heap(ini, fim) Organiza o intervalo como uma max-heap \(O(n)\)
    std::push_heap(ini, fim) Depois de acrescentar um elemento no final, restaura a heap \(O(\log n)\)
    std::pop_heap(ini, fim) Leva o maior elemento para o final e reorganiza o restante como heap \(O(\log n)\)
    std::sort_heap(ini, fim) Ordena uma heap em ordem crescente \(O(n \log n)\)
    std::is_heap(ini, fim) Verifica se o intervalo é uma heap \(O(n)\)

    Repare que std::push_heap e std::pop_heap não mudam o tamanho do vetor: a inserção é feita em duas etapas (push_back seguido de push_heap), e a remoção também (pop_heap seguido de pop_back). Todas as funções aceitam um critério de comparação como último argumento; com std::greater<int>(), a heap passa a ser uma min-heap. É exatamente assim que std::priority_queue funciona por dentro.
