    Contêineres sequenciais¶

    Os contêineres sequenciais guardam os elementos em uma ordem definida pelo programador: cada elemento fica na posição em que foi colocado. Os principais são std::vector, std::array, std::deque e std::list. Eles diferem na forma como organizam os elementos na memória, e por isso cada um é eficiente para um conjunto diferente de operações.

    std::vector¶

    O std::vector, do cabeçalho <vector>, é uma sequência de elementos do mesmo tipo, guardados lado a lado na memória, que cresce e diminui automaticamente. Ele oferece acesso a qualquer elemento pelo índice em tempo constante e inserção e remoção eficientes no final. É o contêiner mais usado de C++, e deve ser a escolha padrão sempre que não houver um bom motivo para usar outro.

    #include <iostream>
#include <string>
#include <vector>

int main()
{
    std::vector<int> vazio;                    // nenhum elemento
    std::vector<int> zeros(5);                 // 5 elementos iguais a 0
    std::vector<int> setes(4, 7);              // 4 elementos iguais a 7
    std::vector<int> primos = {2, 3, 5, 7};    // elementos listados
    std::vector<std::string> nomes = {"Ana", "Bruno"};
    std::vector<int> copia = primos;           // cópia independente

    std::cout << vazio.size() << ' ' << zeros.size() << ' ' << setes.size() << ' '
              << primos.size() << ' ' << nomes.size() << ' ' << copia.size() << '\n';  // 0 5 4 4 2 4
    std::cout << std::boolalpha << vazio.empty() << ' ' << (copia == primos) << '\n';  // true true
    return 0;
}

    Veja bem, preste atenção!

    Parênteses e chaves têm significados diferentes na criação de um vetor: std::vector<int> a(5); cria um vetor com cinco elementos iguais a zero, enquanto std::vector<int> b{5}; cria um vetor com um elemento, igual a 5. Da mesma forma, std::vector<int> c(4, 7); tem quatro setes, e std::vector<int> d{4, 7}; tem os elementos 4 e 7.

    Vetores podem ser copiados com = e comparados com == e < (a comparação com < é lexicográfica, elemento a elemento, como nas cadeias de caracteres).

    #include <iostream>
#include <stdexcept>
#include <vector>

int main()
{
    std::vector<int> v = {10, 20, 30, 40, 50};

    std::cout << v[0] << ' ' << v[4] << '\n';         // 10 50
    std::cout << v.front() << ' ' << v.back() << '\n'; // 10 50

    v[1] = 25;
    v.at(2) = 35;

    for (std::size_t i = 0; i < v.size(); ++i) {
        std::cout << v[i] << ' ';                      // 10 25 35 40 50
    }
    std::cout << '\n';

    try {
        v.at(10) = 1;
    } catch (const std::out_of_range& e) {
        std::cout << "Índice inválido\n";
    }
    return 0;
}
    Operação Descrição Complexidade
    v[i] Elemento na posição i, sem verificação do índice \(O(1)\)
    v.at(i) Elemento na posição i, com verificação (lança std::out_of_range) \(O(1)\)
    v.front(), v.back() Primeiro e último elementos (o vetor não pode estar vazio) \(O(1)\)
    v.size() Número de elementos \(O(1)\)
    v.empty() Verdadeiro se o vetor não tiver elementos \(O(1)\)

    Veja bem, preste atenção!

    O método size() devolve um valor do tipo std::size_t, que é um inteiro sem sinal. Isso causa dois problemas comuns:

    • Comparar um índice int com v.size() gera o aviso comparison of integer expressions of different signedness. Use std::size_t como tipo do índice, ou converta o tamanho: static_cast<int>(v.size());
    • Subtrair de um valor sem sinal pode "dar a volta": se o vetor estiver vazio, v.size() - 1 não é \(-1\), e sim 18446744073709551615. Um laço como for (std::size_t i = 0; i < v.size() - 1; ++i) executa bilhões de vezes com um vetor vazio. Prefira escrever a condição sem subtração: i + 1 < v.size().

    A função std::ssize(v) (C++20, cabeçalho <iterator>) devolve o tamanho como um inteiro com sinal, o que evita os dois problemas.

    #include <algorithm>
#include <iostream>
#include <vector>

void mostra(const std::vector<int>& v)
{
    for (int x : v) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
}

int main()
{
    std::vector<int> v;

    v.push_back(10);                  // [10]
    v.push_back(20);                  // [10, 20]
    v.push_back(30);                  // [10, 20, 30]
    mostra(v);

    v.insert(v.begin() + 1, 15);      // insere 15 na posição 1: [10, 15, 20, 30]
    v.insert(v.begin(), 5);           // insere no início: [5, 10, 15, 20, 30]
    mostra(v);

    v.pop_back();                     // remove o último: [5, 10, 15, 20]
    v.erase(v.begin() + 2);           // remove a posição 2: [5, 10, 20]
    mostra(v);

    v.push_back(10);
    v.push_back(40);                  // [5, 10, 20, 10, 40]
    std::erase(v, 10);                // remove todos os 10 (C++20): [5, 20, 40]
    mostra(v);

    std::erase_if(v, [](int x) { return x > 30; });   // remove os maiores que 30: [5, 20]
    mostra(v);

    v.resize(5);                      // aumenta para 5, completando com 0: [5, 20, 0, 0, 0]
    mostra(v);
    v.resize(1);                      // reduz para 1: [5]
    mostra(v);

    v.clear();                        // remove tudo
    std::cout << v.size() << '\n';    // 0
    return 0;
}
    Operação Descrição Complexidade
    v.push_back(x) Acrescenta x ao final \(O(1)\) amortizado
    v.emplace_back(args...) Constrói um elemento ao final, a partir dos argumentos \(O(1)\) amortizado
    v.pop_back() Remove o último elemento \(O(1)\)
    v.insert(it, x) Insere x antes da posição apontada pelo iterador it \(O(n)\)
    v.erase(it) Remove o elemento apontado por it \(O(n)\)
    v.erase(ini, fim) Remove os elementos do intervalo [ini, fim) \(O(n)\)
    std::erase(v, x) Remove todos os elementos iguais a x (C++20) \(O(n)\)
    std::erase_if(v, cond) Remove todos os elementos para os quais cond é verdadeira (C++20) \(O(n)\)
    v.resize(n) Muda o tamanho para n, completando com zeros ou descartando o final \(O(n)\)
    v.clear() Remove todos os elementos \(O(n)\)

    As posições em insert e erase são indicadas por iteradores: v.begin() aponta para o primeiro elemento, e v.begin() + i para o elemento de índice i. Inserir ou remover no meio (ou no início) de um vetor é \(O(n)\), porque todos os elementos seguintes precisam ser deslocados uma posição. Se o programa faz isso com frequência, um std::deque (para as pontas) ou outra estrutura pode ser mais adequado.

    Veja bem, preste atenção!

    Inserir ou remover elementos pode invalidar os iteradores, ponteiros e referências para elementos do vetor: depois da operação, eles podem apontar para posições erradas ou para memória já liberada. Não guarde iteradores ou referências para elementos de um vetor que vai ser modificado, e nunca insira ou remova elementos dentro de um laço for baseado em intervalo que percorre o próprio vetor.

    Tamanho e capacidade¶

    Para que push_back seja rápido, o vetor reserva mais memória do que precisa. A capacidade (v.capacity()) é quantos elementos cabem no espaço já reservado; o tamanho (v.size()) é quantos elementos existem de fato. Quando o tamanho alcança a capacidade, o vetor aloca um espaço maior (normalmente o dobro), move ou copia os elementos para lá e libera o espaço antigo:

    #include <iostream>
#include <vector>

int main()
{
    std::vector<int> v;
    std::size_t capacidade = v.capacity();
    for (int i = 0; i < 100; ++i) {
        v.push_back(i);
        if (v.capacity() != capacidade) {
            capacidade = v.capacity();
            std::cout << "tamanho " << v.size() << " -> capacidade " << capacidade << '\n';
        }
    }

    std::vector<int> w;
    w.reserve(1000);                  // reserva espaço para 1000 elementos de uma vez
    std::cout << "w: tamanho " << w.size() << ", capacidade " << w.capacity() << '\n';
    return 0;
}

    No exemplo, a capacidade dobra a cada realocação, mas o fator de crescimento não é garantido. A biblioteca garante custo amortizado constante para push_back. Quando o número de elementos é conhecido, reserve(n) reserva espaço para pelo menos n elementos e evita realocações até esse limite. reserve muda a capacidade; resize muda o tamanho, criando ou destruindo elementos.

    #include <iostream>
#include <vector>

int main()
{
    int linhas, colunas;
    std::cin >> linhas >> colunas;

    std::vector<std::vector<int>> m(linhas, std::vector<int>(colunas));

    for (int i = 0; i < linhas; ++i) {
        for (int j = 0; j < colunas; ++j) {
            std::cin >> m[i][j];
        }
    }

    for (int j = 0; j < colunas; ++j) {        // soma de cada coluna
        int soma = 0;
        for (int i = 0; i < linhas; ++i) {
            soma += m[i][j];
        }
        std::cout << "Coluna " << j << ": " << soma << '\n';
    }

    std::vector<std::vector<int>> triangulo;   // linhas de tamanhos diferentes
    for (int i = 0; i < 4; ++i) {
        triangulo.push_back(std::vector<int>(i + 1, i));
    }
    for (const auto& linha : triangulo) {
        for (int x : linha) {
            std::cout << x << ' ';
        }
        std::cout << '\n';
    }
    return 0;
}

    #include <iostream>
#include <string>
#include <vector>

struct Aluno {
    std::string nome;
    double nota;
};

int main()
{
    std::vector<Aluno> turma;
    turma.push_back({"Ana", 8.5});
    turma.push_back(Aluno{"Bruno", 6.0});
    turma.emplace_back("Carla", 9.0);      // constrói o elemento diretamente no vetor

    double soma = 0;
    for (const Aluno& a : turma) {
        soma += a.nota;
    }
    std::cout << "Média da turma: " << soma / turma.size() << '\n';   // 7.83333
    std::cout << "Último: " << turma.back().nome << '\n';             // Carla
    return 0;
}

    push_back recebe um objeto pronto, que é copiado (ou movido) para dentro do vetor. emplace_back recebe os argumentos e constrói o objeto diretamente na memória do vetor, o que evita um objeto temporário.

    Partes de um vetor¶

    Um novo vetor pode ser criado a partir de um intervalo de outro, indicado por dois iteradores: o primeiro aponta para o primeiro elemento copiado, e o segundo para a posição depois do último. Os iteradores rbegin() e rend() percorrem o vetor de trás para frente.

    Quando a parte só precisa ser lida por uma função, não é preciso copiá-la: um std::span, do cabeçalho <span> (C++20), é uma "janela" sobre uma sequência contígua de elementos que pertence a outro contêiner, sem cópia. Uma função que recebe std::span<const int> aceita um vetor, um std::array, um arranjo nativo ou um pedaço de qualquer um deles:

    #include <iostream>
#include <span>
#include <vector>

int soma(std::span<const int> valores)
{
    int total = 0;
    for (int x : valores) {
        total += x;
    }
    return total;
}

int main()
{
    std::vector<int> v = {10, 20, 30, 40, 50, 60};

    std::vector<int> meio(v.begin() + 1, v.begin() + 4);   // cópia de v[1], v[2], v[3]
    std::vector<int> inicio(v.begin(), v.begin() + 2);     // primeiros 2
    std::vector<int> fim(v.end() - 2, v.end());            // últimos 2
    std::vector<int> invertido(v.rbegin(), v.rend());      // de trás para frente

    for (int x : meio) std::cout << x << ' ';
    std::cout << "| ";
    for (int x : inicio) std::cout << x << ' ';
    std::cout << "| ";
    for (int x : fim) std::cout << x << ' ';
    std::cout << "| ";
    for (int x : invertido) std::cout << x << ' ';
    std::cout << '\n';    // 20 30 40 | 10 20 | 50 60 | 60 50 40 30 20 10

    std::span<const int> janela(v);
    std::cout << soma(v) << ' ' << soma(janela.subspan(1, 3)) << ' ' << soma(janela.first(2)) << '\n';  // 210 90 30
    return 0;
}

    janela.subspan(1, 3) é a parte com 3 elementos a partir da posição 1; first(n) e last(n) são os n primeiros e os n últimos elementos.

    std::array¶

    O std::array, do cabeçalho <array>, já apresentado na seção de tipos de dados, é uma sequência de tamanho fixo, definido durante a compilação. Ele tem praticamente a mesma interface do std::vector para acesso e percurso ([], at, front, back, size, begin, end), mas não tem operações que mudam o tamanho, como push_back e erase. Em troca, não faz nenhuma alocação dinâmica: os elementos ficam dentro do próprio objeto.

int main()

    std::array<int, 7> chuva = {12, 0, 5, 30, 8, 0, 2};   // mm por dia da semana

    int total = 0;
    for (int mm : chuva) {
        total += mm;

    Use std::array quando o número de elementos for fixo e pequeno, como os dias da semana, as coordenadas de um ponto ou as casas de um tabuleiro.

    std::deque¶

    O std::deque (lê-se "deque", de double-ended queue, fila de duas pontas), do cabeçalho <deque>, é uma sequência que permite inserir e remover elementos de forma eficiente nas duas pontas, e não apenas no final. Ele também permite acesso pelo índice em tempo constante.

    #include <deque>
#include <iostream>

int main()
{
    std::deque<int> d = {3, 4};

    d.push_front(2);      // [2, 3, 4]
    d.push_front(1);      // [1, 2, 3, 4]
    d.push_back(5);       // [1, 2, 3, 4, 5]

    std::cout << d.front() << ' ' << d.back() << ' ' << d[2] << '\n';   // 1 5 3

    d.pop_front();        // [2, 3, 4, 5]
    d.pop_back();         // [2, 3, 4]

    for (int x : d) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    return 0;
}

    Com push_back e pop_front, um std::deque funciona como uma fila; com push_back e pop_back, como uma pilha. Quando só um desses comportamentos é necessário, os adaptadores std::queue e std::stack (apresentados na próxima página) deixam a intenção do código mais clara. O std::deque é a escolha certa quando o programa realmente precisa usar as duas pontas, como em uma "janela deslizante" que acompanha os últimos valores de uma sequência:

    #include <deque>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> temperaturas = {20, 22, 25, 23, 19, 18, 24};
    std::deque<int> janela;
    int soma = 0;

    for (int t : temperaturas) {
        janela.push_back(t);
        soma += t;
        if (janela.size() > 3) {          // mantém só os 3 últimos valores
            soma -= janela.front();
            janela.pop_front();
        }
        if (janela.size() == 3) {
            std::cout << "Média dos 3 últimos: " << soma / 3.0 << '\n';
        }
    }
    return 0;
}

    Diferentemente do std::vector, os elementos de um std::deque não ficam todos em um único bloco contíguo de memória, e sim em vários blocos menores. Por isso, ele é um pouco mais lento que o vetor para percorrer e acessar pelo índice, e não pode ser usado com std::span.

    std::list e std::forward_list¶

    O std::list, do cabeçalho <list>, é uma lista duplamente encadeada: cada elemento fica em um lugar diferente da memória e guarda ponteiros para o elemento anterior e para o próximo. Isso permite inserir e remover elementos em qualquer posição em tempo constante, desde que se tenha um iterador para aquela posição, sem deslocar nenhum outro elemento. O std::forward_list, do cabeçalho <forward_list>, é uma lista simplesmente encadeada, que só pode ser percorrida para a frente, mas usa menos memória.

    std::list<int> lista = {1, 2, 4, 5};

    auto it = lista.begin();
    ++it;
    ++it;                            // aponta para o 4
    lista.insert(it, 3);             // insere antes do 4, sem deslocar nada: [1, 2, 3, 4, 5]

    lista.remove(2);                 // remove todos os 2: [1, 3, 4, 5]
    lista.push_front(0);             // [0, 1, 3, 4, 5]

    for (int x : lista) {
        std::cout << x << ' ';
    }
    std::cout << '\n';
    return 0;
}

    Em compensação, listas não têm acesso pelo índice: para chegar ao décimo elemento, é preciso percorrer os nove anteriores. Além disso, como os elementos estão espalhados pela memória, percorrer uma lista é bem mais lento que percorrer um vetor. Na prática, listas encadeadas raramente são a melhor escolha; use-as apenas quando o programa fizer muitas inserções e remoções no meio da sequência, a partir de posições que já estão sendo percorridas.
