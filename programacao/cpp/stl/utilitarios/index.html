    Pares, tuplas e tipos utilitários¶

    Além dos contêineres, a biblioteca padrão tem tipos menores, mas muito usados, para agrupar valores, representar valores que podem não existir e gerar sequências de números. Eles aparecem o tempo todo junto com os contêineres: os elementos de um std::map são pares, uma função pode devolver vários valores em uma tupla, e uma busca que pode falhar pode devolver um std::optional.

    std::pair¶

    #include <algorithm>
#include <iostream>
#include <string>
#include <utility>
#include <vector>

int main()
{
    std::pair<std::string, int> aluno = {"Ana", 9};
    std::pair<double, double> ponto(1.5, -2.0);
    auto outro = std::make_pair(3, 'x');          // std::pair<int, char>

    std::cout << aluno.first << " tirou " << aluno.second << '\n';   // Ana tirou 9
    std::cout << '(' << ponto.first << ", " << ponto.second << ")\n";
    std::cout << outro.first << outro.second << '\n';                // 3x

    aluno.second = 10;
    std::cout << aluno.first << " agora tem " << aluno.second << '\n';

    std::vector<std::pair<int, int>> intervalos = {{5, 8}, {1, 4}, {5, 6}, {2, 9}};
    std::sort(intervalos.begin(), intervalos.end());   // por first; empate, por second
    for (const auto& [ini, fim] : intervalos) {
        std::cout << '[' << ini << ", " << fim << "] ";   // [1, 4] [2, 9] [5, 6] [5, 8]
    }
    std::cout << '\n';
    return 0;
}

    Pares podem ser comparados com ==, < e os demais operadores relacionais. A comparação é lexicográfica: primeiro compara-se o first; só em caso de empate o second é comparado. Por isso, ordenar um vetor de pares ordena pelo primeiro campo e desempata pelo segundo, como mostra o exemplo dos intervalos. Isso também permite usar pares diretamente como elementos de std::set, como chaves de std::map e como elementos de std::priority_queue.

    Pares são usados para representar coordenadas (x, y), intervalos (início, fim), arestas de grafos com peso (peso, vértice), associações (valor, nome) e, de forma geral, qualquer resultado com duas partes.

    Escolhendo a ordem dos campos

    Como a comparação começa pelo first, coloque no primeiro campo o critério principal de ordenação. Um truque comum para ordenar decrescentemente pelo primeiro campo e crescentemente pelo segundo, usando a ordenação padrão, é guardar o primeiro valor com o sinal trocado:

    // ordenar por nota decrescente e, no empate, por nome crescente
std::vector<std::pair<int, std::string>> resultado = {
    {-8, "Carla"}, {-10, "Bruno"}, {-8, "Ana"}, {-7, "Daniel"},
};
std::sort(resultado.begin(), resultado.end());
// Bruno 10, Ana 8, Carla 8, Daniel 7

    Para critérios mais complicados, porém, uma estrutura com nomes significativos e uma lambda de comparação deixam o código bem mais legível.

    std::tuple¶

    Uma std::tuple, do cabeçalho <tuple>, generaliza o par para qualquer número de valores. Como os elementos não têm nomes, eles são acessados pela posição, com std::get<i>(tupla), ou "desempacotados" com uma structured binding.     #include <algorithm>
#include <iostream>
#include <string>
#include <tuple>
#include <vector>

std::tuple<int, int, double> estatisticas(const std::vector<int>& v)
{
    int menor = *std::min_element(v.begin(), v.end());
    int maior = *std::max_element(v.begin(), v.end());
    double soma = 0;
    for (int x : v) soma += x;
    return {menor, maior, soma / v.size()};
}

int main()
{
    std::tuple<std::string, int, double> registro = {"Ana", 20, 1.65};
    std::cout << std::get<0>(registro) << ' ' << std::get<1>(registro) << ' '
              << std::get<2>(registro) << '\n';                        // Ana 20 1.65
    std::get<1>(registro) = 21;

    auto [nome, idade, altura] = registro;
    std::cout << nome << " tem " << idade << " anos e " << altura << " m\n";

    auto [menor, maior, media] = estatisticas({4, 8, 15, 16, 23, 42});
    std::cout << menor << ' ' << maior << ' ' << media << '\n';        // 4 42 18

    int a, b;
    double c;
    std::tie(a, b, c) = estatisticas({1, 2, 3});                       // em variáveis já existentes
    std::cout << a << ' ' << b << ' ' << c << '\n';                    // 1 3 2
    return 0;
}

    A função std::tie cria uma tupla de referências para variáveis já existentes, o que permite atribuir as partes de uma tupla a elas de uma só vez.

    Assim como os pares, as tuplas são comparadas lexicograficamente. Isso dá a std::tie um segundo uso muito prático: escrever critérios de comparação com vários campos em uma única linha.     #include <algorithm>
#include <iostream>
#include <string>
#include <tuple>
#include <vector>

struct Pais {
    std::string nome;
    int ouro;
    int prata;
    int bronze;
};

int main()
{
    std::vector<Pais> quadro = {
        {"Brasil", 3, 2, 5}, {"Chile", 3, 4, 1}, {"Peru", 1, 0, 2}, {"Uruguai", 3, 4, 2},
    };

    std::sort(quadro.begin(), quadro.end(), [](const Pais& a, const Pais& b) {
        return std::tie(b.ouro, b.prata, b.bronze) < std::tie(a.ouro, a.prata, a.bronze);
    });

    for (const auto& p : quadro) {
        std::cout << p.nome << ' ' << p.ouro << ' ' << p.prata << ' ' << p.bronze << '\n';
    }
    return 0;
}

    Tupla ou estrutura?

    Tuplas são práticas para agrupar valores temporariamente, como no retorno de uma função ou em um elemento de fila de prioridade. Mas std::get<2>(t) não diz nada sobre o que o valor significa. Quando o agrupamento for usado em vários lugares do programa, prefira uma estrutura com nomes significativos: aluno.nota é muito mais claro que std::get<2>(aluno).

    Structured bindings¶

    As structured bindings (algo como "ligações estruturadas") declaram, de uma só vez, uma variável para cada parte de um valor composto. Elas funcionam com pares, tuplas, estruturas com membros públicos e arranjos, e são especialmente úteis para percorrer mapas:

    #include <iostream>
#include <map>
#include <string>

struct Retangulo {
    double largura;
    double altura;
};

int main()
{
    Retangulo r{3.0, 4.5};
    auto [l, h] = r;                       // com estruturas
    std::cout << l * h << '\n';            // 13.5

    int coordenadas[2] = {10, 20};
    auto [x, y] = coordenadas;             // com arranjos
    std::cout << x + y << '\n';            // 30

    std::map<std::string, int> estoque = {{"caneta", 10}, {"lápis", 3}};
    for (auto& [item, quantidade] : estoque) {   // com referência: altera o mapa
        quantidade *= 2;
    }
    for (const auto& [item, quantidade] : estoque) {
        std::cout << item << ": " << quantidade << '\n';   // caneta: 20, lápis: 6
    }
    return 0;
}

    O número de nomes entre colchetes precisa ser igual ao número de partes do valor. As mesmas regras de cópia e referência do auto valem aqui: auto [a, b] copia as partes, auto& [a, b] permite alterá-las e const auto& [a, b] permite lê-las sem cópia.

    #include <iostream>
#include <string>
#include <utility>
#include <vector>

int main()
{
    int a = 1, b = 2;
    std::swap(a, b);
    std::cout << a << ' ' << b << '\n';            // 2 1

    std::vector<int> grande(1'000'000, 7);
    std::vector<int> pequeno = {1, 2, 3};
    std::swap(grande, pequeno);                     // troca instantânea, sem copiar elementos
    std::cout << grande.size() << ' ' << pequeno.size() << '\n';   // 3 1000000

    std::string s = "abc";
    std::swap(s[0], s[2]);
    std::cout << s << '\n';                         // cba
    return 0;
}

    Para contêineres, std::swap não copia os elementos: ela apenas troca os "ponteiros internos" dos dois contêineres, e por isso é instantânea, qualquer que seja o tamanho.

    std::optional¶

    Muitas funções nem sempre têm um resultado para devolver: uma busca pode não encontrar o elemento, uma conversão pode falhar, uma configuração pode não ter sido definida. Uma solução comum é devolver um valor "especial" (como \(-1\) para uma posição inexistente), mas isso é frágil: quem chama precisa saber qual é o valor especial, e às vezes nenhum valor serve.

    O tipo std::optional<T>, do cabeçalho <optional>, representa explicitamente "um valor do tipo T, ou nenhum valor". Uma função que devolve std::optional<int> deixa claro, na própria declaração, que o resultado pode não existir:

    #include <iostream>
#include <optional>
#include <string>
#include <vector>

std::optional<std::size_t> posicao_de(const std::vector<std::string>& nomes, const std::string& procurado)
{
    for (std::size_t i = 0; i < nomes.size(); ++i) {
        if (nomes[i] == procurado) {
            return i;
        }
    }
    return std::nullopt;                // "nenhum valor"
}

std::optional<int> converte(const std::string& texto)
{
    try {
        return std::stoi(texto);
    } catch (...) {
        return std::nullopt;
    }
}

int main()
{
    std::vector<std::string> nomes = {"Ana", "Bruno", "Carla"};

    if (auto pos = posicao_de(nomes, "Bruno")) {          // verdadeiro se tiver valor
        std::cout << "Bruno está na posição " << *pos << '\n';
    }

    auto pos = posicao_de(nomes, "Daniel");
    std::cout << std::boolalpha << pos.has_value() << '\n';           // false

    std::cout << converte("42").value_or(-1) << ' '
              << converte("abc").value_or(-1) << '\n';                 // 42 -1
    return 0;
}
    Operação Descrição
    return valor; Devolve um std::optional com valor
    return std::nullopt; Devolve um std::optional vazio
    if (opt), opt.has_value() Verdadeiro se houver valor
    *opt, opt->membro O valor (sem verificação: comportamento indefinido se estiver vazio)
    opt.value() O valor, com verificação (lança std::bad_optional_access se estiver vazio)
    opt.value_or(padrao) O valor, ou padrao se estiver vazio

    Valores de vários tipos: std::variant

    O tipo std::variant, do cabeçalho <variant>, representa um valor que pode ser de um entre vários tipos: um std::variant<int, double, std::string> guarda, a cada momento, um inteiro, um real ou uma cadeia. O tipo atual pode ser consultado com std::holds_alternative<T>(v) e o valor obtido com std::get<T>(v). É um recurso mais avançado, útil, por exemplo, para representar os elementos de uma expressão (números, operadores, parênteses) em uma calculadora.

    Sequências de números¶

    Para percorrer uma sequência de inteiros, o laço for tradicional continua sendo a forma mais flexível. A biblioteca padrão oferece duas alternativas:

    • A função std::iota, do cabeçalho <numeric>, preenche um contêiner com valores consecutivos a partir de um valor inicial, e;
    • A view std::views::iota(inicio, fim), do cabeçalho <ranges> (C++20), representa a sequência inicio, inicio + 1, ..., fim - 1 sem guardá-la na memória: os valores são gerados conforme o laço avança. Ela pode ser combinada com outras views, como std::views::filter e std::views::reverse, usando o operador |.

    #include <iostream>
#include <numeric>
#include <ranges>
#include <vector>

int main()
{
    std::vector<int> v(5);
    std::iota(v.begin(), v.end(), 1);              // preenche com 1, 2, 3, 4, 5
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    for (int i : std::views::iota(10, 15)) {       // 10, 11, 12, 13, 14
        std::cout << i << ' ';
    }
    std::cout << '\n';

    for (int i : std::views::iota(0, 20) | std::views::filter([](int n) { return n % 3 == 0; })) {
        std::cout << i << ' ';                     // múltiplos de 3: 0 3 6 9 12 15 18
    }
    std::cout << '\n';

    for (int i : std::views::iota(1, 6) | std::views::reverse) {
        std::cout << i << ' ';                     // 5 4 3 2 1
    }
    std::cout << '\n';

    for (int i = 10; i > 0; i -= 3) {              // passo qualquer: laço for
        std::cout << i << ' ';
    }
    std::cout << '\n';
    return 0;
}

    Assim como nos intervalos de iteradores, o valor final de std::views::iota não faz parte da sequência. As views são apresentadas com mais detalhes na página Iteradores e algoritmos.

    C++23

    O C++23 acrescentou std::views::stride(n), que pega um a cada n elementos de uma sequência: std::views::iota(0, 20) | std::views::stride(5) produz 0, 5, 10 e 15. Em C++20, o equivalente é o laço tradicional for (int i = 0; i < 20; i += 5).
