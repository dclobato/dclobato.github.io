    Conjuntos e mapas¶

    Os contêineres associativos organizam os elementos por valor, e não por posição. Em vez de perguntar "qual é o terceiro elemento?", perguntamos "este elemento está aqui?" ou "qual é o valor associado a esta chave?", e oferecem operações de busca eficientes. Um vetor ordenado também permite busca binária, com outras vantagens e custos.

    A biblioteca padrão oferece duas famílias de contêineres associativos:

    • Os ordenados (std::set, std::map, std::multiset e std::multimap) mantêm os elementos sempre em ordem. Suas implementações usuais usam árvores binárias de busca balanceadas, embora o padrão especifique os requisitos e as complexidades sem impor essa estrutura exata, e as operações de busca, inserção e remoção custam \(O(\log n)\);
    • Os não ordenados (std::unordered_set, std::unordered_map e suas versões multi) não mantêm nenhuma ordem. Eles são implementados como tabelas de dispersão (hash tables), e as mesmas operações custam \(O(1)\) em média.

    Conjuntos: std::set¶

    Um std::set, do cabeçalho <set>, é um conjunto de elementos únicos e ordenados. Inserir um elemento que já existe não tem efeito, e percorrer o conjunto produz os elementos sempre em ordem crescente, independentemente da ordem em que foram inseridos.

    #include <iostream>
#include <set>

int main()
{
    std::set<int> s = {5, 2, 8, 2, 5};      // repetidos são descartados

    s.insert(1);
    s.insert(8);                            // já existe: nada acontece

    for (int x : s) {
        std::cout << x << ' ';              // 1 2 5 8 (sempre em ordem)
    }
    std::cout << "\nTamanho: " << s.size() << '\n';   // 4

    std::cout << std::boolalpha;
    std::cout << s.contains(5) << ' ' << s.contains(7) << '\n';   // true false
    std::cout << s.count(2) << '\n';                              // 1

    s.erase(2);
    auto it = s.find(5);
    if (it != s.end()) {
        std::cout << "Achei o " << *it << '\n';
    }

    std::cout << "Menor: " << *s.begin() << ", maior: " << *s.rbegin() << '\n';   // 1, 8
    return 0;
}
    Operação Descrição Complexidade
    s.insert(x) Insere x, se ainda não existir \(O(\log n)\)
    s.erase(x) Remove x, se existir \(O(\log n)\)
    s.contains(x) Verdadeiro se x estiver no conjunto (C++20) \(O(\log n)\)
    s.count(x) Quantas vezes x aparece (0 ou 1, em um std::set) \(O(\log n)\)
    s.find(x) Iterador para x, ou s.end() se não existir \(O(\log n)\)
    s.lower_bound(x) Iterador para o primeiro elemento \(\geq x\) \(O(\log n)\)
    s.upper_bound(x) Iterador para o primeiro elemento \(> x\) \(O(\log n)\)
    *s.begin(), *s.rbegin() Menor e maior elementos (o conjunto não pode estar vazio) \(O(1)\)
    s.size(), s.empty() Número de elementos; se está vazio \(O(1)\)

#include <set>
#include <string>

int main()
{
    std::vector<std::string> palavras = {"sol", "lua", "sol", "mar", "lua"};

    for (const std::string& palavra : palavras) {

    Veja bem, preste atenção!

    Os elementos de um std::set não podem ser alterados diretamente: *it é constante. Alterar um elemento poderia tirá-lo da posição correta na ordem, quebrando a organização do conjunto. Para "alterar" um elemento, remova o valor antigo e insira o novo.

    #include <algorithm>
#include <iostream>
#include <set>
#include <vector>

int main()
{
    std::vector<int> v = {4, 1, 4, 2, 1, 3, 4};

    std::set<int> unicos(v.begin(), v.end());
    std::cout << "Distintos: " << unicos.size() << '\n';     // 4

    std::sort(w.begin(), w.end());

    std::cout << '\n';

}

    #include <functional>
#include <iostream>
#include <set>

int main()
{
    std::set<int> horarios = {800, 930, 1100, 1400, 1630};

    auto it = horarios.lower_bound(1000);       // primeiro >= 1000
    std::cout << "Próximo horário a partir de 1000: " << *it << '\n';   // 1100

    it = horarios.upper_bound(1400);            // primeiro > 1400
    std::cout << "Primeiro depois de 1400: " << *it << '\n';            // 1630

    if (horarios.lower_bound(1700) == horarios.end()) {
        std::cout << "Nenhum horário a partir de 1700\n";
    }

    std::set<int, std::greater<int>> decrescente = {3, 1, 4, 1, 5};
    for (int x : decrescente) std::cout << x << ' ';   // 5 4 3 1
    std::cout << '\n';
    return 0;
}

    #include <algorithm>
#include <iostream>
#include <iterator>
#include <set>

void mostra(const char* rotulo, const std::set<int>& s)
{
    std::cout << rotulo;
    for (int x : s) {
        std::cout << ' ' << x;
    }
    std::cout << '\n';
}

int main()
{
    std::set<int> a = {1, 2, 3, 4, 5};
    std::set<int> b = {4, 5, 6, 7};
    std::set<int> r;

    std::set_union(a.begin(), a.end(), b.begin(), b.end(), std::inserter(r, r.begin()));
    mostra("União:              ", r);

    r.clear();
    std::set_intersection(a.begin(), a.end(), b.begin(), b.end(), std::inserter(r, r.begin()));
    mostra("Interseção:         ", r);

    r.clear();
    std::set_difference(a.begin(), a.end(), b.begin(), b.end(), std::inserter(r, r.begin()));
    mostra("Diferença (a - b):  ", r);

    r.clear();
    std::set_symmetric_difference(a.begin(), a.end(), b.begin(), b.end(), std::inserter(r, r.begin()));
    mostra("Diferença simétrica:", r);

    std::set<int> c = {4, 5};
    std::cout << std::boolalpha << std::includes(a.begin(), a.end(), c.begin(), c.end()) << ' '
              << std::includes(a.begin(), a.end(), b.begin(), b.end()) << '\n';   // true false
    return 0;
}
    Saída
    União:               1 2 3 4 5 6 7
Interseção:          4 5
Diferença (a - b):   1 2 3
Diferença simétrica: 1 2 3 6 7
true false
    Algoritmo Resultado
    std::set_union Elementos que estão em a ou em b
    std::set_intersection Elementos que estão em a e em b
    std::set_difference Elementos que estão em a, mas não em b
    std::set_symmetric_difference Elementos que estão em apenas um dos dois
    std::includes Verifica se todos os elementos de b estão em a

    Todas essas operações custam \(O(|a| + |b|)\).

#include <map>
#include <string>

int main()
{
    std::map<std::string, int> idades = {
        {"Bruno", 25},
        {"Ana", 30},
    };

    idades["Carla"] = 22;           // insere uma nova chave
    idades["Ana"] = 31;             // altera o valor de uma chave existente

    std::cout << "Ana tem " << idades["Ana"] << " anos\n";
    std::cout << "Bruno tem " << idades.at("Bruno") << " anos\n";
    std::cout << "Pessoas: " << idades.size() << '\n';

    for (const auto& [nome, idade] : idades) {     // em ordem de chave
        std::cout << nome << ": " << idade << '\n';
    }

    idades.erase("Bruno");
    std::cout << std::boolalpha << idades.contains("Bruno") << '\n';   // false
    return 0;
}

    Cada elemento de um mapa é um par (std::pair) com a chave em first e o valor em second. No laço for, a structured binding auto [nome, idade] dá um nome a cada parte do par.

    Operação Descrição Complexidade
    m[k] Valor associado a k; se k não existir, cria a chave com um valor padrão \(O(\log n)\)
    m.at(k) Valor associado a k; lança std::out_of_range se k não existir \(O(\log n)\)
    m.contains(k) Verdadeiro se a chave k existir (C++20) \(O(\log n)\)
    m.count(k) Quantas vezes a chave aparece (0 ou 1) \(O(\log n)\)
    m.find(k) Iterador para o par com chave k, ou m.end() \(O(\log n)\)
    m.insert({k, v}) Insere o par, se a chave ainda não existir \(O(\log n)\)
    m.insert_or_assign(k, v) Insere o par, ou altera o valor se a chave já existir \(O(\log n)\)
    m.try_emplace(k, v) Insere o par apenas se a chave ainda não existir \(O(\log n)\)
    m.erase(k) Remove o par com chave k \(O(\log n)\)
    m.lower_bound(k), m.upper_bound(k) Como em std::set, comparando as chaves \(O(\log n)\)

    Veja bem, preste atenção!

    O operador [] de um mapa cria a chave se ela não existir, com o valor padrão do tipo (zero para números, cadeia vazia para std::string). Isso é conveniente para contar e acumular, mas é uma armadilha quando a intenção é apenas consultar:

    std::map<std::string, int> estoque = {{"caneta", 10}};

std::cout << estoque["lapis"] << '\n';   // 0: e "lapis" foi CRIADO no mapa!
std::cout << estoque.size() << '\n';     // 2

    Para consultar sem alterar o mapa, use contains() antes, at() (que lança uma exceção se a chave não existir) ou find() (que devolve end()). Pelo mesmo motivo, [] não pode ser usado em um mapa constante, como um mapa recebido por const std::map<...>&.

    if (auto it = estoque.find("caneta"); it != estoque.end()) {
    std::cout << it->first << ": " << it->second << '\n';   // caneta: 10
}

    #include <iostream>
#include <map>
#include <string>

int main()
{
    std::map<std::string, double> precos;

    precos.insert({"pão", 0.75});
    auto [it, inseriu] = precos.insert({"pão", 0.99});           // já existe: não altera
    std::cout << it->second << ' ' << std::boolalpha << inseriu << '\n';   // 0.75 false

    precos.try_emplace("leite", 9.99);
    std::cout << precos["leite"] << '\n';                        // 5.49
    return 0;
}

    Contêineres não ordenados¶

    std::unordered_set (cabeçalho <unordered_set>) e std::unordered_map (cabeçalho <unordered_map>) têm praticamente a mesma interface de std::set e std::map, mas são implementados como tabelas de dispersão: uma função de dispersão (hash) transforma cada elemento em um número, que indica em qual "gaveta" de um grande arranjo ele deve ficar. Encontrar um elemento exige apenas calcular a função e olhar a gaveta correspondente, o que custa \(O(1)\) em média.

#include <string>
#include <unordered_map>
#include <unordered_set>

int main()
{
    std::unordered_set<int> vistos;
    for (int x : {7, 3, 7, 1, 3, 9}) {
        if (vistos.contains(x)) {
            std::cout << x << " já apareceu\n";
        }
        vistos.insert(x);

    std::unordered_map<std::string, std::string> capitais = {
        {"SP", "São Paulo"}, {"RJ", "Rio de Janeiro"}, {"MG", "Belo Horizonte"},
    };
    capitais["BA"] = "Salvador";
    std::cout << capitais["MG"] << ' ' << capitais.size() << '\n';   // Belo Horizonte 4

        std::cout << uf << ' ';

    std::cout << '\n';
    return 0;
}

    #include <iostream>
#include <unordered_map>
#include <vector>

int main()
{
    std::vector<int> v = {8, 3, 11, 5, 14, 7};
    int alvo = 19;

    std::unordered_map<int, int> posicao;   // valor -> índice onde apareceu
    for (int i = 0; i < static_cast<int>(v.size()); ++i) {
        int falta = alvo - v[i];
        if (auto it = posicao.find(falta); it != posicao.end()) {
            std::cout << v[it->second] << " + " << v[i] << " = " << alvo
                      << " (posições " << it->second << " e " << i << ")\n";
        }
        posicao[v[i]] = i;
    }
    return 0;
}
    Saída
    8 + 11 = 19 (posições 0 e 2)
5 + 14 = 19 (posições 3 e 4)

    Veja bem, preste atenção!

    • A ordem em que os elementos de um contêiner não ordenado são percorridos não é definida: ela pode mudar de um compilador para outro, e até quando novos elementos são inseridos. Se a saída do programa depender da ordem, use um contêiner ordenado, ou copie os elementos para um vetor e ordene;
    • O custo \(O(1)\) é médio. Se muitos elementos caírem na mesma "gaveta", o desempenho pode se degradar até \(O(n)\) por operação. Isso é raro com dados comuns, mas pode acontecer com entradas construídas de propósito para isso;
    • Os contêineres não ordenados não têm lower_bound, upper_bound, begin() como "menor elemento" nem nenhuma outra operação que dependa de ordem.

    Ordenado ou não ordenado?¶

    Característica std::set / std::map std::unordered_set / std::unordered_map
    Implementação Árvore de busca balanceada Tabela de dispersão
    Busca, inserção e remoção \(O(\log n)\) \(O(1)\) em média, \(O(n)\) no pior caso
    Ordem dos elementos Sempre crescente (ou pelo critério escolhido) Indefinida
    Menor e maior elementos, lower_bound Sim Não
    Exigência sobre o tipo do elemento (ou da chave) Comparação com < Função de dispersão e comparação com ==

    Na dúvida, comece com std::set e std::map: o desempenho é muito bom e previsível, e a ordem costuma ser útil. Troque para as versões não ordenadas quando a ordem não importar e o desempenho for crítico.

    #include <iostream>
#include <map>
#include <set>
#include <string>

int main()
{
    std::multiset<int> notas = {7, 5, 7, 9, 7};
    std::cout << "Quantos 7: " << notas.count(7) << '\n';      // 3
    notas.erase(notas.find(7));                                // remove UM 7
    std::cout << "Quantos 7: " << notas.count(7) << '\n';      // 2
    notas.erase(7);                                            // remove TODOS os 7
    std::cout << "Tamanho: " << notas.size() << '\n';          // 2

    std::multimap<std::string, std::string> telefones = {
        {"Ana", "1111-1111"}, {"Bruno", "2222-2222"}, {"Ana", "3333-3333"},
    };
    auto [ini, fim] = telefones.equal_range("Ana");
    for (auto it = ini; it != fim; ++it) {
        std::cout << it->first << ": " << it->second << '\n';
    }
    return 0;
}

    Veja bem, preste atenção!

    Em um std::multiset, erase(x) remove todas as ocorrências de x. Para remover apenas uma, passe um iterador: s.erase(s.find(x)) (verificando antes se find não devolveu end()).

    Um std::multiset é útil para manter uma coleção ordenada com repetições na qual elementos entram e saem, como as notas de uma turma, das quais se quer saber a cada momento a menor e a maior. O método equal_range(k) devolve o par de iteradores que delimita todos os elementos com a chave k. Um std::multimap não tem o operador [], já que uma chave pode estar associada a vários valores.

    #include <compare>
#include <iostream>
#include <map>
#include <set>

struct Ponto {
    int x;
    int y;
    auto operator<=>(const Ponto&) const = default;
};

int main()
{
    std::set<Ponto> visitados = {{1, 2}, {0, 0}, {1, 2}, {-1, 5}};
    std::cout << visitados.size() << '\n';     // 3

    std::map<Ponto, char> tabuleiro;
    tabuleiro[{0, 0}] = 'X';
    tabuleiro[{1, 1}] = 'O';
    for (const auto& [p, c] : tabuleiro) {
        std::cout << '(' << p.x << ',' << p.y << ") = " << c << '\n';
    }
    return 0;
}

    Pares (std::pair) e tuplas (std::tuple) já podem ser comparados com <, e por isso funcionam diretamente como elementos e chaves de contêineres ordenados: std::set<std::pair<int, int>> é uma forma muito comum de guardar coordenadas.

    Tipos próprios em contêineres não ordenados

    Os contêineres não ordenados exigem, além da comparação com ==, uma função de dispersão para o tipo. A biblioteca padrão fornece funções de dispersão para os tipos básicos e para std::string, mas não para std::pair, std::tuple ou estruturas: std::unordered_set<std::pair<int, int>> não compila. Para esses casos, é preciso escrever um objeto função de dispersão e passá-lo como parâmetro do template:

    struct Ponto {
    int x;
    int y;
    bool operator==(const Ponto&) const = default;
};

struct HashPonto {
    std::size_t operator()(const Ponto& p) const
    {
        return std::hash<long long>{}((static_cast<long long>(p.x) << 32) ^ static_cast<unsigned>(p.y));
    }
};

std::unordered_set<Ponto, HashPonto> visitados;

    Na maioria das vezes, é mais simples usar a versão ordenada (std::set<Ponto>), que só precisa da comparação.
