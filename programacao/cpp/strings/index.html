    Cadeias de caracteres¶

    Textos estão em toda parte nos programas: nomes, mensagens, linhas lidas de arquivos, comandos digitados pelo usuário. Em C++, textos são representados pelo tipo std::string, do cabeçalho <string>. Uma std::string é uma sequência de caracteres (char) que cresce e diminui automaticamente conforme necessário, e que oferece dezenas de operações prontas para busca, extração e modificação de texto.

    #include <iostream>
#include <string>

int main()
{
    std::string vazia;                  // cadeia vazia: ""
    std::string nome = "Programação";
    std::string linha(10, '-');         // "----------"
    std::string copia = nome;           // cópia independente

    std::string saudacao = "Olá, " + std::string("mundo") + "!";
    saudacao += " Tudo bem?";

    std::cout << '[' << vazia << "] " << vazia.empty() << '\n';   // [] 1
    std::cout << linha << '\n';                                   // ----------
    std::cout << saudacao << '\n';                                // Olá, mundo! Tudo bem?
    std::cout << "Tamanho: " << saudacao.size() << '\n';          // Tamanho: 22

    copia[0] = 'p';
    std::cout << nome << " / " << copia << '\n';                  // Programação / programação
    std::cout << "Primeiro: " << nome.front() << ", último: " << nome.back() << '\n';  // P, o
    return 0;
}

    O exemplo mostra as operações mais comuns:

    • Uma std::string declarada sem valor começa vazia. O método empty() informa se ela está vazia, e size() (ou o sinônimo length()) informa quantos caracteres ela tem;
    • std::string linha(10, '-') cria uma cadeia com 10 cópias do caractere '-';
    • A atribuição com = faz uma cópia completa: alterar copia não altera nome;
    • O operador + concatena (junta) cadeias, e += acrescenta texto ao final de uma cadeia existente;
    • Os caracteres são acessados por índice com colchetes, começando em 0, e os métodos front() e back() devolvem o primeiro e o último caractere.

    Veja bem, preste atenção!

    Um texto entre aspas no código (um literal) não é uma std::string, e sim um arranjo de caracteres constantes. Por isso, dois literais não podem ser concatenados com +:

    Incorreto

    std::string s = "Olá, " + "mundo";  // erro de compilação

    Correto

    std::string s = std::string("Olá, ") + "mundo";

    Basta que um dos dois operandos de + seja uma std::string para que a concatenação funcione. No exemplo anterior, "Olá, " + std::string("mundo") + "!" funciona porque a conta é feita da esquerda para a direita, e o resultado de cada + já é uma std::string.

    Veja bem, preste atenção!

    O acesso com colchetes (s[i]) não verifica se o índice é válido: acessar uma posição fora da cadeia tem comportamento indefinido. O método at(i) verifica o índice e lança uma exceção do tipo std::out_of_range se ele for inválido. Chamar front(), back() ou pop_back() em uma cadeia vazia também tem comportamento indefinido.

    Comparação¶

    Cadeias podem ser comparadas diretamente com os operadores relacionais (==, !=, <, <=, >, >=). A comparação é feita caractere a caractere, pelo código numérico de cada caractere, em ordem lexicográfica (a ordem do dicionário):

    #include <iostream>
#include <string>

int main()
{
    std::string a = "banana";
    std::string b = "maçã";
    std::string c = "Banana";

    std::cout << std::boolalpha;
    std::cout << (a == "banana") << '\n';   // true
    std::cout << (a < b) << '\n';           // true: 'b' vem antes de 'm'
    std::cout << (c < a) << '\n';           // true: 'B' (66) vem antes de 'b' (98)
    std::cout << a.compare(b) << '\n';      // negativo: a vem antes de b
    return 0;
}

    O método compare() faz a comparação de uma só vez e devolve um número negativo se a cadeia vier antes do argumento, zero se forem iguais, e um número positivo se vier depois.

    Veja bem, preste atenção!

    Como a comparação usa os códigos numéricos dos caracteres, todas as letras maiúsculas vêm antes de todas as minúsculas: "Zebra" < "abacate" é verdadeiro. Para comparar sem diferenciar maiúsculas de minúsculas, converta as duas cadeias para minúsculas (veja a seção Percorrendo os caracteres) antes de compará-las.

    Letras acentuadas também não ficam na posição esperada pela ordem alfabética do português, porque seus códigos são maiores que os de todas as letras sem acento.

    Busca e extração¶

    O método find() procura um texto (ou um caractere) dentro da cadeia e devolve a posição da primeira ocorrência. Se o texto não for encontrado, find() devolve o valor especial std::string::npos. O método rfind() faz o mesmo, mas procura a última ocorrência. Já o método substr(pos, n) devolve uma nova cadeia com n caracteres a partir da posição pos (ou até o fim, se n for omitido).

    #include <iostream>
#include <string>

int main()
{
    std::string frase = "O rato roeu a roupa do rei de Roma";

    std::cout << frase.find("ro") << '\n';        // 7: primeira ocorrência
    std::cout << frase.find("ro", 8) << '\n';     // 14: procura a partir da posição 8
    std::cout << frase.rfind("ro") << '\n';       // 14: última ocorrência ("Roma" tem R maiúsculo)

    if (frase.find("rei") != std::string::npos) {
        std::cout << "Encontrei o rei!\n";
    }

    std::cout << frase.substr(2, 4) << '\n';      // "rato"
    std::cout << frase.substr(30) << '\n';        // "Roma": da posição 30 até o fim

    std::cout << std::boolalpha << frase.starts_with("O rato") << ' '
              << frase.ends_with("Roma") << '\n'; // true true
    return 0;
}

    Veja bem, preste atenção!

    O valor std::string::npos é o maior número que cabe no tipo std::size_t (em máquinas de 64 bits, 18446744073709551615). Se você esquecer de verificar o resultado de find() e usá-lo diretamente como posição, o programa vai se comportar de forma estranha. Sempre compare o resultado de find() com std::string::npos antes de usá-lo.

    Os métodos starts_with() e ends_with(), disponíveis a partir do C++20, verificam se a cadeia começa ou termina com determinado texto.

    C++23

    O C++23 acrescentou o método contains(), que verifica se a cadeia contém um texto ou caractere: frase.contains("rei") resulta em true. Em C++20, o equivalente é frase.find("rei") != std::string::npos.

    #include <iostream>
#include <string>

int main()
{
    std::string s = "Linguagem C";

    s.push_back('+');              // "Linguagem C+"
    s += '+';                      // "Linguagem C++"
    std::cout << s << '\n';

    s.insert(0, "A ");             // "A Linguagem C++"
    std::cout << s << '\n';

    s.replace(2, 9, "linguagem");  // troca 9 caracteres a partir da posição 2
    std::cout << s << '\n';        // "A linguagem C++"

    s.erase(0, 2);                 // remove 2 caracteres a partir da posição 0
    std::cout << s << '\n';        // "linguagem C++"

    s.pop_back();                  // remove o último caractere
    std::cout << s << '\n';        // "linguagem C+"

    s.clear();                     // esvazia a cadeia
    std::cout << '[' << s << "] " << s.size() << '\n';   // [] 0
    return 0;
}
    Método Efeito
    s.push_back(c) Acrescenta o caractere c ao final
    s.pop_back() Remove o último caractere
    s.insert(pos, t) Insere o texto t antes da posição pos
    s.erase(pos, n) Remove n caracteres a partir da posição pos (até o fim, se n for omitido)
    s.replace(pos, n, t) Substitui n caracteres a partir da posição pos pelo texto t
    s.clear() Remove todos os caracteres

    Percorrendo os caracteres¶

    #include <algorithm>
#include <cctype>
#include <iostream>
#include <string>

int main()
{
    std::string texto = "Ola, Mundo! 2026";

    int vogais = 0;
    int digitos = 0;
    for (char c : texto) {
        char m = std::tolower(static_cast<unsigned char>(c));
        if (m == 'a' || m == 'e' || m == 'i' || m == 'o' || m == 'u') {
            ++vogais;
        }
        if (std::isdigit(static_cast<unsigned char>(c))) {
            ++digitos;
        }
    }
    std::cout << "Vogais: " << vogais << ", dígitos: " << digitos << '\n';  // 4 e 4

    for (char& c : texto) {        // referência: altera os caracteres da cadeia
        c = std::toupper(static_cast<unsigned char>(c));
    }
    std::cout << texto << '\n';    // OLA, MUNDO! 2026

    std::string invertido = texto;
    std::reverse(invertido.begin(), invertido.end());
    std::cout << invertido << '\n';  // 6202 !ODNUM ,ALO

    for (std::size_t i = 0; i < texto.size(); i += 2) {   // caracteres nas posições pares
        std::cout << texto[i];
    }
    std::cout << '\n';             // OA UD!22
    return 0;
}

    Veja bem, preste atenção!

    As funções de <cctype> só funcionam corretamente com valores que cabem em um unsigned char (ou com o valor especial de fim de arquivo). Como char pode ter sinal, caracteres acentuados podem ter valores negativos, e passá-los diretamente para essas funções tem comportamento indefinido. Por isso, o exemplo converte cada caractere com static_cast<unsigned char>(c) antes de chamar as funções.

    O laço que converte para maiúsculas usa uma referência (char& c), para que cada caractere da cadeia seja alterado. A função std::reverse, do cabeçalho <algorithm>, inverte a ordem dos caracteres; ela funciona com qualquer sequência, e faz parte dos algoritmos da biblioteca padrão.

    Caracteres são números¶

    Cada caractere é guardado como um número (o seu código na tabela ASCII), e as letras e os dígitos têm códigos consecutivos. Isso permite fazer contas com caracteres, um truque muito usado:

    std::string numero = "2026";
int soma = 0;
for (char c : numero) {
    soma += c - '0';            // '7' - '0' é 7: converte o dígito no seu valor
}
// soma == 10

char letra = 'c';
int posicao = letra - 'a';      // 2: 'a' é 0, 'b' é 1, 'c' é 2...
char proxima = letra + 1;       // 'd'

    #include <iostream>
#include <stdexcept>
#include <string>

int main()
{
    int idade = std::stoi("42");
    double preco = std::stod("19.90");
    long long grande = std::stoll("9000000000");

    std::string texto = "Idade: " + std::to_string(idade);
    std::cout << texto << ' ' << preco * 2 << ' ' << grande << '\n';  // Idade: 42 39.8 9000000000

    std::cout << std::stoi("123abc") << '\n';   // 123: lê até onde conseguir

    try {
        int x = std::stoi("abc");
        std::cout << x << '\n';
    } catch (const std::invalid_argument& e) {
        std::cout << "Não é um número!\n";
    }

    try {
        int y = std::stoi("99999999999");
        std::cout << y << '\n';
    } catch (const std::out_of_range& e) {
        std::cout << "Número grande demais para um int!\n";
    }
    return 0;
}

    As funções de conversão ignoram espaços no início e leem o número até encontrar um caractere que não faz parte dele: std::stoi("123abc") resulta em 123. Se não houver número nenhum no início da cadeia, elas lançam uma exceção do tipo std::invalid_argument; se o número não couber no tipo, lançam uma exceção do tipo std::out_of_range. O tratamento de exceções com try e catch é apresentado na seção de controle de fluxo.

    #include <iostream>
#include <sstream>
#include <string>
#include <vector>

int main()
{
    std::string linha = "  maratona   de   programação  ";

    std::istringstream fluxo(linha);
    std::vector<std::string> palavras;
    std::string palavra;
    while (fluxo >> palavra) {           // lê palavra por palavra, ignorando espaços
        palavras.push_back(palavra);
    }
    std::cout << palavras.size() << " palavras\n";   // 3 palavras

    std::string csv = "Ana;8.5;Recife";
    std::istringstream campos(csv);
    std::string campo;
    while (std::getline(campos, campo, ';')) {   // separa pelo caractere ';'
        std::cout << '[' << campo << "] ";       // [Ana] [8.5] [Recife]
    }
    std::cout << '\n';

    std::string juntas;
    for (std::size_t i = 0; i < palavras.size(); ++i) {
        if (i > 0) {
            juntas += ", ";
        }
        juntas += palavras[i];
    }
    std::cout << juntas << '\n';         // maratona, de, programação
    return 0;
}

    O operador >> lê uma palavra de cada vez, pulando todos os espaços, tabulações e quebras de linha; quando não há mais palavras, a condição do while se torna falsa. Já std::getline(fluxo, campo, ';') lê tudo até o próximo ;, o que permite separar campos que contêm espaços. As palavras são guardadas em um std::vector<std::string>, uma sequência de cadeias que cresce conforme novos elementos são acrescentados com push_back() (o std::vector é apresentado em detalhes na seção sobre a biblioteca padrão).

    Para juntar as partes com um separador, o laço acrescenta o separador antes de cada palavra, exceto a primeira.

    O ponteiro retornado por c_str() depende do tempo de vida e do armazenamento da cadeia: sua destruição ou operações que realoquem os caracteres podem invalidá-lo. Não guarde esse ponteiro para usar depois dessas mudanças.

    Ao usar std::string_view, lembre-se de que ela não possui os caracteres e não prolonga o tempo de vida da origem; destruir a cadeia ou realocar seus caracteres pode deixá-la pendente. Ela também não garante um terminador nulo no fim de seu trecho.

    Cadeias de caracteres no estilo antigo¶

    Em códigos mais antigos e em algumas bibliotecas, textos aparecem como arranjos de caracteres terminados pelo caractere nulo ('\0'), manipulados por meio de ponteiros do tipo const char*. Um literal comum entre aspas tem tipo arranjo de const char, incluindo o terminador nulo; na maioria das expressões, ele decai para const char*. A construção de uma std::string a partir desses caracteres copia o texto, e o método c_str() faz o caminho inverso, quando uma função exige um const char*:

int main()

    std::string moderna = antiga;        // conversão para std::string
    const char* de_volta = moderna.c_str();

    Veja bem, preste atenção!

    Arranjos de caracteres não se comportam como std::string: não podem ser atribuídos com =, e o operador == compara os endereços de memória onde os arranjos estão, e não o conteúdo. Para manipulá-los, é preciso usar as funções do cabeçalho <cstring> (std::strcpy, std::strcmp, std::strlen...), sempre com cuidado com o tamanho dos arranjos. Em código novo, use sempre std::string, e converta para const char* apenas quando alguma função exigir.

    Visões de cadeias (std::string_view)

    O tipo std::string_view, do cabeçalho <string_view>, representa uma "janela" somente leitura sobre uma sequência de caracteres que pertence a outra variável, sem fazer cópia. Ele é útil como parâmetro de funções que apenas leem um texto, porque aceita tanto uma std::string quanto um literal sem nenhuma conversão:

    bool comeca_com_maiuscula(std::string_view s)
{
    return !s.empty() && s[0] >= 'A' && s[0] <= 'Z';
}

    O cuidado é que a cadeia original precisa continuar existindo enquanto a visão for usada.

    Acentos e o tamanho das cadeias¶

    Os programas deste texto usam a codificação UTF-8, a mais comum atualmente. Nela, os caracteres da tabela ASCII ocupam um byte cada, mas letras acentuadas e outros símbolos ocupam dois bytes ou mais. Como uma std::string é uma sequência de bytes, os métodos size() e length() contam bytes, e não letras:

    std::string a = "cafe";
std::string b = "café";
std::cout << a.size() << ' ' << b.size() << '\n';   // 4 5

    Pelo mesmo motivo, b[3] não é a letra é, e sim apenas o primeiro dos dois bytes que a representam, e inverter uma cadeia com acentos byte a byte produz um texto inválido. Para a maioria dos problemas (e em praticamente todos os problemas de competições de programação, que usam apenas caracteres ASCII), isso não faz diferença. Programas que precisam contar ou manipular letras acentuadas corretamente exigem bibliotecas especializadas.
