    Estruturas de dados¶

    Muitos problemas ficam mais simples (e mais rápidos) quando os dados estão organizados da forma certa: uma pilha para verificar parênteses, uma fila para simular um atendimento, uma fila de prioridade para sempre pegar o menor elemento. A biblioteca padrão de C não traz essas estruturas prontas: ela oferece os arranjos, a alocação dinâmica de memória (malloc, realloc, free), e as funções qsort e bsearch para ordenar e buscar. As estruturas de dados são construídas a partir desses recursos.

    Esta página mostra como implementar as estruturas mais usadas, cada uma como uma struct acompanhada de um pequeno conjunto de funções que a manipulam. As implementações usam ponteiros e alocação dinâmica e a passagem de parâmetros por endereço, e a eficiência de cada operação é descrita com a notação O.

    Arranjos com tamanho fixo ou dinâmico?

    Em programação competitiva, o tamanho máximo da entrada é informado no enunciado, e as estruturas costumam ser implementadas sobre arranjos com tamanho fixo (declarados como globais ou static, se forem grandes), o que é mais simples e mais rápido. Em programas em que o tamanho não é conhecido, o arranjo precisa crescer conforme a necessidade, como no vetor dinâmico apresentado a seguir. As implementações desta página usam as duas formas.

    #include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    int *dados;
    size_t tamanho;
    size_t capacidade;
} Vetor;

void vetor_inicia(Vetor *v)
{
    v->dados = NULL;
    v->tamanho = 0;
    v->capacidade = 0;
}

// Devolve 0 se faltar memória ou a capacidade não puder ser representada.
int vetor_adiciona(Vetor *v, int x)
{
    if (v->tamanho == v->capacidade) {
        if (v->capacidade > SIZE_MAX / 2) {
            return 0;
        }
        size_t nova = (v->capacidade == 0) ? 4 : 2 * v->capacidade;
        if (nova > SIZE_MAX / sizeof *v->dados) {
            return 0;
        }
        int *p = realloc(v->dados, nova * sizeof *p);
        if (p == NULL) {
            return 0;
        }
        v->dados = p;
        v->capacidade = nova;
    }
    v->dados[v->tamanho++] = x;
    return 1;
}

void vetor_libera(Vetor *v)
{
    free(v->dados);
    vetor_inicia(v);
}

int main(void)
{
    Vetor v;
    vetor_inicia(&v);

    int x;
    while (scanf("%d", &x) == 1) {
        if (!vetor_adiciona(&v, x)) {
            fprintf(stderr, "não foi possível ampliar o vetor\n");
            vetor_libera(&v);
            return 1;
        }
    }
    printf("%zu valores (capacidade %zu):", v.tamanho, v.capacidade);
    for (size_t i = 0; i < v.tamanho; i++) {
        printf(" %d", v.dados[i]);
    }
    printf("\n");
    vetor_libera(&v);
    return 0;
}

    9 valores (capacidade 16): 3 1 4 1 5 9 2 6 5

    Como a capacidade dobra a cada realocação, acrescentar um elemento ao final custa \(O(1)\) amortizado: a maior parte das inserções não realoca nada, e as poucas que realocam são compensadas por elas. O acesso a qualquer posição é \(O(1)\), como em um arranjo comum. Repare que todas as funções recebem o endereço do vetor, porque precisam alterar os seus campos.

    Pilha¶

    Uma pilha (stack) é uma sequência em que os elementos são inseridos e removidos sempre na mesma ponta, o topo: o último elemento a entrar é o primeiro a sair (LIFO, de last in, first out), como em uma pilha de pratos. As operações básicas são empilhar (push), desempilhar (pop) e consultar o topo, todas \(O(1)\).

    Uma pilha pode ser implementada com um arranjo e um contador: os elementos ocupam as posições de 0 a topo - 1, e o topo da pilha é o último deles. O exemplo abaixo usa uma pilha para verificar se os parênteses, colchetes e chaves de uma expressão estão balanceados: cada símbolo de abertura é empilhado, e cada símbolo de fechamento precisa corresponder ao que está no topo:

    #include <stdio.h>
#include <string.h>

#define MAX 1000

typedef struct {
    char dados[MAX];
    int topo;                       // quantidade de elementos
} Pilha;

void pilha_inicia(Pilha *p)        { p->topo = 0; }
int  pilha_vazia(const Pilha *p)   { return p->topo == 0; }
int  pilha_cheia(const Pilha *p)   { return p->topo == MAX; }
void empilha(Pilha *p, char c)     { p->dados[p->topo++] = c; }
char desempilha(Pilha *p)          { return p->dados[--p->topo]; }
char topo(const Pilha *p)          { return p->dados[p->topo - 1]; }

int balanceada(const char *s)
{
    Pilha p;
    pilha_inicia(&p);
    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            if (pilha_cheia(&p)) {
                return 0;
            }
            empilha(&p, c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (pilha_vazia(&p)) {
                return 0;                     // fecha algo que não foi aberto
            }
            char aberto = desempilha(&p);
            if ((c == ')' && aberto != '(') || (c == ']' && aberto != '[') ||
                (c == '}' && aberto != '{')) {
                return 0;                     // fecha com o símbolo errado
            }
        }
    }
    return pilha_vazia(&p);                   // sobrou algo aberto?
}

int main(void)
{
    char linha[MAX + 2];
    while (fgets(linha, sizeof(linha), stdin) != NULL) {
        linha[strcspn(linha, "\n")] = '\0';
        printf("%-16s %s\n", linha, balanceada(linha) ? "correta" : "incorreta");
    }
    return 0;
}

Pilhas também aparecem na avaliação de expressões, no desfazer de editores de texto e na própria execução de funções: a pilha de execução guarda as variáveis locais de cada chamada.

    Fila¶

    Uma fila (queue) é uma sequência em que os elementos são inseridos em uma ponta (o fim) e removidos da outra (o início): o primeiro a entrar é o primeiro a sair (FIFO, de first in, first out), como em uma fila de banco.

    Implementar uma fila com um arranjo exige um cuidado: se os elementos removidos deixassem posições livres no início, a fila "andaria" para a direita até o fim do arranjo. A solução é a fila circular: quando o fim chega à última posição, ele volta para a posição 0, ocupando as posições liberadas. O resto da divisão (%) faz essa volta. Com isso, enfileirar e desenfileirar são \(O(1)\).

    O exemplo simula o problema clássico "jogando cartas fora": há uma pilha de cartas numeradas de 1 a n, com a carta 1 no topo. Enquanto houver pelo menos duas cartas, a carta do topo é descartada e a carta seguinte é movida para o fundo. O programa mostra as cartas descartadas e a que sobra:

    #include <stdio.h>

#define MAX 100

typedef struct {
    int dados[MAX];
    int inicio;                     // posição do primeiro elemento
    int tamanho;                    // quantidade de elementos
} Fila;

void fila_inicia(Fila *f)          { f->inicio = 0; f->tamanho = 0; }
int  fila_vazia(const Fila *f)     { return f->tamanho == 0; }

void enfileira(Fila *f, int x)
{
    int fim = (f->inicio + f->tamanho) % MAX;   // dá a volta no final do arranjo
    f->dados[fim] = x;
    f->tamanho++;
}

int desenfileira(Fila *f)
{
    int x = f->dados[f->inicio];
    f->inicio = (f->inicio + 1) % MAX;
    f->tamanho--;
    return x;
}

int main(void)
{
    int n;
    while (scanf("%d", &n) == 1 && n != 0) {
        Fila f;
        fila_inicia(&f);
        for (int carta = 1; carta <= n; carta++) {
            enfileira(&f, carta);
        }

        printf("Descartadas:");
        int primeira = 1;
        while (f.tamanho > 1) {
            printf("%s %d", primeira ? "" : ",", desenfileira(&f));   // joga fora a do topo
            primeira = 0;
            enfileira(&f, desenfileira(&f));                         // a seguinte vai para o fim
        }
        printf("\nCarta restante: %d\n", desenfileira(&f));
    }
    return 0;
}

    Lista encadeada¶

    Em uma lista encadeada, cada elemento fica em um nó alocado separadamente, que guarda o valor e o endereço do nó seguinte. O último nó aponta para NULL, e a lista é representada pelo endereço do primeiro nó (uma lista vazia é simplesmente NULL). Os nós não ficam em posições consecutivas da memória: a ordem é dada pelos ponteiros.

    #include <stdio.h>
#include <stdlib.h>

typedef struct No {
    int valor;
    struct No *proximo;
} No;

// Insere x mantendo a lista em ordem crescente; devolve o (novo) início.
No *insere_ordenado(No *inicio, int x)
{
    No *novo = malloc(sizeof *novo);
    if (novo == NULL) {
        fprintf(stderr, "memória insuficiente\n");
        exit(EXIT_FAILURE);
    }
    novo->valor = x;

    if (inicio == NULL || x < inicio->valor) {      // entra no início
        novo->proximo = inicio;
        return novo;
    }
    No *atual = inicio;
    while (atual->proximo != NULL && atual->proximo->valor < x) {
        atual = atual->proximo;
    }
    novo->proximo = atual->proximo;                 // entra depois de atual
    atual->proximo = novo;
    return inicio;
}

// Remove a primeira ocorrência de x; devolve o (novo) início.
No *remove_valor(No *inicio, int x)
{
    No *anterior = NULL;
    No *atual = inicio;
    while (atual != NULL && atual->valor != x) {
        anterior = atual;
        atual = atual->proximo;
    }
    if (atual == NULL) {
        return inicio;                              // não encontrado
    }
    if (anterior == NULL) {
        inicio = atual->proximo;                    // era o primeiro
    } else {
        anterior->proximo = atual->proximo;
    }
    free(atual);
    return inicio;
}

void imprime(const No *inicio)
{
    printf("[");
    for (const No *p = inicio; p != NULL; p = p->proximo) {
        printf("%d%s", p->valor, p->proximo != NULL ? " -> " : "");
    }
    printf("]\n");
}

void libera(No *inicio)
{
    while (inicio != NULL) {
        No *seguinte = inicio->proximo;            // guarde antes de liberar
        free(inicio);
        inicio = seguinte;
    }
}

int main(void)
{
    No *lista = NULL;                               // lista vazia
    int valores[] = {30, 10, 50, 20, 40};
    for (int i = 0; i < 5; i++) {
        lista = insere_ordenado(lista, valores[i]);
    }
    imprime(lista);
    lista = remove_valor(lista, 10);
    lista = remove_valor(lista, 40);
    lista = remove_valor(lista, 99);
    imprime(lista);
    libera(lista);
    return 0;
}

    [10 -> 20 -> 30 -> 40 -> 50]
[20 -> 30 -> 50]
    • Para inserir um elemento depois de um nó, basta criar o novo nó e ajustar dois ponteiros: nenhum elemento precisa ser deslocado, ao contrário do que acontece em um arranjo. Uma vez encontrada a posição, a inserção é \(O(1)\);
    • Para remover, o nó anterior passa a apontar para o seguinte, e o nó removido é liberado com free;
    • As funções que podem alterar o primeiro nó (inserindo antes dele ou removendo-o) devolvem o novo início, e quem chama atualiza a variável: lista = insere_ordenado(lista, x);;
    • Na liberação, o endereço do próximo nó é guardado antes do free, porque depois o nó não pode mais ser acessado.

    Em troca da inserção e da remoção rápidas, a lista perde o acesso direto pela posição: para chegar ao décimo elemento, é preciso percorrer os nove anteriores, o que é \(O(n)\). Na prática, por causa disso e porque os nós espalhados pela memória são mais lentos de percorrer, um vetor dinâmico costuma ser a melhor escolha, e as listas encadeadas são usadas quando há muitas inserções e remoções no meio da sequência, ou como base para outras estruturas (como as listas de adjacência de grafos).

    Fila de prioridade (heap)¶

    Uma fila de prioridade é uma coleção em que o elemento removido é sempre o menor (ou o maior) de todos, e não o primeiro a entrar. Ela é usada para escolher a próxima tarefa mais urgente, para encontrar caminhos mínimos em grafos e para combinar sequências ordenadas.

    A implementação mais usada é a heap binária: uma árvore binária completa guardada em um arranjo, em que cada elemento é menor ou igual aos seus filhos. Os filhos do elemento da posição i estão nas posições 2*i + 1 e 2*i + 2, e o seu pai está na posição (i - 1) / 2. Com isso, o menor elemento está sempre na posição 0, mas o resto do arranjo não fica ordenado:

    • Para inserir, o elemento é colocado no final e "sobe", trocando de lugar com o pai enquanto for menor que ele;
    • Para remover o menor, o último elemento é levado para a posição 0 e "desce", trocando de lugar com o menor dos filhos enquanto for maior que algum deles.

    Como a árvore é completa, a sua altura é \(O(\log n)\), e as duas operações são \(O(\log n)\); consultar o menor elemento é \(O(1)\).

    #include <stdio.h>

#define MAX 1000

typedef struct {
    int dados[MAX];
    int tamanho;
} Heap;                             // heap de mínimo: o menor elemento fica em dados[0]

void troca(int *a, int *b) { int aux = *a; *a = *b; *b = aux; }

void heap_insere(Heap *h, int x)
{
    int i = h->tamanho++;
    h->dados[i] = x;
    while (i > 0 && h->dados[(i - 1) / 2] > h->dados[i]) {   // sobe enquanto for menor que o pai
        troca(&h->dados[(i - 1) / 2], &h->dados[i]);
        i = (i - 1) / 2;
    }
}

int heap_remove_menor(Heap *h)
{
    int menor = h->dados[0];
    h->dados[0] = h->dados[--h->tamanho];     // o último vai para a raiz...
    int i = 0;
    while (1) {                               // ...e desce enquanto for maior que um filho
        int esq = 2 * i + 1, dir = 2 * i + 2, m = i;
        if (esq < h->tamanho && h->dados[esq] < h->dados[m]) m = esq;
        if (dir < h->tamanho && h->dados[dir] < h->dados[m]) m = dir;
        if (m == i) break;
        troca(&h->dados[i], &h->dados[m]);
        i = m;
    }
    return menor;
}

int main(void)
{
    Heap h = {.tamanho = 0};
    int x;
    while (scanf("%d", &x) == 1) {
        heap_insere(&h, x);
    }
    printf("heap: ");
    for (int i = 0; i < h.tamanho; i++) {
        printf("%d ", h.dados[i]);
    }
    printf("\nem ordem: ");
    while (h.tamanho > 0) {
        printf("%d ", heap_remove_menor(&h));
    }
    printf("\n");
    return 0;
}

    A primeira linha da saída mostra o arranjo da heap depois das inserções: o 1 está na posição 0, e cada elemento é menor que os seus filhos (o 3 é menor que o 5 e o 9; o 2, menor que o 8 e o 7), mas o arranjo não está em ordem. Retirando o menor elemento repetidamente, os valores saem em ordem crescente: essa é a ideia do algoritmo de ordenação heapsort, que é \(O(n \log n)\). Para uma heap de máximo, basta inverter as comparações.

    #include <stdio.h>

#define MAX_VALOR 1000

int main(void)
{
    int visto[MAX_VALOR + 1] = {0};        // visto[v] indica se v já apareceu
    int contagem[MAX_VALOR + 1] = {0};     // quantas vezes cada valor apareceu
    int x;

    printf("Sem repetições:");
    while (scanf("%d", &x) == 1) {
        if (x < 0 || x > MAX_VALOR) {
            continue;                      // fora do intervalo previsto
        }
        contagem[x]++;
        if (!visto[x]) {
            visto[x] = 1;
            printf(" %d", x);
        }
    }
    printf("\nRepetidos:");
    for (int v = 0; v <= MAX_VALOR; v++) {
        if (contagem[v] > 1) {
            printf(" %d (%dx)", v, contagem[v]);
        }
    }
    printf("\n");
    return 0;
}

    Essa técnica é muito usada em programação competitiva para marcar valores já vistos, contar frequências (como a contagem de letras na seção sobre cadeias de caracteres) e registrar estados visitados. O custo é a memória: o arranjo precisa ter uma posição para cada valor possível, e não serve para valores muito grandes ou para textos. Nesses casos, é preciso ordenar os dados e usar busca binária, ou implementar uma tabela de dispersão (hash table), que transforma cada chave em uma posição de um arranjo por meio de uma função.

    Ordenação e busca¶

    A biblioteca padrão oferece qsort para ordenar arranjos e bsearch para buscar em um arranjo ordenado. Implementações usuais apresentam ordenação em \(O(n \log n)\) e busca em \(O(\log n)\), mas o padrão C não fixa limites de complexidade para essas funções. As duas recebem uma função de comparação, explicada na seção sobre funções, e há um exemplo na biblioteca de códigos. Ordenar uma vez e fazer várias buscas é uma alternativa à tabela de dispersão quando as chaves não cabem em um arranjo de contagem.
