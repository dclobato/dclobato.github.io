    Expressões e operadores¶

    Nas subseções a seguir, letras minúsculas como a e b representam valores literais ou nomes de variáveis, o que for apropriado no contexto. Ao avaliar uma expressão, os seguintes operadores podem ser usados. T indica um tipo de dados.

    Expressões e operadores aritméticos¶

    Uma expressão aritmética vai ser construída a partir de operadores aritméticos e variáveis ou constantes numéricas.

    Operador Sintaxe Exemplo e/ou observações
    Adição a + b
    Subtração a - b
    Mais unário +a
    Menos unário (inverso aditivo) -a
    Multiplicação a * b O produto será do tipo com maior precisão entre os fatores
    Divisão a / b O quociente será do tipo com maior precisão entre o divisor e o dividendo
    Módulo a % b Resto da divisão de a por b
    Pré-incremento ++a Incrementa de um o valor de a, e depois utiliza o valor
    Pós-incremento a++ Utiliza o valor de a, e depois incrementa de um o valor
    Pré-decremento --a Decrementa de um o valor de a, e depois utiliza o valor
    Pós-decremento a-- Utiliza o valor de a, e depois decrementa de um o valor

    No pré-incremento (++x) ou pré-decremento (--x), o valor da variável é alterado antes de ser utilizado na expressão. Já no pós-incremento (x++) ou pós-decremento (x--), o valor original da variável é usado na expressão antes que o incremento ou decremento ocorra. Essa diferença, embora sutil, pode gerar resultados distintos em operações combinadas, como atribuições ou chamadas de funções. Por exemplo:

    int x = 5;
int y = ++x; // y será 6, x também será 6

int x = 5;
int y = x++; // y será 5, x será 6

    Embora muitas vezes ambas as versões levem ao mesmo resultado quando usadas isoladamente, seu uso dentro de expressões compostas exige atenção. Veja o exemplo a seguir:

    #include <stdio.h>

int main() {
    int a = 5;
    int b = 10;
    int c;

    c = a++ + --b + ++a - b--;

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("c = %d\n", c);

    return 0;
}

    Vamos analisar a linha c = a++ + --b + ++a - b--;

    Valores iniciais:

    • a = 5
    • b = 10

    Vamos por partes, respeitando a ordem de avaliação dos operadores. Os operadores de pré-incremento/decremento (++x, --x) têm maior precedência que operadores aritméticos como + e -, e os operadores pós-incremento/decremento (x++, x--) também têm alta precedência (mas menor que os prefixados).

    A avaliação acontece da esquerda para a direita, levando em conta as alterações de valores no tempo certo (antes ou depois da utilização):

    1. a++:

      • Usa o valor atual de a (que é 5) na expressão
      • Depois incrementa a para 6

    2. --b:

      • Primeiro decrementa b de 10 para 9
      • Depois usa esse valor (9) na expressão

    3. ++a:

      • Primeiro incrementa a de 6 para 7
      • Depois usa esse valor (7) na expressão

    4. b--:

      • Usa o valor atual de b (que é 9) na expressão
      • Depois decrementa b para 8

    Substituindo os valores na expressão:

    1
2
3
4
    c = 5       // (a++)  
  + 9       // (--b)  
  + 7       // (++a)  
  - 9;      // (b--)
    Resultado final
    1
    c = 5 + 9 + 7 - 9 = 12

    E os valores das variáveis no fim são:

    • a = 7 (foi incrementado duas vezes)
    • b = 8 (foi decrementado duas vezes)
    • c = 12

    Quando os operandos são de tipos diferentes, mas compatíveis, o C faz uma conversão de tipo implícita, também conhecida como coerção ou type juggling. Nesse caso, dados de um ou mais subtipos podem ser convertidos em um supertipo se necessário. Por exemplo, se um int for adicionado a um float, o int é implicitamente convertido em float e o resultado será do tipo float.

    A conversão implícita só acontece quando os tipos são diferentes. Então, ao efetuar a divisão de um inteiro por outro, o resultado será inteiro, a menos que seja feita a conversão explícita do dividendo ou do divisor para float ou double. 5/2 não é 2.5, e sim 2, pois 5 e 2 são do mesmo tipo (int), então o resultado será, também, do mesmo tipo (int). Para que seja 2.5, é preciso fazer 5.0/2 ou 5/2.0.

    Não lembrar desse pequeno detalhe pode acabar produzindo resultados não esperados durante a execução dos programas.

    Incorreto

    float r;
int a, b;

a = 5; b = 2;
r = a / b;     // r = 5/2

    Correto

    float r;
int a, b;

a = 5; b = 2;
r = (float)a / b;     // r = 5.0/2

    Operadores lógicos¶

    Operadores lógicos retornam um valor do tipo bool, indicando o resultado da operação.

    Operador Sintaxe Exemplo e/ou observações
    NOT (\(\lnot\)) !a Nega o valor de a
    AND (\(\land\)) a && b Será verdadeiro apenas quando a e b forem verdadeiros; em todos os outros casos, falso
    OR (\(\lor\)) a || b Será falso apenas quando a e b forem falsos; em todos os outros casos, verdadeiro
    | a | **AND** | b | | :--: | :--: | :--: | | Verdadeiro | **Verdadeiro** | Verdadeiro | | Verdadeiro | **Falso** | Falso | | Falso | **Falso** | Verdadeiro | | Falso | **Falso** | Falso |
    | a | **OR** | b | | :--: | :--: | :--: | | Verdadeiro | **Verdadeiro** | Verdadeiro | | Verdadeiro | **Verdadeiro** | Falso | | Falso | **Verdadeiro** | Verdadeiro | | Falso | **Falso** | Falso |
    | **NOT** | a | | :--: | :--: | | **Falso** | Verdadeiro | | **Verdadeiro** | Falso |

    Em C, a avaliação de operadores lógicos como && (E lógico) e || (OU lógico) segue uma estratégia conhecida como "curto-circuito". Esse mecanismo otimiza a execução do código ao interromper a avaliação de uma expressão lógica assim que o resultado final pode ser determinado de forma inequívoca.

    No caso do operador &&, a avaliação ocorre da esquerda para a direita. Se o primeiro operando for avaliado como falso, o resultado final da expressão será necessariamente falso, independentemente do valor do segundo operando. Portanto, o segundo operando não é avaliado, evitando cálculos desnecessários e possíveis efeitos colaterais. Um exemplo prático seria a verificação de um ponteiro antes de acessar a memória que ele aponta: if (ptr != NULL && *ptr == 10). Se ptr for NULL, a segunda parte da condição (*ptr == 10) não será avaliada, evitando um erro de acesso à memória inválida.

    De forma semelhante, o operador || também utiliza o curto-circuito. Se o primeiro operando for avaliado como verdadeiro, o resultado final da expressão será necessariamente verdadeiro, independentemente do valor do segundo operando. Logo, o segundo operando não é avaliado. Um exemplo comum é a verificação de múltiplas condições alternativas: if (opcao == 'a' || opcao == 'b' || opcao == 'c'). Se opcao for igual a a, as outras comparações não serão realizadas.

    Essa característica dos operadores lógicos em C não apenas melhora a eficiência do código, mas também permite escrever expressões mais seguras, prevenindo erros que poderiam ocorrer se todos os operandos fossem avaliados indiscriminadamente.

    Operadores relacionais¶

    Os operadores relacionais retornam um valor do tipo bool que indica se a relação é verdadeira ou falsa.

    | Operação | Sintaxe | Exemplo e/ou observações | :-- | :--: | :--| | Igual a | `a == b` | `a` igual a `b` | | Não igual a
    (diferente de) | `a != b` | `a` não igual (diferente) a `b` | | Maior que | `a > b` | `a` maior que `b` | | Menor que | `a < b` | `a` menor que `b` | | Maior ou igual a | `a >= b` | `a` maior ou igual a `b` | | Menor ou igual a | `a <= b` | `a` menor ou igual a `b` |

    Em C, o operador de igualdade é um sinal de igual duplo (==), enquanto o sinal de igual simples (=) é utilizado para atribuição. No início, é comum confundir os sinais, então cuidado e atenção! Se você acidentalmente usar = em vez de == dentro de uma condição, poderá ter resultados inesperados.

    Por exemplo, a expressão abaixo não verifica se a é igual a b, mas sim atribui b a a. Como a atribuição retorna o valor atribuído, a condição será verdadeira sempre que b for diferente de zero:

    if (a = b) {  // ERRO: deveria ser "a == b"
    printf("A condição é verdadeira!\n");
}

    Se b for diferente de zero, a receberá b, e a condição será avaliada como verdadeira. Esse erro pode causar um comportamento inesperado no código. Para verificar a igualdade corretamente, sempre use ==:

    if (a == b) {  // Comparação correta
    printf("A condição é verdadeira!\n");
}

    Veja bem, preste atenção!

    Se você quer saber se um número está entre outros dois, a expressão usada na matemática (\(10 < n < 50\)) não vai funcionar em C. Se você usar essa expressão, o compilador vai avaliar a primeira parte (\(10 < n\)) e, o resultado dessa comparação será comparado com 50.

    A forma correta envolve o operador AND (&&): 10 < n && n < 50.

    Operadores de bit¶

    Você sabia?

    Os operadores de deslocamento podem ser usados para efetuar multiplicação e divisão.

    Suponha que temos um número inteiro a = 5. Em representação binária, 5 é 00000101. Agora, vamos realizar um deslocamento à esquerda de 2 bits (a << 2). O que teremos é os bits de a "empurrados" 2 posições para a esquerda, resultando em 00010100. Os bits vazios à direita são preenchidos com zeros. Como 00010100 em binário corresponde a 20 em decimal, 5 << 2 resulta em 20.

    Uso mesmo número a = 5 (binário 00000101), um deslocamento à direita de 1 bit (a >> 1) resulta em 0000010. Para números sem sinal (unsigned), o bit vazio à esquerda é preenchido com zero. Para números com sinal (signed), o bit mais significativo (bit de sinal) é replicado. Como 0000010 em binário é 2 em decimal, temos que 5 >> 1 resulta em 2.

    Resumo:

    • a << b: Multiplica a por \(2^b\).
    • a >> b: Divide a por \(2^b\) (com comportamento diferente para números negativos).

    Os operadores de bit operam sobre os valores binários da variáveis.

    Operação Sintaxe Exemplo e/ou observações
    NOT ~a Inverte os bits de a
    AND a & b Efetua a operação AND bit-a-bit sobre os operandos a e b
    OR a | b Efetua a operação OR bit-a-bit sobre os operandos a e b
    XOR a ^ b Efetua a operação OR bit-a-bit sobre os operandos a e b
    Deslocamento à esquerda a << b Desloca os bits de a para a esquerda por b posições. Os bits à direita são preenchidos com zeros
    Deslocamento à direita a >> b Desloca os bits de a para a direita por b posições. O comportamento dos bits à esquerda depende do tipo de a: se a for signed, o bit de sinal é replicado (deslocamento aritmético); se a for unsigned, os bits à esquerda são preenchidos com zeros (deslocamento lógico)

    O operador XOR (OU-exclusivo) retorna verdadeiro apenas quando a != b.

    | a | **XOR** | b | | :--: | :--: | :--: | | Verdadeiro | **Falso** | Verdadeiro | | Verdadeiro | **Verdadeiro** | Falso | | Falso | **Verdadeiro** | Verdadeiro | | Falso | **Falso** | Falso |

    Operadores de atribuição¶

    Para operadores combinados na forma \(a~ \circledcirc= b\), a operação equivalente é \(a = a \circledcirc b\).

    Operação Sintaxe Exemplo e/ou observações
    Atribuição a = b Atribui o valor de b à variável a
    Adição combinada a += b Equivalente a a = a + b
    Subtração combinada a -= b Equivalente a a = a - b
    Multiplicação combinada a *= b Equivalente a a = a * b
    Divisão combinada a /= b Equivalente a a = a / b
    Módulo combinado a %= b Equivalente a a = a % b (resto da divisão)
    AND bit-a-bit combinado a &= b Equivalente a a = a & b
    OR bit-a-bit combinado a |= b Equivalente a a = a | b
    XOR bit-a-bit combinado a ^= b Equivalente a a = a ^ b
    Deslocamento à esquerda combinado a <<= b Equivalente a a = a << b
    Deslocamento à direita combinado a >>= b Equivalente a a = a >> b

    Precedência dos operadores¶

    Da hora de avaliar uma expressão, seja ela aritmética, de bit ou lógica, os diversos operadores presentes precisam ser avaliados na ordem correta de precedência. Já fazemos isso quando nós mesmos resolvemos uma expressão aritmética no papel: primeiro as potências e raízes, depois os produtos e quocientes, e assim sucessivamente.

    A tabela abaixo mostra os operadores ordenados de forma decrescente de prioridade (primeiro os do início, depois os do final), se possuem um (unários) ou dois (binários) operandos, e se são avaliados da esquerda para a direita (→) ou da direita para a esquerda (←).

    Operador Operandos Sentido da avaliação
    () [] -> . 2 →
    - ++ -- ! & * ~ (T) sizeof 1 ←
    * / % 2 →
    + - 2 →
    << >> 2 →
    < <= >= > 2 →
    == != 2 →
    & 2 →
    ^ 2 →
    | 2 →
    && 2 →
    || 2 →
    ? : 2 ←
    = op= 2 ←

    Na última linha op= representa os operadores na forma \(a~ \circledcirc= b\) listados em seção anterior.
