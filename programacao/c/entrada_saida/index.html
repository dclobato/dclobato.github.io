    Entrada e saída

    Entrada de Dados¶

    Função scanf()¶

    A função scanf() é uma das primeiras que aprendemos a utilizar em C. Com ela, é possível atribuir a uma variável algum valor (numérico ou não) informado pelo usuário. O f no nome da função indica que ela faz uma entrada formatada. Os caracteres que definem as máscaras de formatação estão definidos em outra parte deste documento.

    Se não houver redirecionamento de fluxo padrão, a leitura é feita a partir da entrada padrão.

    Lendo a idade
    int idade;
printf("Digite sua idade: ");
scanf("%d", &idade);
printf("Você tem %d anos.\n", idade);

    Um dos problemas que aparecem com o uso de scanf() é na hora de misturar a leitura de valores numéricos com valores não-numéricos: a função pode deixar caracteres pendentes no fluxo de entrada, causando problemas nas leituras subsequentes:

    Problema no uso de scanf()
    char nome[50];
int idade;
printf("Digite sua idade: ");
scanf("%d", &idade);
printf("Digite seu nome: ");
scanf("%s", nome);
printf("Nome: %s, Idade: %d\n", nome, idade);

    O problema ocorre porque scanf("%d", &idade) deixa um \n não processado no fluxo de entrada.

    A solução ideal para esse caso é não utilizar scanf(). Na biblioteca de códigos há a proposta de algumas rotinas que resolvem esse problema.

    Uma outra alternativa, mais simples, mas que nem sempre funciona, é consumir manualmente o \n com a função getchar(), que será detalhada a seguir.

    Consumindo o \n restante
    char nome[50];
int idade;
printf("Digite sua idade: ");
scanf("%d", &idade);
getchar(); // Consome o '\n'

    Podemos ler várias variáveis ao mesmo tempo usando um único scanf(). Para isso, basta incluir todas as máscaras de leitura (como %d, %f, etc...) dentro do scanf(), e passar as variáveis correspondentes na mesma ordem. Veja o exemplo abaixo, que é perfeitamente válido em C:

    int a, b, c;

    Nesse exemplo, o programa espera que o usuário digite três inteiros seguidos de um número real, todos separados por um ou mais espaço (ou ++Enter++). Os valores serão lidos na mesma ordem e armazenados nas variáveis correspondentes.

    Função sscanf()¶

    A função sscanf() lê dados de uma string ao invés da entrada padrão:

    Uso de sscanf()
    char entrada[] = "25";
int idade;
sscanf(entrada, "%d", &idade);
printf("Idade lida: %d\n", idade);

    Isso permite manipular dados sem interagir diretamente com o usuário. Isso é útil quando, por exemplo, trazemos dados de um arquivo e queremos fazer o processamento formatado deles.

    getc() e getchar()¶

    As funções scanf() e sscanf() fazem o processamento de um fluxo de dados. Se a necessidade for consumir apenas um caracter, podemos utilizar as funções getc() e getchar().

    Exemplo de uso de getchar()
    char c;
printf("Digite um caractere: ");
c = getchar();
printf("Você digitou: %c\n", c);

    A diferença entre essas duas funções é que a primeira pode ser usada para obter um caracter de qualquer fluxo, e não apenas do fluxo de entrada padrão. É como se getchar() fosse o mesmo que getc(stdin).

    Saída de Dados¶

    Função printf()¶

    Tal como podemos usar scanf() para a entrada formatada de dados, a linguagem C oferece uma contra-parte para a saída formatada de dados: printf(). É muito difícil escrever um programa em C que não use pelo menos um printf() em algum lugar para apresentar algum dado para o usuário.

    Assim como o scanf(), printf() faz uso de caracteres de formatação nas máscaras. Os caracteres disponíveis podem ser consultados aqui.

    Exemplo de uso de printf()
    int idade = 30;
printf("Idade: %d anos\n", idade);

    Além de exibir números, printf() pode formatar strings e caracteres especiais (sequências de escape, que foram apresentadas anteriormente):

    Exemplo de uso de printf()
    char nome[] = "Carlos";
printf("Nome: %s\n", nome);
printf("Caracteres especiais: Tab\tNova linha\n");

    putc() e putchar()¶

    Se a necessidade for apresentar apenas um caractere, e não o valor de uma variável numérica ou uma cadeia de caracteres, as funções putc() e putchar() podem ser utilizadas.

    Exemplo de uso de putchar()
    char c;
c = 'A';
putchar(c);
putchar('\n');
    A diferença entre essas duas funções é que a primeira pode ser usada para colocar um caracter de qualquer fluxo, e não apenas do fluxo de saída padrão. É como se putchar() fosse o mesmo que putc(stdout).

    Manipulação de arquivos texto¶

    A manipulação de arquivos em C é uma operação fundamental que permite ao programador ler e escrever dados em arquivos. Essa capacidade é essencial para muitas aplicações, desde a simples leitura de configurações até a complexa manipulação de dados em grandes conjuntos.

    Abrindo Arquivos¶

    Para abrir um arquivo em C, utiliza-se a função fopen(), que retorna um ponteiro para o FILE. Este ponteiro é usado para realizar operações no arquivo. A função fopen() requer dois parâmetros: o nome do arquivo e o modo de abertura. Após realizar operações em um arquivo, é essencial fechá-lo com fclose() para garantir a integridade dos dados e liberar recursos do sistema.

    Os modos de abertura disponíveis são:

    Modo Descrição
    "r" Leitura. O arquivo deve existir, pois não é criado automaticamente. Se não existir, fopen() retornará NULL
    "w" Escrita. Cria um novo arquivo ou sobrescreve um existente
    "a" Anexação. Adiciona dados ao final do arquivo
    "r+" Leitura e escrita. Permite modificar seu conteúdo sem apagar tudo. O arquivo deve existir, pois não é criado automaticamente
    "w+" Leitura e escrita. Se o arquivo existir, seu conteúdo será apagado; caso contrário, um novo arquivo será criado.

    No exemplo abaixo, utilizando o modo a, se dados.txt não existir, ele será criado; caso contrário, o texto será anexado ao final do arquivo.

    Para ler uma linha de um arquivo, a função fgets() é recomendada. Com ela é possível definir tanto a quantidade máxima de caracteres que devem ser lidos, como o fluxo de origem da leitura, que pode ser o arquivo ou o fluxo de entrada padrão (stdin).

  arquivo = fopen("entrada.txt", "r");

  fgets(linha, sizeof(linha), arquivo);

    Utilizando fscanf()¶

    A função fscanf() permite a leitura de dados formatados diretamente de um arquivo. Seu funcionamento é semelhante ao de scanf(), mas, em vez de ler a entrada do usuário pelo teclado (stdin), ela lê os dados de um fluxo de arquivo. Essa função é útil para extrair valores de arquivos de texto organizados de forma estruturada, como arquivos CSV ou tabelas.

    #include <stdio.h>

int main() {
    int idade;
    char nome[50];
    FILE *arquivo;

    arquivo = fopen("dados.txt", "r");

    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo!\n");
        return 1;
    }

    fscanf(arquivo, "%s %d", nome, &idade);
    printf("Nome: %s, Idade: %d\n", nome, idade);

    fclose(arquivo);
    return 0;
}

    Carlos 25

    Nome: Carlos, Idade: 25

    Veja bem, preste atenção!

    Diferente de fgets(), fscanf() não lida automaticamente com espaços em branco em cadeias de caracteres. Ao tentar ler uma frase com espaços, apenas a primeira palavra será armazenada. Para ler uma linha completa, recomenda-se usar fgets(). Além disso, fscanf() pode deixar dados no buffer de entrada, o que pode causar problemas em leituras subsequentes.

    Não use fscanf() a menos que você tenha uma razão muito forte para fazê-lo, e saiba o que está fazendo.

    Utilizando fprintf()¶

    fprintf() vs. fputs()

    Enquanto fputs() escreve apenas strings no arquivo, fprintf() permite a formatação de diferentes tipos de dados, como inteiros, floats e caracteres. Isso torna fprintf() mais útil na geração de saídas estruturadas.

    A função fprintf() permite escrever dados formatados em um arquivo, funcionando de maneira semelhante à printf(), mas direcionando a saída para um fluxo de arquivo em vez do console. Isso é útil para gerar relatórios, logs e arquivos estruturados de forma organizada.

    Manipulação de arquivos binários¶

    Em C, além de arquivos de texto, é possível trabalhar com arquivos binários, que armazenam dados no formato bruto da memória, sem conversões para texto. Esse tipo de arquivo é útil para armazenar estruturas complexas, dados numéricos, imagens, arquivos de áudio, entre outros.

    A manipulação de arquivos binários em C é feita usando principalmente as funções fopen(), fwrite(), fread() e fclose().

    A abertura dos arquivos é feita da mesma forma que fazemos para a manipulação de arquivos de texto, porém adicionando b ao modo de abertura. Ou seja:

    Modo Descrição
    "rb" Leitura binária (read binary). O arquivo deve existir.
    "wb" Escrita binária (write binary). Cria um novo arquivo ou sobrescreve um existente.
    "ab" Anexação binária (append binary). Adiciona dados ao final do arquivo.
    "rb+" Leitura e escrita binária (read/write binary). O arquivo deve existir.
    "wb+" Leitura e escrita binária (write/read binary). Cria um novo arquivo ou sobrescreve um existente.
    "ab+" Leitura e anexação binária (append/read binary). Permite leitura e escrita, preservando os dados existentes.

    Entrada de dados binários¶

    A função fread() é usada para ler dados de um arquivo binário. Sua sintaxe é:

    size_t fread(void *ptr, size_t size, size_t count, FILE *stream);
    • ptr: Ponteiro para armazenar os dados lidos.
    • size: Tamanho de cada elemento em bytes.
    • count: Número de elementos a serem lidos.
    • stream: Ponteiro para o arquivo.

    No exemplo a seguir, conseguimos ler os dados gravados pelo programa anterior de volta para a memória.

}

    • count: Número de elementos a serem escritos.

    Deslocamento no arquivo binário¶

    Ao trabalhar com arquivos binários em C, é essencial saber como mover o ponteiro do arquivo para ler ou escrever dados em posições específicas. Para isso, utilizamos as funções fseek(), que move o ponteiro, e ftell(), que retorna a posição atual do ponteiro.

    A função fseek() permite posicionar o ponteiro de leitura/escrita em qualquer parte do arquivo. Sua sintaxe é:

    int fseek(FILE *arquivo, long offset, int origem);
    • arquivo: Ponteiro para o arquivo.
    • offset: Quantidade de bytes a mover. Pode ser positivo (avançar) ou negativo (retroceder).
    • origem: Ponto de referência para o deslocamento. Pode assumir os seguintes valores:
      • SEEK_SET: início do arquivo.
      • SEEK_CUR: posição atual do ponteiro.
      • SEEK_END: final do arquivo.

    A função rewind(arquivo) é um atalho para fseek(arquivo, 0, SEEK_SET), ou seja, retorna o ponteiro ao início do arquivo. Se fseek() for bem-sucedido, retorna 0. Caso contrário, retorna um valor diferente de zero.

    #include <stdio.h>

int main() {
    FILE *arquivo;

    arquivo = fopen("dados.bin", "rb");

    if (arquivo == NULL) {
        printf("Erro ao abrir o arquivo!\n");
        return 1;
    }

    fseek(arquivo, 10, SEEK_SET);  // Move o ponteiro para o 10º byte a partir do início
    fseek(arquivo, -5, SEEK_CUR);  // Retrocede 5 bytes da posição atual
    fseek(arquivo, 0, SEEK_END);   // Move para o final do arquivo

    fclose(arquivo);
    return 0;
}

    Evite fseek() em arquivos texto.

    Em arquivos texto, fseek() pode ter comportamento inesperado, pois alguns sistemas operacionais convertem \r\n em \n, alterando a contagem de bytes. Seu uso é mais confiável em arquivos binários.

    A função ftell() retorna a posição atual do ponteiro no arquivo. Sua sintaxe é:

    long ftell(FILE *arquivo);

    Se bem-sucedida, retorna um valor long correspondente à posição do ponteiro em bytes. Em caso de erro, retorna -1L.

    Fluxos de entrada e saída¶

    A linguagem C oferece um modelo padronizado de entrada e saída baseado em três fluxos fundamentais:

    • stdin (standard input): fluxo de entrada padrão, geralmente associado ao teclado.
    • stdout (standard output): fluxo de saída padrão, comumente direcionado ao console (monitor).
    • stderr (standard error): fluxo de saída de erros, utilizado para exibir mensagens de erro separadamente da saída padrão (normalmente, o mesmo destino do stdout).

    Esses fluxos permitem flexibilidade na interação entre o programa e o sistema operacional, possibilitando que a entrada e a saída sejam redirecionadas para arquivos ou dispositivos específicos.

    Os fluxos padrões podem ser redirecionados via linha de comando, permitindo que os dados sejam lidos ou escritos a partir de diferentes fontes.

    Por exemplo, um programa que lê um número e imprime o dobro dele pode obter o número que deve ser multiplicado por 2 de um arquivo chamado entrada.txt.

  int num;
  printf("Digite um número: ");
  scanf("%d", &num);

    O programa lerá os dados do arquivo entrada.txt em vez do teclado.

    A mesma idéia pode ser aplicada ao fluxo de saída, redirecionando-o para um arquivo. Nesse caso, nada seria impresso na tela, mas sim redirecionado para o arquivo em questão.

    C:\Users\danie>programa.exe > saida.txt

C:\Users\danie>

    Isso salva a saída no arquivo saida.txt, ao invés de exibi-la na tela.

    Os fluxos de entrada e de saída podem ser redirecionados simultaneamente, como por exemplo em:

    C:\Users\danie>programa.exe < entrada.txt > saida.txt
