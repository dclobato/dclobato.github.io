    Introdução à Programação Orientada a Objetos em Python¶

    A Programação Orientada a Objetos (POO) é um paradigma de programação que organiza o código em torno de "objetos", que são instâncias de "classes". Python é uma linguagem multiparadigma que suporta plenamente a programação orientada a objetos, oferecendo recursos para criar e manipular classes e objetos de forma elegante e eficiente.

    Conceitos Fundamentais¶

    Classes e Objetos¶

    Uma classe é um modelo ou um plano para criar objetos. Ela define atributos (propriedades) e métodos (funções) que serão compartilhados por todos os objetos criados a partir dela. Um objeto é uma instância de uma classe — uma entidade concreta baseada no modelo da classe.

    class Pessoa:
    # Método inicializador (construtor)
    def __init__(self, nome, idade):
        # Atributos ou propriedades
        self.nome = nome
        self.idade = idade

    # Método da classe
    def apresentar(self):
        return f"Olá, meu nome é {self.nome} e tenho {self.idade} anos."

# Criando objetos (instâncias) da classe Pessoa
pessoa1 = Pessoa("Ana", 28)
pessoa2 = Pessoa("Carlos", 35)

# Chamando métodos e acessando propriedades
print(pessoa1.apresentar())  # Olá, meu nome é Ana e tenho 28 anos.
print(pessoa2.nome)          # Carlos

    No exemplo acima:

    • Pessoa é uma classe;
    • pessoa1 e pessoa2 são objetos (instâncias) da classe Pessoa;
    • nome e idade são atributos (propriedades);
    • apresentar() é um método;
    • __init__ é o método construtor, chamado quando um novo objeto é criado;
    • self é uma referência ao próprio objeto.

    Encapsulamento¶

    O encapsulamento é o princípio de esconder os detalhes internos de um objeto e expor apenas as interfaces necessárias. Em Python, o encapsulamento é implementado através de convenções de nomenclatura:

    • Atributos com prefixo _ (underscore simples) são considerados "protegidos" (apenas uma convenção)
    • Atributos com prefixo __ (duplo underscore) são "privados" (tecnicamente, são renomeados pelo interpretador)

    class ContaBancaria:
    def __init__(self, titular, saldo_inicial):
        self.titular = titular        # Público
        self._saldo = saldo_inicial   # Protegido (por convenção)
        self.__historico = []         # Privado

    def depositar(self, valor):
        self._saldo += valor
        self.__registrar_transacao(f"Depósito: +R${valor}")
        return self._saldo

    def __registrar_transacao(self, descricao):
        self.__historico.append(descricao)

# Uso da classe
conta = ContaBancaria("João Silva", 1000)
conta.depositar(500)

print(conta.titular)    # João Silva - acesso normal
print(conta._saldo)     # 1500 - acesso possível, mas não recomendado
# print(conta.__historico)  # Erro! Atributo privado não acessível diretamente

    Herança¶

    A herança permite que uma classe (subclasse) herde atributos e métodos de outra classe (superclasse). Isso promove reusabilidade e estabelece relações "é um" entre classes.

    # Classe base (superclasse)
class Animal:
    def __init__(self, nome):
        self.nome = nome

    def fazer_som(self):
        pass  # Método a ser sobrescrito pelas subclasses

# Subclasses
class Cachorro(Animal):
    def fazer_som(self):
        return "Au au!"

class Gato(Animal):
    def fazer_som(self):
        return "Miau!"

# Uso das classes
rex = Cachorro("Rex")
mimi = Gato("Mimi")

print(f"{rex.nome}: {rex.fazer_som()}")  # Rex: Au au!
print(f"{mimi.nome}: {mimi.fazer_som()}")  # Mimi: Miau!

    Python também suporta herança múltipla, permitindo que uma classe herde de várias superclasses.

    Polimorfismo¶

    O polimorfismo permite que objetos de diferentes classes sejam tratados como objetos de uma classe comum. Em Python, o polimorfismo é naturalmente suportado devido à sua natureza dinâmica.

    class Pessoa:
    def __init__(self, nome, idade):
        self._nome = nome
        self._idade = idade

    # Getter para nome
    def get_nome(self):
        return self._nome

    # Setter para nome
    def set_nome(self, novo_nome):
        if isinstance(novo_nome, str) and novo_nome:
            self._nome = novo_nome
        else:
            raise ValueError("Nome deve ser uma string não vazia")

    # Getter para idade
    def get_idade(self):
        return self._idade

    # Setter para idade
    def set_idade(self, nova_idade):
        if isinstance(nova_idade, int) and 0 <= nova_idade <= 150:
            self._idade = nova_idade
        else:
            raise ValueError("Idade deve ser um inteiro entre 0 e 150")

# Uso
p = Pessoa("Ana", 28)
print(p.get_nome())    # Ana
p.set_idade(29)
print(p.get_idade())   # 29

    class Pessoa:
    def __init__(self, nome, idade):
        self._nome = nome
        self._idade = idade

    # Getter para nome
    @property
    def nome(self):
        return self._nome

    # Setter para nome
    @nome.setter
    def nome(self, valor):
        if isinstance(valor, str) and valor:
            self._nome = valor
        else:
            raise ValueError("Nome deve ser uma string não vazia")

    # Getter para idade
    @property
    def idade(self):
        return self._idade

    # Setter para idade
    @idade.setter
    def idade(self, valor):
        if isinstance(valor, int) and 0 <= valor <= 150:
            self._idade = valor
        else:
            raise ValueError("Idade deve ser um inteiro entre 0 e 150")

    # Propriedade somente leitura (apenas getter)
    @property
    def maioridade(self):
        return self._idade >= 18

# Uso
p = Pessoa("Ana", 28)
print(p.nome)        # Ana - acesso como atributo
p.idade = 29         # Chama o setter
print(p.idade)       # 29
print(p.maioridade)  # True - propriedade calculada somente leitura

# Tentativa de atribuir valor inválido
try:
    p.idade = -5
except ValueError as e:
    print(e)         # Idade deve ser um inteiro entre 0 e 150

    O uso de @property torna o código mais limpo e pythônico, mantendo a sintaxe de acesso a atributos enquanto permite a validação e lógica adicional.

    class Circulo:
    def __init__(self, raio):
        self._raio = raio

    @property
    def raio(self):
        return self._raio

    @property
    def area(self):
        import math
        return math.pi * self._raio ** 2

    @property
    def circunferencia(self):
        import math
        return 2 * math.pi * self._raio

# Uso
c = Circulo(5)
print(c.raio)           # 5
print(c.area)           # 78.53981633974483
print(c.circunferencia) # 31.41592653589793

# Tentativa de modificar atributos
try:
    c.area = 100  # Erro! Não existe setter para 'area'
except AttributeError as e:
    print("Não é possível modificar a área diretamente.")

    Vantagens dos getters e setters¶

    O uso de getters e setters, especialmente com @property, oferece várias vantagens:

    • Validação de dados: Permite verificar se os valores atribuídos são válidos
    • Encapsulamento: Oculta detalhes de implementação e protege o estado interno
    • Abstração: Permite que propriedades calculadas sejam acessadas como atributos simples
    • Compatibilidade: Mudanças na implementação não afetam o código cliente
    • Depuração: Facilita a inserção de pontos de depuração ou logging

    Boas Práticas¶

    • Use @property em vez de métodos explícitos sempre que possível para manter uma interface pythônica
    • Projete suas classes cuidadosamente para que a maioria dos atributos seja acessível diretamente
    • Use getters e setters apenas quando necessário para validação ou lógica adicional
    • Documente o comportamento esperado das propriedades para que outros desenvolvedores entendam as restrições

    Classes de Dados (dataclass)¶

    As classes de dados (dataclass) em Python são um recurso da linguagem que facilita a criação de classes voltadas para o armazenamento e manipulação de dados. Introduzidas no Python 3.7, elas geram automaticamente métodos comuns, como __init__, __repr__, __eq__, e outros, com base nos atributos declarados na classe, o que reduz a quantidade de código repetitivo.

    Enquanto as classes tradicionais oferecem flexibilidade para definir métodos e lógica de negócio, as dataclasses são focadas em simplificar a criação de classes para armazenar dados. Elas são adequadas quando o principal objetivo da classe é representar um objeto com atributos específicos e não possui lógica de comportamento complexa.

    A criação de uma dataclass é feita utilizando o decorador @dataclass. Ao decorar uma classe com @dataclass, Python automaticamente cria o método __init__ e outros métodos importantes, como __repr__ e __eq__.

    from dataclasses import dataclass

@dataclass
class Pessoa:
    nome: str
    idade: int

p1 = Pessoa("Alice", 25)
print(p1)  # Pessoa(nome='Alice', idade=25)
p2 = Pessoa("Alice", 25)
print(p1 == p2)  # True

    O exemplo acima define uma dataclass chamada Pessoa com dois atributos: nome e idade. O método __repr__ gerado automaticamente facilita a exibição do conteúdo da instância, bem como o método __eq__ para comparar instâncias de uma classe de dados.

    Além disso, é possível tornar uma dataclass imutável, definindo o parâmetro frozen=True no decorador @dataclass. Com isso, os atributos da instância não poderão ser modificados após sua criação.

    from dataclasses import dataclass

@dataclass
class Animal:
    nome: str
    especie: str

    def falar(self):
        return f"{self.nome} faz barulho!"

@dataclass
class Cachorro(Animal):
    cor: str

    def falar(self):
        return f"{self.nome} diz au au!"

cachorro = Cachorro("Rex", "Cachorro", "Marrom")
print(cachorro.falar())  # Rex diz au au!

    No exemplo acima, Cachorro herda de Animal e sobrescreve o método falar. Essa flexibilidade permite que as dataclasses sejam utilizadas em sistemas onde a simplicidade de armazenamento de dados ainda é necessária, mas com a possibilidade de estender comportamentos através de herança.
