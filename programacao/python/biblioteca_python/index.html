    Trechos de código relevantes em Python e cheat sheets¶

    Esta página reúne funções prontas para usar e tabelas de consulta rápida com os recursos da linguagem e da biblioteca padrão que aparecem com mais frequência. Os exemplos foram executados no Python 3.14.

    Leitura robusta de números¶

    A função input() devolve sempre uma cadeia de caracteres, e a conversão com int() ou float() levanta ValueError quando o usuário digita algo inválido, encerrando o programa. As funções abaixo repetem a pergunta até que um valor válido seja informado, e encerram o programa com uma mensagem de erro se a entrada terminar. São úteis em programas interativos; em programas para juízes online, em que a entrada sempre segue o formato do enunciado, use as formas de leitura da seção sobre entrada e saída.

    """Funções para ler valores digitados pelo usuário, repetindo a pergunta
até que um valor válido seja informado."""

import sys


def ler_linha(prompt=""):
    """Lê uma linha da entrada padrão, sem o '\\n' do final.

    Encerra o programa com uma mensagem de erro se a entrada terminar.
    """
    try:
        return input(prompt)
    except EOFError:
        print("\nErro: a entrada terminou antes do esperado", file=sys.stderr)
        sys.exit(1)


def ler_int(prompt="", minimo=None, maximo=None):
    """Lê um número inteiro, opcionalmente dentro do intervalo [minimo, maximo]."""
    while True:
        texto = ler_linha(prompt)
        try:
            valor = int(texto)
        except ValueError:
            print(f"'{texto.strip()}' não é um número inteiro.")
            continue
        if minimo is not None and valor < minimo:
            print(f"O valor deve ser maior ou igual a {minimo}.")
        elif maximo is not None and valor > maximo:
            print(f"O valor deve ser menor ou igual a {maximo}.")
        else:
            return valor


def ler_float(prompt=""):
    """Lê um número real; aceita vírgula ou ponto como separador decimal."""
    while True:
        texto = ler_linha(prompt)
        try:
            return float(texto.replace(",", "."))
        except ValueError:
            print(f"'{texto.strip()}' não é um número.")


def ler_sim_nao(prompt=""):
    """Lê uma resposta do tipo sim/não e devolve True ou False."""
    while True:
        resposta = ler_linha(prompt).strip().lower()
        if resposta in ("s", "sim"):
            return True
        if resposta in ("n", "não", "nao"):
            return False
        print("Responda com 's' ou 'n'.")

    Formatação com f-strings¶

    Dentro das chaves de uma f-string, depois do valor, o sinal de dois pontos introduz uma especificação de formato, na forma [[preenchimento]alinhamento][sinal][#][0][largura][,][.precisão][tipo]:

    Especificação Significado Exemplo Resultado
    .Nf N casas decimais f"{3.14159:.2f}" 3.14
    N Largura mínima N (números à direita, textos à esquerda) f"[{42:5}]" [ 42]
    <N, >N, ^N Alinhado à esquerda, à direita ou centralizado f"[{'ab':^6}]" [ ab ]
    cN Preenche com o caractere c f"{'ab':*^6}" **ab**
    0N Zeros à esquerda f"{7:03}" 007
    + Sinal também nos positivos f"{5:+}" +5
    , ou _ Separador de milhares f"{1234567:,}" 1,234,567
    e Notação científica f"{1234.5:.2e}" 1.23e+03
    % Porcentagem (multiplica por 100) f"{0.256:.1%}" 25.6%
    b, o, x, X Binário, octal, hexadecimal f"{255:b}", f"{255:x}" 11111111, ff
    # Prefixo da base f"{255:#x}" 0xff
    {v:{n}} Largura (ou precisão) dada por uma variável f"[{7:{n}}]", com n = 4 [ 7]
    = Mostra a expressão e o valor f"{n=}", com n = 4 n=4

    Números aleatórios¶

    O módulo random gera números pseudoaleatórios a partir de uma semente. Por padrão, usa uma fonte de aleatoriedade do sistema operacional quando disponível, ou o relógio como alternativa. Uma semente fixa ajuda a reproduzir testes no mesmo ambiente; nem todas as funções mantêm sequências idênticas entre versões de Python.

print(random.random())                    # real em [0, 1)

cartas = list(range(1, 11))
random.shuffle(cartas)                    # embaralha a lista no lugar
print(cartas)
print(random.sample(range(1, 61), 6))     # 6 números distintos, como na Mega-Sena
print([random.randint(1, 6) for _ in range(10)])

    Função O que faz
    random.random() Um número real em \([0, 1)\)
    random.randint(a, b) Um inteiro de a a b, incluindo b
    random.randrange(a, b, passo) Um inteiro de range(a, b, passo) (sem incluir b)
    random.uniform(a, b) Um número real entre a e b
    random.choice(seq) Um elemento qualquer da sequência
    random.choices(seq, k=n) n elementos, que podem se repetir
    random.sample(seq, k=n) n elementos distintos
    random.shuffle(lista) Embaralha a lista, alterando-a
    random.gauss(media, desvio) Um número com distribuição normal
    random.seed(valor) Define a semente

    Veja bem, preste atenção!

    Os números do módulo random são previsíveis para quem conhece o algoritmo e a semente, e não devem ser usados para senhas, tokens de acesso ou qualquer outro fim de segurança. Para isso, use o módulo secrets, como em secrets.token_hex(16) ou secrets.randbelow(100).

    • Os inteiros (int) não têm limite de tamanho: 2 ** 100 é calculado exatamente. O único limite é a memória disponível. sys.maxsize é o maior valor de Py_ssize_t, usado para tamanhos e índices na implementação; não é o maior inteiro de Python nem uma promessa de que uma lista desse tamanho possa ser alocada;
    • Os números reais (float) têm cerca de 15 dígitos significativos (sys.float_info.dig), e vão até cerca de \(1{,}8 \times 10^{308}\). math.inf representa o infinito, e math.nan representa um valor indefinido ("não é um número"), que é diferente de tudo, inclusive de si mesmo (por isso, use math.isnan para testá-lo);
    • Por causa da representação aproximada, compare números reais com math.isclose(a, b), e não com ==.

    math.prod(seq), math.fsum(seq) Produto dos elementos, e soma de reais com menos erro de arredondamento

    Veja bem, preste atenção!

    O operador // arredonda para baixo, e não em direção ao zero: -17 // 5 vale -4, e -17 % 5 vale 3 (o resto tem sempre o sinal do divisor). Para raízes de inteiros grandes, use math.isqrt: int(math.sqrt(n)) passa pelo float, que tem só 15 dígitos de precisão, e pode errar com números grandes.

    Métodos de cadeias de caracteres¶

    A tabela abaixo resume os métodos mais usados. A explicação e os exemplos de uso estão na seção sobre cadeias de caracteres.

    Método O que faz
    s.strip(), s.lstrip(), s.rstrip() Remove os espaços (ou os caracteres indicados) das pontas
    s.split(), s.split(sep) Divide em uma lista; sem argumento, separa por qualquer sequência de espaços
    sep.join(lista) Junta os elementos da lista (que precisam ser cadeias), separados por sep
    s.upper(), s.lower(), s.title(), s.capitalize() Maiúsculas, minúsculas, iniciais maiúsculas, primeira letra maiúscula
    s.find(t), s.rfind(t), s.index(t) Posição da primeira (ou última) ocorrência; find devolve -1 e index levanta ValueError se não encontrar
    s.count(t), t in s Quantidade de ocorrências; se t aparece em s
    s.replace(a, b), s.replace(a, b, n) Troca as ocorrências de a por b (ou só as n primeiras)
    s.startswith(t), s.endswith(t) Se começa ou termina com t
    s.isdigit(), s.isalpha(), s.isalnum(), s.isspace() Se todos os caracteres são dígitos, letras, letras ou dígitos, espaços
    s.zfill(n), s.center(n, c), s.ljust(n, c), s.rjust(n, c) Completa até n caracteres, com zeros ou com o caractere c
    s[::-1], s[i:j] Cadeia invertida; fatia da posição i até j - 1

    Cadeias de caracteres são imutáveis: esses métodos não modificam a original, e alguns podem devolver o próprio objeto quando o resultado não muda.

    bisect_left(v, x) devolve a primeira posição em que x poderia ser inserido mantendo a lista ordenada, e bisect_right(v, x), a última. Assim, bisect_right(v, x) - bisect_left(v, x) é a quantidade de ocorrências de x, e bisect_left(v, x) é a quantidade de elementos menores que x.

    sorted(seq) devolve uma lista nova ordenada, e lista.sort() ordena a própria lista (e devolve None). As duas aceitam reverse=True e uma função key, aplicada a cada elemento antes da comparação: com uma tupla, como (-nota, nome), a ordenação usa vários critérios, e o sinal de menos inverte a ordem de um critério numérico. Sem key, cadeias são comparadas pelos pontos de código Unicode; para as letras ASCII, maiúsculas vêm antes de minúsculas; com key=str.lower, a diferença é ignorada. A seção sobre funções explica o parâmetro key em detalhes.
