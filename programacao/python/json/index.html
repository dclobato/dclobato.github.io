    Manipulação de JSON¶

    JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados, amplamente utilizado para comunicação entre sistemas e armazenamento de informações estruturadas. Ele surgiu como uma alternativa simplificada ao XML (Extensible Markup Language), com foco em legibilidade e facilidade de uso por humanos e máquinas. Por ser baseado em texto, JSON pode ser facilmente transmitido entre aplicações, incluindo aquelas escritas em linguagens diferentes, o que o torna um formato popular em APIs, aplicações web e sistemas distribuídos.

    O JSON é lido e escrito com as mesmas ferramentas de entrada e saída em arquivos apresentadas na seção anterior, com a ajuda do módulo json da biblioteca padrão.

    Veja bem, preste atenção!

    Diferente de XML, JSON não aceita comentários. Qualquer tentativa de inserir //, /* ... */ ou # causará erro de leitura ou de validação.

    Essa decisão de design foi tomada intencionalmente por Douglas Crockford, o criador do JSON, por vários motivos, sendo os principais:

    • Evitar diretivas de processamento: Crockford observou que comentários eram, às vezes, usados para incorporar diretivas de processamento ou instruções específicas para determinados processadores de documento. Essa prática poderia levar à falta de interoperabilidade, já que diferentes processadores poderiam interpretar essas diretivas de forma diferente ou nem interpretá-las, potencialmente interrompendo o comportamento pretendido dos dados JSON em vários sistemas;
    • Manter a simplicidade e o foco somente em dados: o JSON foi projetado como um formato leve e genérico para intercâmbio de dados entre máquinas (M2M). A inclusão de comentários adicionaria uma camada de complexidade ao processo de processamento e potencialmente mudaria seu foco da representação pura de dados para um formato mais expressivo, semelhante a uma configuração. O objetivo era manter o JSON como uma estrutura de dados clara e inequívoca;
    • Garantir a portabilidade: ao excluir comentários, o JSON garante que os dados em si sejam a única fonte de informação, tornando-os mais portáteis e consistentemente interpretáveis em diferentes linguagens de programação e plataformas, sem preocupações sobre como os comentários podem ser tratados.

    Para um desenvolvedor Python, a estrutura de um documento JSON é imediatamente familiar, pois se assemelha muito a um dicionário aninhado com listas. No entanto, é crucial entender que JSON e dicionários Python não são a mesma coisa. O módulo json do Python atua como uma "ponte", traduzindo (serializando e desserializando) objetos de um formato para o outro.

    Um documento JSON pode conter qualquer valor JSON no nível principal, inclusive um número, texto, booleano ou null. As principais diferenças em relação aos dicionários Python são:

    Característica Dicionário Python Documento JSON
    Chaves Precisam ser hashable, como strings, números e tuplas cujos elementos também sejam hashable. Obrigatoriamente strings, sempre entre aspas duplas.
    Strings Podem ser delimitadas por aspas simples (') ou duplas ("). Obrigatoriamente aspas duplas (").
    Valores Nulos Representados pelo objeto None. Representados pela palavra-chave null.
    Valores Booleanos Representados por True e False (com inicial maiúscula). Representados por true e false (com inicial minúscula).
    Tipos de Dados Suporta uma vasta gama de tipos: int, float, list, dict, tuple, set, etc. Suporta apenas: string, number, object (dicionário), array (lista), boolean e null.

    JSON suporta naturalmente a criação de estruturas hierárquicas e aninhadas, permitindo representar dados complexos por meio de objetos dentro de objetos e listas (arrays) de objetos. Por exemplo, ao modelar informações sobre uma pessoa, pode-se criar um campo "endereço" que, por sua vez, seja um objeto com campos de rua, cidade, número, etc. Da mesma forma, é possível ter listas de objetos, como uma lista de projetos associados a um usuário, cada um descrito em detalhes. Essa flexibilidade faz com que JSON seja ideal para representar árvores de dados, configurações sofisticadas e mensagens de APIs modernas, indo muito além de simples listas planas ou associações diretas de chave-valor.     Além disso, um aspecto importante do JSON é a padronização da codificação de caracteres em UTF-8.     Outros elementos fundamentais são a portabilidade e a independência de linguagem: JSON pode ser manipulado nativamente ou por meio de bibliotecas em praticamente todas as linguagens de programação modernas, como Python, JavaScript, Java, C#, PHP e muitas outras. Essa característica consolidou o formato não apenas como uma escolha popular em APIs web, mas também em bancos de dados NoSQL, arquivos de configuração e sistemas distribuídos.

    Lendo (desserializando) dados JSON¶

    Desserializar é o processo de converter uma string ou um arquivo JSON em um objeto Python (normalmente um dicionário ou uma lista). O módulo json oferece duas funções principais para isso:

    • json.loads(): Carrega (load string) um objeto JSON a partir de uma string.
    • json.load(): Carrega um objeto JSON a partir de um arquivo.

    import json

# Exemplo com json.loads() a partir de uma string
json_string = """
{
   "nome": "Alice",
   "idade": 30,
   "cidade": "São Paulo",
   "ativa": true,
   "cursos": [
      "Python",
      "Análise de Sistemas"
   ]
}
"""

dados_python = json.loads(json_string)
print(f"Tipo do objeto Python: {type(dados_python)}")
print(f"Nome: {dados_python['nome']}")
print(f"Ativa: {dados_python['ativa']}, cursos: {dados_python['cursos']}")

# Grava a mesma string em um arquivo, para o exemplo seguinte
with open("usuario.json", "w", encoding="utf-8") as arquivo:
    arquivo.write(json_string)

# Exemplo com json.load() a partir de um arquivo
with open("usuario.json", "r", encoding="utf-8") as arquivo:
    dados_do_arquivo = json.load(arquivo)
    print(f"Cidade lida do arquivo: {dados_do_arquivo['cidade']}")

    Tipo do objeto Python: <class 'dict'>
Nome: Alice
Ativa: True, cursos: ['Python', 'Análise de Sistemas']
Cidade lida do arquivo: São Paulo

    Repare que o valor true do JSON virou True, e o array virou uma lista. O texto JSON foi escrito entre aspas triplas, que permitem uma cadeia de caracteres com várias linhas.

    Escrevendo (serializando) objetos em JSON¶

    Serializar é o processo inverso: converter um objeto Python (como um dicionário ou lista) em uma string ou arquivo no formato JSON. As funções para esta tarefa são:

    • json.dumps(): Converte (dump string) um objeto Python para uma string formatada em JSON.
    • json.dump(): Escreve um objeto Python diretamente em um arquivo, no formato JSON.

    Essas funções aceitam parâmetros úteis para formatação:

    • indent: Define o número de espaços para a indentação, tornando o resultado legível para humanos (pretty-printing).
    • sort_keys=True: Ordena as chaves do dicionário em ordem alfabética.
    • ensure_ascii=False: Garante que caracteres não ASCII (como ç, ã) sejam escritos como são, em vez de sequências de escape. É uma opção de legibilidade: os escapes também são válidos em um arquivo UTF-8 e preservam os mesmos caracteres.

    import json

dados_para_salvar = {
    'id_usuario': 102,
    'contato': {
        'email': 'carlos@exemplo.com',
        'telefone': None
    },
    'permissões': ['leitura', 'escrita'],
    'configuração': {
        'tema': 'escuro',
        'notificações': True
    }
}

# Exemplo com json.dumps() para gerar uma string formatada
json_formatado = json.dumps(dados_para_salvar, indent=4, sort_keys=True, ensure_ascii=False)
print(json_formatado)

# Sem ensure_ascii=False, os caracteres acentuados viram sequências de escape
print(json.dumps({'ação': 'não'}))

# Exemplo com json.dump() para salvar em um arquivo
with open('configuracao.json', 'w', encoding='utf-8') as arquivo:
    json.dump(dados_para_salvar,
              arquivo,
              indent=4,
              ensure_ascii=False)

print("\nArquivo 'configuracao.json' salvo com sucesso.")

    Na conversão, None virou null e True virou true, e as chaves foram ordenadas por causa de sort_keys=True.     Números e interoperabilidade

    Por padrão, json.dumps() aceita NaN e infinitos, embora esses valores não façam parte do formato JSON. Use allow_nan=False para recusá-los com ValueError. Na leitura, parse_constant permite rejeitar essas extensões. Além disso, skipkeys=False é o padrão: chaves de tipos não aceitos pelo serializador causam TypeError; chaves numéricas aceitas são convertidas em texto. Serializar e ler novamente um dicionário não preserva necessariamente os tipos de suas chaves.

    Tratamento de exceções comuns¶

    Durante a manipulação de documentos JSON, alguns problemas podem acontecer, e eles são sinalizados por meio de exceções. A explicação detalhada de como funciona o tratamento de exceções está na seção sobre controle de fluxo.

    Durante a manipulação de JSON, duas exceções principais podem ocorrer:

    json.JSONDecodeError¶

    Levantada durante a leitura (load ou loads) quando a string ou o arquivo não contêm um JSON válido. Causas comuns incluem o uso de aspas simples, vírgulas no final de uma lista de itens (trailing comma) ou formatação quebrada.

except json.JSONDecodeError as e:
    print(f"Erro ao decodificar JSON: {e}")

    A mensagem indica o problema e a posição em que ele foi encontrado (linha 1, coluna 2: a aspa simples logo depois da chave).

    TypeError¶

    Ocorre durante a escrita (dump ou dumps) ao tentar serializar um tipo de dado Python que não tem uma representação direta em JSON, como objetos de data e hora (datetime), conjuntos (set) ou classes customizadas. Nesses casos, cabe ao programador escrever métodos para serializar esses objetos.

from datetime import date

dados_com_tipo_invalido = {
    "evento": "Aniversário do Projeto",
    "data": date(2025, 10, 26)  # O tipo 'date' não é suportado por padrão

{"evento": "Aniversário do Projeto", "data": "2025-10-26"}

    A solução mais simples é converter o valor para um tipo que o JSON aceita antes de serializar: uma data vira um texto no formato ISO (AAAA-MM-DD), com isoformat(), e um conjunto vira uma lista, com list(). Na leitura, o texto pode ser convertido de volta com date.fromisoformat().

    Exemplo completo¶

    O código a seguir apresenta um exemplo abrangente da manipulação de arquivos estruturados em Python, demonstrando de forma integrada as operações fundamentais de leitura, processamento e escrita de dados. A função processar_vendas_diarias_json() implementa um sistema de análise de vendas que lê dados de um arquivo JSON, exemplificando as melhores práticas no manuseio de arquivos, combinando verificações de integridade, tratamento de erros e a geração automatizada de relatórios em múltiplos formatos.

    A lógica da aplicação começa com uma verificação da existência do arquivo de entrada utilizando os.path.exists(), estabelecendo uma abordagem que evita falhas de execução desnecessárias. O processamento principal emprega o gerenciador de contexto with open(), garantindo o fechamento automático dos recursos de sistema mesmo em caso de exceções, uma prática fundamental para aplicações robustas. A especificação explícita da codificação UTF-8 assegura compatibilidade internacional e tratamento adequado de caracteres acentuados.

    Durante a fase de leitura e processamento, o código utiliza o método json.load() para decodificar o arquivo de entrada diretamente em uma estrutura de dados Python. A estratégia de validação itera sobre cada registro de venda (um dicionário dentro de uma lista) e utiliza blocos try/except para lidar de forma segura com inconsistências, como a ausência de chaves esperadas (KeyError) ou valores que não podem ser convertidos para números (ValueError, TypeError), garantindo a integridade do processamento mesmo com dados malformados.

    A geração de saídas demonstra a flexibilidade do Python ao produzir dois tipos de relatórios a partir dos mesmos dados processados. Primeiramente, um relatório de texto legível para humanos é criado, utilizando a função print() com o parâmetro file para cabeçalhos e resumos, e o método write() para a apresentação tabular dos dados. Em segundo lugar, um arquivo de resumo JSON é gerado com json.dump(), contendo os dados consolidados de forma estruturada, ideal para ser consumido por outros sistemas ou para arquivamento. A implementação de ordenação decrescente por valor de vendas utilizando sorted() com função lambda exemplifica técnicas de processamento que agregam valor analítico aos dois relatórios finais.

    A estratégia de nomenclatura temporal para os arquivos de relatório, empregando datetime.now().strftime(), estabelece um sistema de versionamento automático que previne sobreposições acidentais e facilita o rastreamento histórico. O bloco de execução condicional if __name__ == "__main__": ilustra a estrutura modular adequada para código Python, permitindo tanto a importação como módulo quanto a execução independente, facilitando testes e reutilização em diferentes contextos de desenvolvimento.

    import os
import json
from datetime import datetime

def processar_vendas_diarias_json(nome_arquivo_json):
    """
    Lê um arquivo JSON de vendas, processa os dados e gera dois relatórios:
    um em formato texto (.txt) para leitura humana e outro em JSON (.json) com os dados consolidados.
    """
    # 1. Verificar se o arquivo de entrada existe
    if not os.path.exists(nome_arquivo_json):
        print(f"Erro: Arquivo de entrada '{nome_arquivo_json}' não encontrado.")
        return False

    try:
        # 2. Ler e decodificar o arquivo JSON de entrada
        with open(nome_arquivo_json, 'r', encoding='utf-8') as arquivo:
            print(f"Processando arquivo: {nome_arquivo_json}")
            lista_vendas = json.load(arquivo)

        # 3. Processar os dados das vendas
        vendas_por_vendedor = {}
        total_geral = 0

        # Verifica se o JSON é uma lista
        if not isinstance(lista_vendas, list):
            print("Erro: O arquivo JSON de entrada deve conter uma lista de vendas.")
            return False

        for i, venda in enumerate(lista_vendas, 1):
            try:
                vendedor = venda['vendedor']
                valor = float(venda['valor'])

                # Acumular valores
                vendas_por_vendedor[vendedor] = vendas_por_vendedor.get(vendedor, 0) + valor
                total_geral += valor

            except KeyError as e:
                print(f"Aviso: Chave {e} ausente na venda de número {i}. Ignorando registro.")
            except (ValueError, TypeError):
                print(f"Aviso: Valor inválido na venda de número {i} ('{venda.get('valor')}'). Ignorando registro.")

        # --- Geração de Relatórios ---

        # Define um timestamp para os nomes dos arquivos
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')

        # 4. Gerar relatório em formato TEXTO (.txt)
        nome_relatorio_txt = f"relatorio_vendas_{timestamp}.txt"
        with open(nome_relatorio_txt, 'w', encoding='utf-8') as relatorio:
            print("RELATÓRIO DE VENDAS DIÁRIAS", file=relatorio)
            print("=" * 40, file=relatorio)
            print(f"Gerado em: {datetime.now().strftime('%d/%m/%Y às %H:%M:%S')}", file=relatorio)
            print(f"Arquivo origem: {nome_arquivo_json}", file=relatorio)
            print("", file=relatorio)

            relatorio.write("VENDAS POR VENDEDOR:\n")
            relatorio.write("-" * 25 + "\n")

            vendedores_ordenados = sorted(vendas_por_vendedor.items(), key=lambda x: x[1], reverse=True)

            for vendedor, total in vendedores_ordenados:
                linha_vendedor = f"{vendedor:<20}: R$ {total:>10.2f}\n"
                relatorio.write(linha_vendedor)

            print("", file=relatorio)
            print(f"TOTAL GERAL: R$ {total_geral:.2f}", file=relatorio)
            print(f"NÚMERO DE VENDEDORES: {len(vendas_por_vendedor)}", file=relatorio)

            if vendas_por_vendedor:
                media = total_geral / len(vendas_por_vendedor)
                print(f"MÉDIA POR VENDEDOR: R$ {media:.2f}", file=relatorio)

        print(f"Relatório de texto gerado com sucesso: {nome_relatorio_txt}")

        # 5. Gerar relatório/saída em formato JSON (.json)
        nome_relatorio_json = f"resumo_vendas_{timestamp}.json"
        dados_resumo = {
            'data_processamento': datetime.now().isoformat(),
            'arquivo_origem': nome_arquivo_json,
            'total_geral_vendas': round(total_geral, 2),
            'vendas_consolidadas_por_vendedor': vendas_por_vendedor
        }

        with open(nome_relatorio_json, 'w', encoding='utf-8') as saida_json:
            json.dump(dados_resumo, saida_json, indent=4, ensure_ascii=False)

        print(f"Resumo JSON gerado com sucesso: {nome_relatorio_json}")
        print(f"Total processado: R$ {total_geral:.2f}")
        return True

    except json.JSONDecodeError:
        print(f"Erro: O arquivo '{nome_arquivo_json}' não contém um JSON válido.")
        return False
    except Exception as e:
        print(f"Erro inesperado durante o processamento: {e}")
        return False
