    Entrada e saída

    A entrada e saída de dados constituem elementos essenciais em qualquer linguagem de programação, pois possibilitam a comunicação entre o usuário e o programa. As funções fundamentais para lidar com a entrada e saída padrão em Python são input(), responsável por coletar dados do usuário via teclado, e print(), que exibe valores, resultados e mensagens no terminal.

    Além de serem fáceis de usar, essas funções oferecem recursos avançados de formatação e manipulação, como as f-strings, a personalização do separador, do caractere final da linha e a possibilidade de redirecionar a saída. O entendimento dessas ferramentas é o ponto de partida para o desenvolvimento de programas interativos e eficientes, onde a troca de informações com o usuário é fundamental para a execução das tarefas propostas.

    Entrada de dados pelo console¶

    input()¶

    A função input() é uma ferramenta fundamental para a interação entre o usuário e o programa em Python. Ela pausa a execução do programa e aguarda uma informação na entrada padrão (tipicamente, o teclado), retornando sempre uma string com o que foi digitado. Opcionalmente, a função aceita um argumento de texto que é exibido como um prompt para orientar o usuário sobre o que deve ser digitado:

    Python
    1
2
    nome = input("Digite seu nome: ")
print("Você digitou", nome)

    Como input() retorna sempre uma string, quando for necessário trabalhar com outros tipos de dados, como números inteiros ou reais, é essencial realizar a conversão explícita usando funções como int() e float():

    Python
    1
    idade = int(input("Digite sua idade: "))

    .split() e map()¶

    Para entrada múltipla, é comum usar input() com o método .split(), que divide a string em uma lista de substrings com base nos espaços. Combinado com a função map(), é possível converter cada item da lista para o tipo desejado e desempacotá-los diretamente em variáveis:

    Python
    1
2
    a, b = map(int, input("Digite dois números separados por espaço: ").split())
print(f"Soma: {a + b}")

    O método split() pode receber um argumento opcional que especifica o caractere usado como separador. Por exemplo, a string "cachorro,gato,passaro".split(",") resulta na lista ['cachorro', 'gato', 'passaro'], usando a vírgula como separador. Também é permitido usar delimitadores de múltiplos caracteres, como "a><b><c".split("><"), que gera ['a', 'b', 'c'].

    Outra funcionalidade útil é o parâmetro maxsplit, que determina o número máximo de divisões a serem realizadas e, após esse limite, o restante da string permanece intacto como o último elemento da lista, como em "7><1><9".split("><", 1), que produz ['7', '1><9']. Essas opções fazem do split() um método versátil para transformar strings formatadas em listas organizadas, facilitando o tratamento e processamento dos dados.

    Tratamento da entrada de dados¶

    Além disso, é importante tratar algumas situações para tornar o código mais robusto:

    • Entrada vazia: Quando o usuário não digita nada e pressiona Enter, input() retorna uma string vazia (""). É possível verificar essa condição para validar os dados antes de seguir com o processamento.
    • Tratamento de exceções: Em casos de conversão, o programa pode lançar exceções ao tentar converter valores inválidos. O uso do bloco try/except permite capturar esses erros e solicitar uma nova entrada, evitando que o programa termine abruptamente.
    • Captura de interrupção do usuário: Caso o usuário pressione Ctrl+C durante a espera na função input(), uma exceção KeyboardInterrupt é gerada. Capturá-la com try/except possibilita tratar a interrupção de maneira amigável.

    Exemplos de uso de tratamento exceções na manipulação de arquivos estão na seção de tratamento de erros.

    Essas práticas ampliam a usabilidade da função input() , permitindo criar programas interativos mais seguros e amigáveis, capazes de validar e reagir adequadamente às entradas dos usuários.

    Saída de dados pelo console¶

    print()¶

    A função print() exibe valores na saída padrão (tipicamente, o terminal). Por padrão, múltiplos argumentos são separados por espaço e um caractere de nova linha é adicionado ao final. Esse comportamento pode ser alterado com os parâmetros end e sep. O parâmetro opcional end define o caractere a ser impresso ao final da linha, podendo ser uma string vazia ou espaço, e o parâmetro opcional sep indica o separador que será usado entre os argumentos.

    Python
    1
2
3
4
    print("Olá", "Mundo!", end="... ")
print("Continuação na mesma linha")    # Saída: Olá Mundo!... Continuação na mesma linha
print('Dia', 'Mês', 'Ano', sep='/')    # Saída: Dia/Mês/Ano
print('A', 'B', 'C', sep='-')          # Saída: A-B-C

    f-strings¶

    As f-strings, ou "formatted string literals", foram introduzidas no Python 3.6 através da PEP 498 como uma forma de realizar interpolação de strings. Elas permitem que expressões Python sejam embutidas diretamente em literais de string prefixadas pela letra f ou F, com as expressões colocadas dentro de chaves ({}). Essa inovação tornou o código mais legível e conciso, além oferecer melhor desempenho em relação às técnicas anteriores de formatação de texto.

    Antes das f-strings, o Python oferecia principalmente duas opções para interpolação e formatação de strings. A primeira era o operador %, similar ao usado em C, que utiliza especificadores de formato para substituir valores em uma string (ex: print("Olá %s" % nome)). A segunda era o método .format(), introduzido no Python 3.0, que é mais flexível e poderoso, permitindo a formatação por posição ou por nome, além de especificadores detalhados (print("Olá {}".format(nome))). No entanto, ambos se mostraram menos intuitivos e mais verbosos em comparação com as f-strings, que simplificaram a sintaxe ao unir interpolação e formatação dentro da própria string literal, com avaliação dinâmica das expressões em tempo de execução.

    Python
    1
2
3
    nome = "Ana"
idade = 20
print(f"Nome: {nome}, Idade: {idade}")

    Dentro das f-strings, usa-se dois-pontos (:) para aplicar especificadores de formatação, controlando casas decimais, largura, alinhamento e preenchimento. A tabela abaixo apresenta um resumo das opções de formatação disponíveis:

    Tipo de Formatação Valores Possíveis Exemplo de Uso
    Precisão (casas decimais) Números inteiros positivos print(f"{valor:.2f}")
    Largura mínima (número de caracteres) Números inteiros positivos, precedidos ou não de zero print(f"{valor:8}")
    Alinhamento < (esquerda), > (direita), ^ (centralizado) print(f"{texto:<10} {texto:>10} {texto:^10}")
    Preenchimento com caractere Qualquer caractere antes do alinhamento print(f"{valor:*^10}")
    Tipo de valor d (decimal), f (float), % (porcentagem), x/X (hexadecimal), o (octal), b (binário), e/E (exponencial) {valor:d}, {valor:.1%}, {valor:x}, {valor:o}, {valor:b}, {valor:e}
    Sinal + (sempre mostrar), - (mostrar apenas negativos), espaço (mostrar espaço para positivos) print(f"{valor:+} {valor:-} {valor: }")
    Separador de milhares , (vírgula), _ (sublinhado) print(f"{valor:,} {valor:_}")
    Formatação condicional e funções Qualquer expressão ou chamada de função dentro das chaves print(f"{'maior' if idade >= 18 else 'menor'}")

    Entrada e Saída em Arquivos¶

    Embora as operações de entrada e saída via console sejam fundamentais para a interação direta com o usuário, o processamento de dados em grande escala frequentemente requer a manipulação de arquivos. Python oferece recursos para trabalhar com arquivos através da função open() e do gerenciador de contexto #!pythonwith, proporcionando controle sobre o acesso aos dados armazenados e garantindo o fechamento adequado dos recursos do sistema.

    A manipulação de arquivos em Python segue o paradigma de abertura, processamento e fechamento, no qual cada arquivo deve ser explicitamente aberto antes do uso e fechado após o processamento. O gerenciador de contexto with automatiza esse processo, garantindo que os recursos sejam liberados mesmo em situações de erro, tornando o código mais seguro e confiável.

    Abertura de arquivos com with open()¶

    A declaração with open() é a forma recomendada para trabalhar com arquivos em Python. Ela combina a abertura do arquivo com um gerenciador de contexto que assegura o fechamento automático do arquivo ao final do bloco de código, mesmo que ocorram exceções durante o processamento.

    Python
    1
2
3
4
    with open('arquivo.txt', 'r') as arquivo:
    conteudo = arquivo.read()
    print(conteudo)
# O arquivo é automaticamente fechado aqui

    A sintaxe básica requer dois parâmetros obrigatórios: o nome (ou caminho) do arquivo e o modo de abertura. O terceiro parâmetro, encoding, embora opcional, é altamente recomendado para garantir a correta interpretação dos caracteres, especialmente em sistemas que lidam com texto em português.

    Python
    1
2
3
    with open('dados.txt', 'r', encoding='utf-8') as arquivo:
    # Processamento do arquivo
    pass

    Modos de abertura de arquivos¶

    Python oferece diversos modos de abertura que determinam como o arquivo será acessado e manipulado. Cada modo possui características específicas que influenciam as operações disponíveis e o comportamento do programa.

    Modo de leitura ('r')¶

    O modo de leitura é o padrão quando nenhum modo é especificado. Permite apenas a leitura do conteúdo, posicionando o cursor no início do arquivo. Caso o arquivo não exista, uma exceção FileNotFoundError será gerada.

    Python
    1
2
3
4
    # Lendo todo o conteúdo do arquivo
with open('config.txt', 'r', encoding='utf-8') as arquivo:
    conteudo_completo = arquivo.read()
    print(conteudo_completo)
    Modo de escrita ('w')¶

    O modo de escrita cria um novo arquivo ou sobrescreve completamente um arquivo existente. O cursor é posicionado no início, e qualquer conteúdo anterior é permanentemente perdido. Este modo é ideal para gerar relatórios ou arquivos de saída completamente novos.

    Python
    1
2
3
4
5
    # Criando/sobrescrevendo um arquivo
with open('relatorio.txt', 'w', encoding='utf-8') as arquivo:
    arquivo.write("Relatório de Vendas\n")
    arquivo.write("Data: 23/09/2025\n")
    arquivo.write("Total: R$ 15.432,90\n")
    Modo de adição ('a')¶

    O modo de adição preserva o conteúdo existente, posicionando o cursor no final do arquivo. Novas informações são anexadas sem alterar os dados anteriores. É particularmente útil para logs, históricos e arquivos de acumulação de dados.

    Python
    1
2
3
4
    # Adicionando informações ao final do arquivo
with open('log_sistema.txt', 'a', encoding='utf-8') as arquivo:
    arquivo.write("2025-09-23 14:30:15 - Sistema iniciado\n")
    arquivo.write("2025-09-23 14:30:22 - Usuário logado: admin\n")
    Modos binários e combinados¶

    Para trabalhar com arquivos que não contêm texto (imagens, executáveis, arquivos compactados), utiliza-se o sufixo 'b' junto ao modo desejado ('rb', 'wb', 'ab'). Além disso, o modo 'r+' permite leitura e escrita simultaneamente, mantendo o conteúdo existente.

    Usando print() com o parâmetro file¶

    A função print() pode redirecionar sua saída para qualquer objeto que implemente o protocolo de escrita, incluindo arquivos abertos. O parâmetro file permite especificar o destino da saída, mantendo todas as funcionalidades de formatação disponíveis na saída padrão.

    nome = "Maria Silva"
    notas = [ 8.5, 7.2, 9.1 ]
    media = sum(notas) / len(notas)

    print(f"Relatório de Notas", file=arquivo)
    print(f"=" * 20, file=arquivo)
    print(f"Aluno: {nome}", file=arquivo)

    print(f"Média: {media:.2f}", file=arquivo)
    print(f"Status: {'Aprovado' if media >= 7.0 else 'Reprovado'}", file=arquivo)

    Métodos de leitura completa¶

    read()¶

    O método read() carrega todo o conteúdo do arquivo na memória como uma única string. É eficiente para arquivos pequenos, mas pode consumir recursos significativos em arquivos grandes.

    readlines()¶

    O método readlines() retorna uma lista onde cada elemento é uma linha do arquivo, incluindo os caracteres de quebra de linha. Útil quando é necessário processar todas as linhas do arquivo após carregá-las para a memória.

    for i, linha in enumerate(linhas, 1):
        print(f"Linha {i}: {linha.strip()}")  # strip() remove a quebra de linha

        linha = linha.strip()
        if linha and not linha.startswith('#'):  # Ignora linhas vazias e comentários
            partes = linha.split(',')
            if len(partes) >= 2:
                try:
                    valor = float(partes[1])
                    total_vendas += valor
                    contador_linhas += 1
                except ValueError:
                    print(f"Valor inválido encontrado: {linha}")

    if contador_linhas > 0:
        print(f"Total de vendas: R$ {total_vendas:.2f}")
        print(f"Média por transação: R$ {total_vendas/contador_linhas:.2f}")

    Manipulação de JSON em Python¶

    JSON (JavaScript Object Notation) é um formato leve de intercâmbio de dados, amplamente utilizado para comunicação entre sistemas e armazenamento de informações estruturadas. Ele surgiu como uma alternativa simplificada ao XML (Extensible Markup Language), com foco em legibilidade e facilidade de uso por humanos e máquinas. Por ser baseado em texto, JSON pode ser facilmente transmitido entre aplicações, incluindo aquelas escritas em linguagens diferentes, o que o torna um formato popular em APIs, aplicações web e sistemas distribuídos.

    Veja bem, preste atenção!

    Diferente de XML, JSON não aceita comentários. Qualquer tentativa de inserir //, /* ... */ ou # causará erro de leitura ou de validação.

    Essa decisão de design foi tomada intencionalmente por Douglas Crockford, o criador do JSON, por vários motivos, sendo os principais:

    • Evitar diretivas de processamento: Crockford observou que comentários eram, às vezes, usados ​​para incorporar diretivas de processamento ou instruções específicas para determinados processadores de documento. Essa prática poderia levar à falta de interoperabilidade, já que diferentes processadores poderiam interpretar essas diretivas de forma diferente ou nem interpretá-las, potencialmente interrompendo o comportamento pretendido dos dados JSON em vários sistemas;
    • Manter a simplicidade e o foco somente em dados: o JSON foi projetado como um formato leve e genérico para intercâmbio de dados entre máquinas (M2M). A inclusão de comentários adicionaria uma camada de complexidade ao processo de processamento e potencialmente mudaria seu foco da representação pura de dados para um formato mais expressivo, semelhante a uma configuração. O objetivo era manter o JSON como uma estrutura de dados clara e inequívoca, e;
    • Garantir a portabilidade: ao excluir comentários, o JSON garante que os dados em si sejam a única fonte de informação, tornando-os mais portáteis e consistentemente interpretáveis ​​em diferentes linguagens de programação e plataformas, sem preocupações sobre como os comentários podem ser tratados.

    Para um desenvolvedor Python, a estrutura de um documento JSON é imediatamente familiar, pois se assemelha muito a um dicionário aninhado com listas. No entanto, é crucial entender que JSON e dicionários Python não são a mesma coisa. O módulo json do Python atua como uma "ponte", traduzindo (serializando e desserializando) objetos de um formato para o outro.

    As principais diferenças entre dicionários e documentos JSON em Python são:

    Característica Dicionário Python Documento JSON
    Chaves Podem ser de vários tipos imutáveis (strings, números, tuplas). Obrigatoriamente strings, sempre entre aspas duplas.
    Strings Podem ser delimitadas por aspas simples (') ou duplas ("). Obrigatoriamente aspas duplas (").
    Valores Nulos Representados pelo objeto None. Representados pela palavra-chave null.
    Valores Booleanos Representados por True e False (com inicial maiúscula). Representados por true e false (com inicial minúscula).
    Tipos de Dados Suporta uma vasta gama de tipos: int, float, list, dict, tuple, set, etc. Suporta apenas: string, number, object (dicionário), array (lista), boolean e null.

    JSON suporta naturalmente a criação de estruturas hierárquicas e aninhadas, permitindo representar dados complexos por meio de objetos dentro de objetos e listas (arrays) de objetos. Por exemplo, ao modelar informações sobre uma pessoa, pode-se criar um campo "endereço" que, por sua vez, seja um objeto com campos de rua, cidade, número, etc. Da mesma forma, é possível ter listas de objetos, como uma lista de projetos associados a um usuário, cada um descrito em detalhes. Essa flexibilidade faz com que JSON seja ideal para representar árvores de dados, configurações sofisticadas e mensagens de APIs modernas, indo muito além de simples listas planas ou associações diretas de chave-valor.     Outro elemento fundamental é a portabilidade e independência de linguagem: JSON pode ser manipulado nativamente ou por meio de bibliotecas em praticamente todas as linguagens de programação modernas, como Python, JavaScript, Java, C#, PHP e muitas outras. Essa característica consolidou o formato não apenas como uma escolha popular em APIs web, mas também em bancos de dados NoSQL, arquivos de configuração e sistemas distribuídos.

    Escrevendo (Serializando) Objetos Python para JSON¶

    Serializar é o processo inverso: converter um objeto Python (como um dicionário ou lista) em uma string ou arquivo no formato JSON. As funções para esta tarefa são:

    • json.dumps(): Converte (dump string) um objeto Python para uma string formatada em JSON.
    • json.dump(): Escreve um objeto Python diretamente em um arquivo, no formato JSON.

    Essas funções aceitam parâmetros úteis para formatação:

    • indent: Define o número de espaços para a indentação, tornando o resultado legível para humanos (pretty-printing).
    • sort_keys=True: Ordena as chaves do dicionário em ordem alfabética.
    • ensure_ascii=False: Garante que caracteres não-ASCII (como ç, ã) sejam escritos como são, em vez de sequências de escape. É essencial ao trabalhar com encoding='utf-8'.

    import os
import json
from datetime import datetime

def processar_vendas_diarias_json(nome_arquivo_json):
    """
    Lê um arquivo JSON de vendas, processa os dados e gera dois relatórios:
    um em formato texto (.txt) para leitura humana e outro em JSON (.json) com os dados consolidados.
    """
    # 1. Verificar se o arquivo de entrada existe
    if not os.path.exists(nome_arquivo_json):
        print(f"Erro: Arquivo de entrada '{nome_arquivo_json}' não encontrado.")
        return False

    try:
        # 2. Ler e decodificar o arquivo JSON de entrada
        with open(nome_arquivo_json, 'r', encoding='utf-8') as arquivo:
            print(f"Processando arquivo: {nome_arquivo_json}")
            lista_vendas = json.load(arquivo)

        # 3. Processar os dados das vendas
        vendas_por_vendedor = {}
        total_geral = 0

        # Verifica se o JSON é uma lista
        if not isinstance(lista_vendas, list):
            print("Erro: O arquivo JSON de entrada deve conter uma lista de vendas.")
            return False

        for i, venda in enumerate(lista_vendas, 1):
            try:
                vendedor = venda['vendedor']
                valor = float(venda['valor'])

                # Acumular valores
                vendas_por_vendedor[vendedor] = vendas_por_vendedor.get(vendedor, 0) + valor
                total_geral += valor

            except KeyError as e:
                print(f"Aviso: Chave {e} ausente na venda de número {i}. Ignorando registro.")
            except (ValueError, TypeError):
                print(f"Aviso: Valor inválido na venda de número {i} ('{venda.get('valor')}'). Ignorando registro.")

        # --- Geração de Relatórios ---

        # Define um timestamp para os nomes dos arquivos
        timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')

        # 4. Gerar relatório em formato TEXTO (.txt)
        nome_relatorio_txt = f"relatorio_vendas_{timestamp}.txt"
        with open(nome_relatorio_txt, 'w', encoding='utf-8') as relatorio:
            print("RELATÓRIO DE VENDAS DIÁRIAS", file=relatorio)
            print("=" * 40, file=relatorio)
            print(f"Gerado em: {datetime.now().strftime('%d/%m/%Y às %H:%M:%S')}", file=relatorio)
            print(f"Arquivo origem: {nome_arquivo_json}", file=relatorio)
            print("", file=relatorio)

            relatorio.write("VENDAS POR VENDEDOR:\n")
            relatorio.write("-" * 25 + "\n")

            vendedores_ordenados = sorted(vendas_por_vendedor.items(), key=lambda x: x[1], reverse=True)

            for vendedor, total in vendedores_ordenados:
                linha_vendedor = f"{vendedor:<20}: R$ {total:>10.2f}\n"
                relatorio.write(linha_vendedor)

            print("", file=relatorio)
            print(f"TOTAL GERAL: R$ {total_geral:.2f}", file=relatorio)
            print(f"NÚMERO DE VENDEDORES: {len(vendas_por_vendedor)}", file=relatorio)

            if vendas_por_vendedor:
                media = total_geral / len(vendas_por_vendedor)
                print(f"MÉDIA POR VENDEDOR: R$ {media:.2f}", file=relatorio)

        print(f"Relatório de texto gerado com sucesso: {nome_relatorio_txt}")

        # 5. Gerar relatório/saída em formato JSON (.json)
        nome_relatorio_json = f"resumo_vendas_{timestamp}.json"
        dados_resumo = {
            'data_processamento': datetime.now().isoformat(),
            'arquivo_origem': nome_arquivo_json,
            'total_geral_vendas': round(total_geral, 2),
            'vendas_consolidadas_por_vendedor': vendas_por_vendedor
        }

        with open(nome_relatorio_json, 'w', encoding='utf-8') as saida_json:
            json.dump(dados_resumo, saida_json, indent=4, ensure_ascii=False)

        print(f"Resumo JSON gerado com sucesso: {nome_relatorio_json}")
        print(f"Total processado: R$ {total_geral:.2f}")
        return True

    except json.JSONDecodeError:
        print(f"Erro: O arquivo '{nome_arquivo_json}' não contém um JSON válido.")
        return False
    except Exception as e:
        print(f"Erro inesperado durante o processamento: {e}")
        return False
