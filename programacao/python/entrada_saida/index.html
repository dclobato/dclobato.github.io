    Entrada e saída de dados¶

    A entrada e a saída de dados constituem elementos essenciais em qualquer linguagem de programação, pois possibilitam a comunicação entre o usuário e o programa. As funções fundamentais para lidar com a entrada e saída padrão em Python são input(), responsável por coletar dados do usuário via teclado, e print(), que exibe valores, resultados e mensagens no terminal.

    Além de serem fáceis de usar, essas funções oferecem recursos avançados de formatação e manipulação, como as f-strings, a personalização do separador, do caractere final da linha e a possibilidade de redirecionar a saída. O entendimento dessas ferramentas é o ponto de partida para o desenvolvimento de programas interativos e eficientes, nos quais a troca de informações com o usuário é fundamental para a execução das tarefas propostas.

    Entrada de dados pelo console¶

    input()¶

    A função input() é uma ferramenta fundamental para a interação entre o usuário e o programa em Python. Ela pausa a execução do programa e aguarda uma informação na entrada padrão (tipicamente, o teclado), retornando sempre uma string com o que foi digitado. Opcionalmente, a função aceita um argumento de texto que é exibido como um prompt para orientar o usuário sobre o que deve ser digitado:

    Python
    1
2
    nome = input("Digite seu nome: ")
print("Você digitou", nome)

    Como input() retorna sempre uma string, quando for necessário trabalhar com outros tipos de dados, como números inteiros ou reais, é essencial realizar a conversão explícita usando funções como int() e float():

    Python
    1
    idade = int(input("Digite sua idade: "))

    .split() e map()¶

    Para entrada múltipla, é comum usar input() com o método .split(), que divide a string em uma lista de substrings com base nos espaços. Combinado com a função map(), é possível converter cada item da lista para o tipo desejado e desempacotar os valores diretamente em variáveis:

    Python
    1
2
    a, b = map(int, input("Digite dois números separados por espaço: ").split())
print(f"Soma: {a + b}")

    O método split() pode receber um argumento opcional que especifica o caractere usado como separador. Por exemplo, a string "cachorro,gato,passaro".split(",") resulta na lista ['cachorro', 'gato', 'passaro'], usando a vírgula como separador. Também é permitido usar delimitadores de múltiplos caracteres, como "a><b><c".split("><"), que gera ['a', 'b', 'c'].

    Outra funcionalidade útil é o parâmetro maxsplit, que determina o número máximo de divisões a serem realizadas e, após esse limite, o restante da string permanece intacto como o último elemento da lista, como em "7><1><9".split("><", 1), que produz ['7', '1><9']. Essas opções fazem do split() um método versátil para transformar strings formatadas em listas organizadas, facilitando o tratamento e processamento dos dados.

    Tratamento da entrada de dados¶

    Além disso, é importante tratar algumas situações para tornar o código mais robusto:

    • Entrada vazia: Quando o usuário não digita nada e pressiona Enter, input() retorna uma string vazia (""). É possível verificar essa condição para validar os dados antes de seguir com o processamento.
    • Tratamento de exceções: Em casos de conversão, o programa pode lançar exceções ao tentar converter valores inválidos. O uso do bloco try/except permite capturar esses erros e solicitar uma nova entrada, evitando que o programa termine abruptamente.
    • Captura de interrupção do usuário: Caso o usuário pressione Ctrl+C durante a espera na função input(), uma exceção KeyboardInterrupt é gerada. Capturá-la com try/except possibilita tratar a interrupção de maneira amigável.

    Exemplos de uso de tratamento de exceções na manipulação de arquivos estão na seção de tratamento de erros.

    Essas práticas ampliam a usabilidade da função input(), permitindo criar programas interativos mais seguros e amigáveis, capazes de validar e reagir adequadamente às entradas dos usuários.

    Saída de dados pelo console¶

    print()¶

    A função print() exibe valores na saída padrão (tipicamente, o terminal). Por padrão, múltiplos argumentos são separados por espaço e um caractere de nova linha é adicionado ao final. Esse comportamento pode ser alterado com os parâmetros end e sep. O parâmetro opcional end define a cadeia a ser escrita depois dos argumentos, podendo ser uma string vazia ou espaço, e o parâmetro opcional sep indica o separador que será usado entre os argumentos.

    Python
    1
2
3
4
    print("Olá", "Mundo!", end="... ")
print("Continuação na mesma linha")    # Saída: Olá Mundo!... Continuação na mesma linha
print('Dia', 'Mês', 'Ano', sep='/')    # Saída: Dia/Mês/Ano
print('A', 'B', 'C', sep='-')          # Saída: A-B-C

    f-strings¶

    As f-strings, ou "formatted string literals", foram introduzidas no Python 3.6 por meio da PEP 498 como uma forma de realizar interpolação de strings. Elas permitem que expressões Python sejam embutidas diretamente em literais de string prefixados pela letra f ou F, com as expressões colocadas dentro de chaves ({}). Essa inovação tornou o código mais legível e conciso, além de oferecer melhor desempenho em relação às técnicas anteriores de formatação de texto.

    Antes das f-strings, o Python oferecia principalmente duas opções para interpolação e formatação de strings. A primeira era o operador %, que utiliza especificadores de formato para substituir valores em uma string (por exemplo, print("Olá %s" % nome)). A segunda era o método .format(), introduzido no Python 3.0, que é mais flexível e poderoso, permitindo a formatação por posição ou por nome, além de especificadores detalhados (print("Olá {}".format(nome))). No entanto, ambos se mostraram menos intuitivos e mais verbosos em comparação com as f-strings, que simplificaram a sintaxe ao unir interpolação e formatação dentro da própria string literal, com avaliação dinâmica das expressões em tempo de execução.

    Python
    1
2
3
    nome = "Ana"
idade = 20
print(f"Nome: {nome}, Idade: {idade}")

    Dentro das f-strings, usam-se dois-pontos (:) para aplicar especificadores de formatação, controlando casas decimais, largura, alinhamento e preenchimento. A tabela abaixo apresenta um resumo das opções de formatação disponíveis:

    Tipo de Formatação Valores Possíveis Exemplo de Uso
    Precisão (casas decimais) Números inteiros positivos print(f"{valor:.2f}")
    Largura mínima (número de caracteres) Números inteiros positivos, precedidos ou não de zero print(f"{valor:8}")
    Alinhamento < (esquerda), > (direita), ^ (centralizado) print(f"{texto:<10} {texto:>10} {texto:^10}")
    Preenchimento com caractere Qualquer caractere antes do alinhamento print(f"{valor:*^10}")
    Tipo de valor d (decimal), f (float), % (porcentagem), x/X (hexadecimal), o (octal), b (binário), e/E (exponencial) {valor:d}, {valor:.1%}, {valor:x}, {valor:o}, {valor:b}, {valor:e}
    Sinal + (sempre mostrar), - (mostrar apenas negativos), espaço (mostrar espaço para positivos) print(f"{valor:+} {valor:-} {valor: }")
    Normalização do zero negativo z (exibe zero negativo como positivo após o arredondamento; Python 3.11+) print(f"{valor:z.2f}")
    Separador de milhares , (vírgula), _ (sublinhado) print(f"{valor:,} {valor:_}")
    Formatação condicional e funções Qualquer expressão ou chamada de função dentro das chaves print(f"{'maior' if idade >= 18 else 'menor'}")

    Dicas para juízes online¶

    Os juízes online executam o programa com a entrada de cada caso de teste redirecionada para a entrada padrão, como se ela tivesse sido digitada, e comparam a saída padrão com a saída esperada. Algumas práticas evitam respostas erradas e estouros do tempo limite.

    Escreva apenas o que foi pedido¶

    O juiz compara a saída do programa, caractere por caractere, com a saída esperada. Por isso:

    • Não passe mensagens para input(): em input("Digite um número: "), a mensagem é escrita na saída padrão e faz a resposta ser considerada errada. Use input(), sem argumento;
    • Siga exatamente o formato de saída pedido, inclusive espaços, quebras de linha e a quantidade de casas decimais, que pode ser controlada com as f-strings;
    • Mensagens de depuração podem ser escritas no fluxo de erros, com print(..., file=sys.stderr), que normalmente não é comparado pelo juiz. O ideal, porém, é removê-las antes de enviar.

    Lendo até o final da entrada¶

    Muitos problemas não informam quantas linhas serão lidas: o programa deve processar a entrada até o final. Há duas formas de fazer isso:

    soma_linhas.py
    1
2
3
4
5
    import sys

for linha in sys.stdin:
    a, b = map(int, linha.split())
    print(a + b)
    soma_linhas.py
    1
2

4
5
6
7
    while True:
    try:
        linha = input()
    except EOFError:
        break
    a, b = map(int, linha.split())
    print(a + b)

    1 2
10 20
-5 5

    3

0

    O objeto sys.stdin, do módulo sys, pode ser percorrido com um for, que entrega uma linha (com o \n do final) a cada repetição e termina quando a entrada acaba. A função input(), por sua vez, levanta a exceção EOFError quando não há mais nada para ler. Para testar no terminal, o final da entrada é indicado com Ctrl+D no Linux e no macOS, ou com Ctrl+Z seguido de Enter no Windows.

    Leitura rápida¶

    A função input() é prática, mas lenta quando a entrada tem centenas de milhares de linhas. No ambiente do Arena (Python 3.14), ler 1 milhão de inteiros, um por linha, levou:

    Forma de leitura Tempo
    int(input()) em um laço cerca de 1,06 s
    int(sys.stdin.readline()) em um laço cerca de 0,35 s
    sys.stdin.buffer.read().split(), uma única vez cerca de 0,17 s

    A forma mais simples de acelerar um programa que já usa input() é substituir a função no início do programa:

    import sys

input = sys.stdin.readline

    Com isso, todas as chamadas a input() passam a usar sys.stdin.readline, que é bem mais rápida. A diferença é que ela mantém o \n no final da linha: int() e split() ignoram esse caractere, mas, ao ler um texto, é preciso removê-lo com .rstrip("\n") (a linha Maria Clara seria lida como 'Maria Clara\n'). Além disso, no final da entrada, sys.stdin.readline() devolve uma cadeia vazia, em vez de levantar EOFError.

    Quando a entrada é formada só por números (ou palavras) separados por espaços e quebras de linha, uma alternativa que costuma ser rápida é ler tudo de uma vez, quando o volume cabe na memória, e dividir em partes, independentemente de como os valores estão distribuídos nas linhas:

    casos.py
    1
2
3

    import sys

dados = sys.stdin.read().split()
t = int(dados[0])
pos = 1
for caso in range(1, t + 1):
    a, b = int(dados[pos]), int(dados[pos + 1])
    pos += 2
    print(f"Caso #{caso}: {a + b}")

10

    Caso #1: 3
Caso #2: 30
Caso #3: 0

    A variável pos indica o próximo valor a ser usado. Com sys.stdin.buffer.read(), os dados são lidos como bytes, o que é um pouco mais rápido; int() aceita bytes diretamente, mas textos precisam ser convertidos com .decode().

    Saída rápida¶

    Chamar print muitas vezes também tem um custo. No mesmo ambiente, escrever 1 milhão de números, um por linha, levou cerca de 0,45 segundo com um print para cada número, e cerca de 0,15 segundo juntando todas as linhas em uma única cadeia e escrevendo-a de uma vez:

    import sys

resultados = [str(x) for x in range(1_000_000)]
sys.stdout.write("\n".join(resultados) + "\n")

    Guarde os resultados em uma lista ao longo do programa, e escreva tudo no final, com "\n".join(...). Os elementos precisam ser cadeias de caracteres: converta os números com str() (ou com map(str, ...)).

    Problemas interativos¶

    Em alguns problemas, o programa conversa com o juiz: escreve uma pergunta, lê a resposta, escreve outra pergunta, e assim por diante. Quando a saída padrão não é a tela, o que o programa escreve é acumulado em uma área de memória (o buffer) e só é enviado quando ela enche ou quando o programa termina. Nesses problemas, a pergunta precisa chegar ao juiz antes de o programa tentar ler a resposta: use print(..., flush=True), ou chame sys.stdout.flush() depois de cada escrita.

    Recursão profunda¶

    O interpretador limita a profundidade da recursão a cerca de 1000 chamadas, e uma função recursiva que passa desse limite termina com RecursionError. Em problemas com entradas grandes, aumente o limite com sys.setrecursionlimit(10**6), ou reescreva a função com um laço, como mostra a seção sobre recursão.

    Entrada e Saída em Arquivos¶

    Embora as operações de entrada e saída via console sejam fundamentais para a interação direta com o usuário, o processamento de dados em grande escala frequentemente requer a manipulação de arquivos. Python oferece recursos para trabalhar com arquivos por meio da função open() e do gerenciador de contexto with, proporcionando controle sobre o acesso aos dados armazenados e garantindo o fechamento adequado dos recursos do sistema.

    A manipulação de arquivos em Python segue o paradigma de abertura, processamento e fechamento, no qual cada arquivo deve ser explicitamente aberto antes do uso e fechado após o processamento. O gerenciador de contexto with automatiza esse processo, garantindo que os recursos sejam liberados mesmo em situações de erro, tornando o código mais seguro e confiável.

    Abertura de arquivos com with open()¶

    A declaração with open() é a forma recomendada para trabalhar com arquivos em Python. Ela combina a abertura do arquivo com um gerenciador de contexto que assegura o fechamento automático do arquivo ao final do bloco de código, mesmo que ocorram exceções durante o processamento.

    Python
    1
2
3
4
    with open('arquivo.txt', 'r') as arquivo:
    conteudo = arquivo.read()
    print(conteudo)
# O arquivo é automaticamente fechado aqui

    Somente o arquivo é obrigatório em open(): o modo padrão é "r". Para arquivos de texto, indique a codificação por nome, como em open(caminho, "r", encoding="utf-8"). encoding não é o terceiro argumento posicional: essa posição corresponde a buffering. Em modo binário, não informe encoding.

    Python
    1
2
3
    with open('dados.txt', 'r', encoding='utf-8') as arquivo:
    # Processamento do arquivo
    pass

    Modos de abertura de arquivos¶

    Python oferece diversos modos de abertura que determinam como o arquivo será acessado e manipulado. Cada modo possui características específicas que influenciam as operações disponíveis e o comportamento do programa.

    Modo de leitura ('r')¶

    O modo de leitura é o padrão quando nenhum modo é especificado. Permite apenas a leitura do conteúdo, posicionando o cursor no início do arquivo. Caso o arquivo não exista, uma exceção FileNotFoundError será gerada.

    Python
    1
2
3
4
    # Lendo todo o conteúdo do arquivo
with open('config.txt', 'r', encoding='utf-8') as arquivo:
    conteudo_completo = arquivo.read()
    print(conteudo_completo)
    Modo de escrita ('w')¶

    O modo de escrita cria um novo arquivo ou sobrescreve completamente um arquivo existente. O cursor é posicionado no início, e qualquer conteúdo anterior é permanentemente perdido. Este modo é ideal para gerar relatórios ou arquivos de saída completamente novos.

    Python
    1
2
3
4
5
    # Criando/sobrescrevendo um arquivo
with open('relatorio.txt', 'w', encoding='utf-8') as arquivo:
    arquivo.write("Relatório de Vendas\n")
    arquivo.write("Data: 23/09/2025\n")
    arquivo.write("Total: R$ 15.432,90\n")
    Modo de adição ('a')¶

    O modo de adição preserva o conteúdo existente, posicionando o cursor no final do arquivo. Novas informações são anexadas sem alterar os dados anteriores. É particularmente útil para logs, históricos e arquivos de acumulação de dados.

    Python
    1
2
3
4
    # Adicionando informações ao final do arquivo
with open('log_sistema.txt', 'a', encoding='utf-8') as arquivo:
    arquivo.write("2025-09-23 14:30:15 - Sistema iniciado\n")
    arquivo.write("2025-09-23 14:30:22 - Usuário logado: admin\n")
    Modos binários e combinados¶

    contador_linhas = 0

        if linha and not linha.startswith('#'):  # Ignora linhas vazias e comentários
            partes = linha.split(',')

        print(f"Média por transação: R$ {total_vendas/contador_linhas:.2f}")

    def processar_arquivo(nome_arquivo):
    try:
        with open(nome_arquivo, 'r', encoding='utf-8') as arquivo:
            return arquivo.read()
    except FileNotFoundError:
        print(f"Erro: O arquivo '{nome_arquivo}' não foi encontrado.")
        return None
    except PermissionError:
        print(f"Erro: Sem permissão para acessar '{nome_arquivo}'.")
        return None
    except UnicodeDecodeError:
        print(f"Erro: Problema de codificação no arquivo '{nome_arquivo}'.")
        return None
    except Exception as e:
        print(f"Erro inesperado ao processar '{nome_arquivo}': {e}")
        return None

    import os
from datetime import datetime

def criar_backup_seguro(nome_arquivo):
    if os.path.exists(nome_arquivo):
        nome_backup = f"{nome_arquivo}.backup"

        with open(nome_arquivo, 'r', encoding='utf-8') as original:
            with open(nome_backup, 'w', encoding='utf-8') as backup:
                backup.write(original.read())

        print(f"Backup criado: {nome_backup}")
        return True
    else:
        print(f"Arquivo '{nome_arquivo}' não existe.")
        return False

# Exemplo prático
if criar_backup_seguro('configuracao_sistema.txt'):
    # Prosseguir com modificações no arquivo original
    with open('configuracao_sistema.txt', 'a', encoding='utf-8') as arquivo:
        arquivo.write(f"\n# Modificado em {datetime.now()}")
    print("Arquivo modificado com segurança!")
else:
    print("Operação cancelada - arquivo não encontrado.")
