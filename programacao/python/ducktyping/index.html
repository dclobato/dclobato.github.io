    O sistema de tipos dinâmico de Python¶

    Uma das diferenças fundamentais entre C e Python é o sistema de tipos. Em C, o tipo de uma variável é determinado em tempo de compilação e não pode mudar. Em Python, o tipo é determinado em tempo de execução e pode mudar.

    # Variável inicialmente do tipo int
x = 10
print(type(x))  # <class 'int'>

# Mesma variável agora do tipo str
x = "dez"
print(type(x))  # <class 'str'>

# E agora uma lista
x = [1, 2, 3]
print(type(x))  # <class 'list'>

    Python 3.5 introduziu anotações de tipo (type hints), que permitem indicar os tipos esperados, mas são apenas sugestões e não afetam a execução do programa:

    Tipagem Dinâmica vs. Duck Typing¶

    Python segue o princípio "duck typing": "se parece com um pato, nada como um pato e grasna como um pato, então provavelmente é um pato". Isso significa que o tipo específico de um objeto é menos importante que os métodos e propriedades que ele possui.

    class Pato:
    def quack(self):
        print("Quack!")

    def nadar(self):
        print("Splash!")

class Robot:
    def quack(self):
        print("Bip quack!")

    def nadar(self):
        print("Motor ativado, navegando!")

def fazer_pato_agir(pato):
    # Não importa se é um Pato real ou um Robot,
    # desde que implemente quack() e nadar()
    pato.quack()
    pato.nadar()

donald = Pato()
r2d2 = Robot()

fazer_pato_agir(donald)  # Funciona
fazer_pato_agir(r2d2)    # Também funciona!

    Este modelo de programação é muito diferente do sistema de tipos estático de C, permitindo maior flexibilidade e polimorfismo. Embora falte o controle estrito sobre memória e tipos oferecido por C, Python compensa com maior legibilidade, segurança e produtividade para muitos tipos de aplicações.
