    A Criação de um Programa em Python¶

    Quando escrevemos um programa em Python, o código que criamos geralmente é salvo em arquivos com extensão .py, chamados arquivos-fonte. Para executar esse código, utilizamos um interpretador.

    O interpretador processa o código-fonte e executa as instruções do programa. Nas próximas seções, veremos como ele analisa o código, gera uma representação intermediária e a executa.

    Para executar um programa Python, precisamos essencialmente de duas etapas: edição do código-fonte e interpretação. Essa simplicidade é uma das características que tornam Python acessível para iniciantes.

    Vamos analisar essas etapas e entender o papel de cada uma delas.

    Edição do código-fonte¶

    Podemos utilizar qualquer editor de texto para escrever um programa em Python. Para aumentar nossa produtividade, é recomendável usar um ambiente de desenvolvimento integrado (IDE) ou um editor de código específico para programação.

    Python é conhecido por sua legibilidade e simplicidade sintática. Mesmo sem recursos avançados de uma IDE, é possível escrever programas em Python. Ferramentas específicas para a linguagem oferecem vantagens significativas:

    • IDEs completas como PyCharm, Visual Studio Code com extensões Python, ou Spyder oferecem um conjunto abrangente de ferramentas para desenvolvimento Python. Estas incluem destaque de sintaxe, autocompletar, depuração integrada, gerenciamento de pacotes e ferramentas para teste e análise de código.

    • Notebooks interativos como Jupyter Notebook ou Google Colab são particularmente populares para análise de dados, aprendizado de máquina e ensino de Python. Eles permitem combinar código executável, visualizações e texto explicativo em um único documento.

    A escolha do ambiente de desenvolvimento para Python frequentemente depende do caso de uso específico. Por exemplo, cientistas de dados podem preferir notebooks Jupyter, enquanto desenvolvedores de aplicações web podem optar por IDEs mais robustas como PyCharm.

    Uma vantagem significativa para iniciantes é que Python vem com um modo interativo integrado, acessível pelo comando python ou python3 no terminal. Este modo REPL (Read-Eval-Print Loop) permite experimentar comandos Python e ver os resultados imediatamente, sem necessidade de criar, salvar e executar arquivos.

    $ python3
Python 3.14.4 (main, Aug 20 2026, 10:41:58) [GCC 15.2.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> print("Hello, World!")
Hello, World!
>>> 2 + 2
4
>>>

    Este modo interativo é uma ferramenta de aprendizado que permite testar pequenos trechos de código e observar os resultados imediatamente.

    Comentários¶

    Os comentários em Python são elementos não executáveis que fornecem descrições e explicações dentro do código-fonte. Eles ajudam a documentar o código, tornando-o mais compreensível tanto para quem o escreveu quanto para outros desenvolvedores.

    Python oferece comentários de linha única e strings de documentação para registrar explicações sobre o código:

    Os comentários de linha única começam com o caractere #. Tudo o que estiver após esse símbolo até o final da linha será ignorado pelo interpretador Python:

    Exemplo de comentário
    # Este é um comentário de linha única em Python

    As strings de documentação, ou docstrings, são strings literais usadas como documentação de funções, classes e módulos. Elas podem ser acessadas programaticamente e costumam ser delimitadas por três aspas duplas ou simples:

    Exemplo de docstring
    def calcular_area(raio):
    """
    Calcula a área de um círculo.

    Args:
        raio (float): O raio do círculo

    Returns:
        float: A área calculada
    """
    import math
    return math.pi * raio ** 2

    Para comentar blocos inteiros de código, use o caractere # no início de cada linha. Strings delimitadas por aspas triplas são literais de texto, e seu uso como docstrings tem a finalidade de documentar funções, classes e módulos.

    Os comentários em Python são utilizados por várias razões importantes:

    • Eles explicam o raciocínio por trás de decisões complexas de programação
    • Facilitam a revisão de código e a colaboração entre membros da equipe
    • Servem como notas temporárias durante o desenvolvimento
    • Podem desativar temporariamente partes do código durante testes (comentar código)

    As docstrings têm a vantagem adicional de serem acessíveis por meio do atributo __doc__ ou da função help(), o que facilita a criação de documentação automática:

    Consultando a documentação da função `calcular_area`
    >>> help(calcular_area)
Help on function calcular_area in module __main__:

calcular_area(raio)
    Calcula a área de um círculo.

    Args:
        raio (float): O raio do círculo

    Returns:
        float: A área calculada

    As melhores práticas para o uso de comentários em Python incluem:

    • Comentar o "porquê" em vez do "como" (o código já mostra como algo é feito)
    • Manter os comentários atualizados quando o código muda
    • Usar docstrings para documentar funções, classes e módulos
    • Evitar comentários redundantes que apenas repetem o que o código claramente expressa
    • Seguir convenções estabelecidas como a PEP 257 para docstrings

    A filosofia de Python enfatiza a legibilidade do código, conforme expressa no Zen do Python com o princípio "explicit is better than implicit" (explícito é melhor que implícito). Bons comentários contribuem para essa clareza, tornando o código mais acessível e facilitando a manutenção.

    Quando executamos um programa Python, o interpretador realiza as seguintes ações:

    Análise sintática (parsing)¶

    O interpretador Python primeiro verifica o código em busca de erros sintáticos — como parênteses não fechados, indentação incorreta ou uso impróprio de palavras-chave. Se encontrar erros, ele interrompe a execução e exibe uma mensagem de erro.

    Em Python, a indentação define a estrutura dos blocos de código e deve ser usada de forma consistente.

    Compilação para bytecode¶

    Se o código não contiver erros sintáticos, o interpretador Python compila o código-fonte para um formato intermediário chamado bytecode. Este bytecode não é código de máquina específico para um processador, mas sim instruções para a Máquina Virtual Python (PVM).

    Ao importar módulos, o CPython pode guardar o bytecode em arquivos .pyc dentro de __pycache__, evitando recompilar código que continua válido. Esse cache depende da configuração e da permissão de escrita. O arquivo principal executado diretamente como script normalmente não ganha um .pyc automaticamente, e a ausência do cache não impede a execução.

    O bytecode é um código intermediário executado pelo interpretador, sem depender diretamente da arquitetura do processador.

    Execução do bytecode¶

    A Máquina Virtual Python (PVM) executa o bytecode instrução por instrução. Durante essa execução, a PVM gerencia a memória automaticamente (por meio da coleta de lixo), lida com exceções e interage com o sistema operacional subjacente.

    Nesse modelo, o bytecode é interpretado pela PVM, que coordena a execução das instruções e o gerenciamento dos recursos do programa.

    Características do interpretador Python¶

    Tipagem dinâmica: Python verifica os tipos em tempo de execução. Isso permite flexibilidade, mas também significa que erros de tipo podem ser descobertos apenas quando o trecho correspondente é executado.

    # Em Python, podemos mudar o tipo de uma variável durante a execução
x = 5        # x é um inteiro
x = "texto"  # agora x é uma string

    Execução de instruções: o código de um script é analisado e compilado antes de começar sua execução. O fluxo segue as chamadas, condições e repetições do programa, e não necessariamente a ordem das linhas. No REPL, cada entrada completa é processada separadamente.

    Importação de módulos: Quando importamos um módulo em Python, o interpretador procura o módulo, o compila para bytecode (se necessário) e o executa. O estado resultante da execução do módulo (como funções e classes definidas) é então disponibilizado para o código que o importou.

    import math  # O módulo math é carregado e suas funções ficam disponíveis
radius = 5
area = math.pi * radius ** 2

    Modo interativo e execução de scripts: Python pode ser executado interativamente, processando comandos um a um, ou pode executar scripts completos.

    Este modelo de execução dá ao Python características como portabilidade entre plataformas, facilidade de prototipagem e recursos dinâmicos como introspecção e metaclasses.
