    Expressões Regulares: Identificação de Padrões em Texto¶

    Em muitas situações, é necessário identificar padrões dentro de um texto de forma eficiente. Um exemplo prático está na análise de fórmulas químicas: ao receber a representação de uma substância como \(H_2O\) ou \(C_6H_{12}O_6\), pode ser necessário extrair os símbolos dos elementos químicos que a compõem. Realizar essa tarefa manualmente ou com operações básicas de manipulação de strings pode ser trabalhoso e sujeito a erros.

    Este texto contém uma introdução ao assunto. Existem livros inteiros dedicados às expressões regulares, e um dos melhores é em português: o Livro do Piazinho, do Aurélio Marinho Jargas.

    Para testar expressões regulares, e ver se elas fazem o que você gostaria que elas fizessem, também há sites muito bons, entre eles o RegExr, o Regex Learn, o Regular Expressions 101 e uma área especial no site do Livro do Piazinho.

    Definição e Funcionalidade¶

    Expressões regulares constituem uma linguagem formal para definição de padrões em cadeias de caracteres. Elas permitem especificar, de maneira concisa, regras capazes de localizar, extrair ou validar informações em um texto. No cenário da identificação de elementos químicos, é possível definir um padrão que reconheça símbolos químicos — uma letra maiúscula seguida, opcionalmente, de uma ou mais letras minúsculas — e utilizá-lo para extrair todos os elementos presentes em uma fórmula.

    Em Python, o módulo re implementa o suporte completo a expressões regulares, oferecendo funções para busca, substituição e extração de padrões. Métodos convencionais de varredura de strings, baseados em verificações sequenciais de cada caractere, são extensos e pouco flexíveis comparados à elegância e eficiência das expressões regulares.

    Aplicações Práticas¶

    O uso de expressões regulares transcende a análise de fórmulas químicas, sendo aplicável em diversos contextos:

    • Validação de dados: verificação de formatos como endereços de e-mail, números de telefone ou CPF pode ser realizada diretamente com padrões específicos.
    • Processamento de logs: extração de informações relevantes como endereços IP, códigos de status HTTP ou timestamps de arquivos de registro, independentemente da formatação específica.
    • Extração textual: localização sistemática de referências numéricas, unidades de medida ou palavras-chave em documentos extensos.

    Em todos esses casos, as expressões regulares atuam como uma ferramenta fundamental para descrever padrões de texto de maneira compacta e reutilizável, evitando o desenvolvimento de rotinas manuais específicas e proporcionando maior robustez ao código.

    Sintaxe Básica em Python¶

    Literais e Metacaracteres¶

    Os elementos mais simples em uma expressão regular são os literais: caracteres que correspondem exatamente a si mesmos no texto. Por exemplo, o padrão casa encontra a sequência "casa" no texto de entrada. O módulo re oferece funções fundamentais como re.search() para localizar a primeira ocorrência e re.findall() para encontrar todas as ocorrências.

    import re
texto = "A casa amarela tem uma porta azul"

# re.search retorna Match object
resultado = re.search(r'casa', texto)
print(resultado)         # <re.Match object; span=(2, 6), match='casa'>
print(resultado.group()) # 'casa' (aqui sim temos o literal)

# re.findall retorna lista com os literais
todas = re.findall(r'a', texto)
print(todas)             # ['a', 'a', 'a', 'a', 'a']

    No caso de buscas por literais:

    • re.search(): retorna um Match object quando encontra o padrão, não o literal diretamente. Para acessar o literal encontrado, é necessário usar o método .group(). Quando não encontra, retorna None.
    • re.findall(): retorna uma lista contendo os literais encontrados. Quando não encontra nada, retorna uma lista vazia ([]).

    O que é esse r na frente da string da linha 10?

    Em Python, além das f-strings, usadas para formatação, temos as raw strings, usadas quando queremos que uma string seja interpretada literalmente (as is): caracteres de escape como \n, \t ou \\ são tratados como caracteres comuns, não como comandos especiais. Isso é especialmente útil para representar expressões regulares, que frequentemente contêm barras invertidas, como veremos a seguir.

    Nas expressões regulares, os metacaracteres são símbolos especiais que não representam a si mesmos, mas possuem uma função particular ao definir padrões. Em outras palavras, eles têm um significado diferente do literal que aparece na string.

    No Python, os metacaracteres fundamentais são:

    • ^: indica o início da string (ou de uma linha, dependendo do modo usado). Exemplo: ^a corresponde a qualquer string que comece com a letra a. ^Python encontra Python é ótimo, mas não Eu uso Python.

    • $: indica o final da string (ou de uma linha). Exemplo: a$ corresponde a qualquer string que termine com a letra a. Python$ encontra Eu programo em Python, mas não Python é ótimo.

    • .: representa qualquer caractere, exceto quebra de linha (por padrão). Exemplo: a.b corresponde a aab, acb, a_b ou a3b, mas não a ab. Muito útil quando você sabe a estrutura, mas não o caractere específico.

    • \: o caractere de escape. Transforma símbolos especiais em literais. Exemplo: \. corresponde a um ponto literal na string (como em exemplo.com). \$ encontra o símbolo de cifrão, não o final da string.

    • |: operador de alternativa (OR lógico). Permite escolher entre opções. Exemplo: gato|cachorro encontra tanto gato quanto cachorro. (jpg|png|gif)$ valida extensões de arquivos de imagem.

    • (): cria grupos para captura ou aplicação de operadores. Exemplo: (Python|Java) agrupa as alternativas. Permite extrair partes específicas do padrão encontrado.

    Veja bem, preste atenção!

    Note que metacaracteres são diferentes de quantificadores (*, +, ?, {}), que controlam repetições, e classes predefinidas (\d, \w, \s), que são atalhos para conjuntos comuns de caracteres. Cada categoria tem seu papel específico na construção de padrões eficazes.

    Classes de Caracteres¶

    Classes de caracteres permitem especificar conjuntos de caracteres válidos usando colchetes. A expressão [aeiou] corresponde a qualquer vogal, enquanto [0-9] corresponde a qualquer dígito. O símbolo ^ dentro da classe nega o conjunto: [^0-9] corresponde a qualquer caractere que não seja dígito.

    Python
    1
2
3
4
5
    # Encontrar qualquer vogal
vogais = re.findall(r'[aeiouAEIOU]', "Expressões Regulares")

# Encontrar caracteres que não são letras
nao_letras = re.findall(r'[^a-zA-Z]', "Python 3.9!")

    Existem classes predefinidas convenientes: \d (dígitos), \w (caracteres alfanuméricos), \s (espaços em branco) e suas versões negadas \D, \W, \S.

    Intervalos e Ranges¶

    Intervalos dentro de classes de caracteres utilizam o hífen para definir sequências: [a-z] representa letras minúsculas, [A-Z] maiúsculas, [0-9] dígitos. Múltiplos intervalos podem ser combinados: [a-zA-Z0-9] aceita letras e números.

    Python
    1
2
3
    # Validar se uma string começa com uma letra ou um número
padrao = r'^[a-zA-Z0-9]'
resultado = re.match(padrao, "Python3")  # Retorna match

    Quantificadores¶

    Quantificadores especificam a quantidade de repetições do elemento anterior:

    • *: zero ou mais ocorrências
    • +: uma ou mais ocorrências
    • ?: zero ou uma ocorrência (opcional)
    • {n}: exatamente \(n\) ocorrências
    • {n,}: \(n\) ou mais ocorrências
    • {n,m}: entre \(n\) e \(m\) ocorrências
    Python
    1
2
3
4
    # Diferentes quantificadores em ação
telefone = re.search(r'\d{2} \d{4,5}-\d{4}', "11 9876-5432")  # 2 dígitos, espaço, 4 ou 5 dígitos, hífen, 4 dígitos
email = re.search(r'\w+@\w+\.\w+', "usuario@dominio.com")     # Um ou mais caracteres alfanuméricos
codigo = re.findall(r'[A-Z]{3}\d?', "ABC1 DEF XYZ2")          # 3 letras maiúsculas seguidas de dígito opcional

    Agrupamento e Captura¶

    Parênteses criam grupos que podem ser referenciados e extraídos separadamente. Os grupos numerados começam em 1 e podem ser acessados através do método .group():

    Python
    1
2
3
4
5
6
7
    # Extrair partes específicas de um padrão
data = re.search(r'(\d{2})/(\d{2})/(\d{4})', "25/12/2023")
if data:
    dia = data.group(1)    # '25'
    mes = data.group(2)    # '12'
    ano = data.group(3)    # '2023'
    completa = data.group(0)  # '25/12/2023'

    Grupos nomeados utilizam a sintaxe (?P<nome>...) para maior clareza:

    Python
    1
2
3
4
5
    # Uso de grupos nomeados para melhor legibilidade
elemento = re.search(r'(?P<simbolo>[A-Z][a-z]*)(?P<numero>\d*)', "H2O")
if elemento:
    simbolo = elemento.group('simbolo')  # 'H'
    numero = elemento.group('numero')    # '2'

    Esta sintaxe fundamental permite construir padrões sofisticados para resolver problemas complexos de processamento textual de forma concisa e eficiente.

    Métodos Principais do Módulo re¶

    Além das funções re.search() e re.findall() já apresentadas, o módulo re oferece outros métodos essenciais para manipulação de texto baseada em padrões.

    re.match() - Correspondência no Início¶

    O método re.match() verifica se o padrão corresponde apenas no início da string. Se a correspondência não começar na primeira posição, retorna None.

    Python
    1
2
3
4

7

    import re

texto = "Python é uma linguagem poderosa"
resultado1 = re.match(r'Python', texto)    # Encontra (início da string)
resultado2 = re.match(r'linguagem', texto) # None (não está no início)

if resultado1:
    print(f"Encontrado: {resultado1.group()}")  # "Python"

    Uso típico: validação de formatos que devem seguir estrutura específica desde o início, como códigos de identificação ou protocolos de URL.

    re.fullmatch() - Correspondência Completa¶

    O método re.fullmatch() exige que o padrão corresponda exatamente a toda a string, do início ao fim. É mais restritivo que re.match().

    Python
    1

    # Validação rigorosa de formato
email = "usuario@dominio.com"
padrao_email = r'\w+@\w+\.\w+'

resultado1 = re.fullmatch(padrao_email, email)           # Match completo
resultado2 = re.fullmatch(padrao_email, "email: " + email) # None (texto extra)

if resultado1:
    print("Email válido!")

    Uso típico: validação estrita onde a string deve conter apenas o padrão especificado, sem caracteres extras.

    re.match e re.fullmatch podem ser substituidos pelo re.search com o uso dos metacaracteres ^ e $?

    Tecnicamente, sim, você pode substituir re.fullmatch por re.search com esses metacaracteres. Mas qual a diferença prática?

    Apesar de equivalentes quanto ao resultado, existem alguns pontos importantes:

    • Legibilidade e intenção clara: re.fullmatch(r'\d+', texto) deixa imediatamente explícito que esperamos a string toda como dígitos.
    • Consistência de API: O Python fornece re.match, re.fullmatch, re.search e re.findall justamente para expressar intenções distintas sem precisar decorar âncoras sempre. São os chamados conveniences methods (métodos de conveniência) que tornam o código mais legível e intencionalmente claro.
    • Manutenção de código: Usar re.fullmatch evita erros caso alguém esqueça de incluir os dois metacaracteres (^ e $) no padrão.
    • Desempenho: Os métodos específicos são otimizados internamente. re.match() pode parar imediatamente se não encontrar correspondência no início; re.fullmatch() é otimizado para validação completa, e; re.search() com âncoras precisa processar os metacaracteres adicionais.

    re.finditer() - Iterador de Correspondências¶

    O método re.finditer() retorna um iterador que produz objetos Match para cada correspondência encontrada no texto. Diferentemente de re.findall() que retorna apenas as strings correspondentes, re.finditer() preserva informações detalhadas sobre cada correspondência. Isso é útil quando se deseja não apenas as strings encontradas, mas também dados adicionais sobre a posição ou para iterar eficientemente sobre grandes volumes de texto sem carregar todas as correspondências na memória.

    texto = "Os preços são: R$ 25,90, R$ 150,00 e R$ 8,75"
padrao = r'R\$\s*(\d+),(\d{2})'

# Usando re.findall() - só os grupos capturados
valores_findall = re.findall(padrao, texto)
print("findall():", valores_findall)  # [('25', '90'), ('150', '00'), ('8', '75')]

# Usando re.finditer() - objetos Match completos
for match in re.finditer(padrao, texto):
    preco_completo = match.group(0)  # Toda a correspondência
    reais = match.group(1)           # Primeiro grupo (parte antes da vírgula)
    centavos = match.group(2)        # Segundo grupo (parte após a vírgula)
    posicao = match.span()           # Posição no texto

    print(f"Preço: {preco_completo} | Posição: {posicao} | Reais: {reais} | Centavos: {centavos}")

    O método re.split() divide uma string usando um padrão como delimitador, oferecendo mais flexibilidade que o método convencional str.split().

texto = "Python,Java;C++|JavaScript"
linguagens = re.split(r'[,;|]', texto)

# Divisão por espaços variáveis
frase = "palavra1    palavra2  palavra3"
palavras = re.split(r'\s+', frase)  # \s+ = um ou mais espaços
print(palavras)  # ['palavra1', 'palavra2', 'palavra3']

# Limitando o número de divisões
dados = "nome:idade:cidade:pais"
campos = re.split(r':', dados, maxsplit=2)
print(campos)  # ['nome', 'idade', 'cidade:pais']

    Uso típico: processamento de dados com delimitadores variáveis ou múltiplos, parsing de arquivos CSV malformados, ou limpeza de texto com espaçamento inconsistente.

    # Substituição simples
texto = "Contato: (11) 99999-8888 ou (21) 88888-7777"
texto_limpo = re.sub(r'[()-]', '', texto)  # Remove parênteses e hífens

datas = "25/12/2023 e 31/01/2024"

# Limitando substituições
codigo = "var x = 10; var y = 20; var z = 30;"
novo_codigo = re.sub(r'var', 'let', codigo, count=2)  # Apenas as 2 primeiras
print(novo_codigo)  # "let x = 10; let y = 20; var z = 30;"

# Substituição com função personalizada
def maiuscula_match(match):
    return match.group().upper()

texto = "python java c++"
resultado = re.sub(r'\w+', maiuscula_match, texto)
print(resultado)  # "PYTHON JAVA C++"

    Características importantes:

    • Grupos numerados: \1, \2, \3 referenciam grupos capturados na substituição
    • Parâmetro count: limita o número de substituições realizadas
    • Função de substituição: permite lógica personalizada baseada no match encontrado

    Objetos Match¶

    Quando uma função como re.search() ou re.match() encontra uma correspondência, ela retorna um objeto do tipo Match. Esse objeto contém informações detalhadas sobre a ocorrência encontrada e métodos para extrair dados específicos dessa correspondência.

    Os principais ,étodos e propriedades principais do objeto Match são:

    • .group(): retorna o texto exato que correspondeu ao padrão. Se o padrão casa com "Python" em "Python é ótimo", match.group() retorna "Python". Pode receber um número ou nome para recuperar grupos capturados, ou seja, match.group(1) retorna o conteúdo do primeiro grupo entre parênteses;
    • .start(): retorna o índice (posição) do início da correspondência na string original;
    • .end(): retorna o índice logo após o fim da correspondência na string original;
    • .span(): retorna uma tupla (início, fim) indicando os índices da substring que correspondeu ao padrão. É equivalente a (match.start(), match.end());
    • .groups(): retorna uma tupla com todos os grupos capturados pela expressão regular, na ordem;
    • .groupdict(): retorna um dicionário com grupos nomeados capturados, onde as chaves são os nomes dos grupos e os valores são as strings capturadas;
