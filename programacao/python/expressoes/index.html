    Expressões e operadores em Python¶

    Nas subseções a seguir, letras minúsculas como a e b representam valores literais ou nomes de variáveis, o que for apropriado no contexto. Ao avaliar uma expressão, os seguintes operadores podem ser usados.

    Expressões e operadores aritméticos¶

    Uma expressão aritmética em Python é construída a partir de operadores aritméticos e variáveis ou constantes numéricas. Python suporta uma ampla gama de operadores aritméticos, alguns semelhantes aos de C e outros específicos da linguagem.

    Operador Sintaxe Exemplo e/ou observações
    Adição a + b Também usado para concatenação de sequências
    Subtração a - b
    Mais unário +a Geralmente não altera o valor de a
    Menos unário (inverso aditivo) -a
    Multiplicação a * b Também usado para repetição de sequências ("abc" * 3 resulta em "abcabcabc")
    Divisão a / b Sempre resulta em um número de ponto flutuante, mesmo quando os operandos são inteiros
    Divisão inteira a // b Retorna o maior inteiro menor ou igual ao quociente (arredonda para baixo)
    Módulo a % b Resto da divisão de a por b
    Exponenciação a ** b Eleva a à potência de b

    Diferentemente de C, Python não possui operadores de incremento/decremento (++ ou --). Para aumentar ou diminuir o valor de uma variável, deve-se usar operadores de atribuição combinada como a += 1 ou a -= 1.

    No que diz respeito à conversão de tipos em operações aritméticas, Python também realiza coerção de tipos, mas com regras ligeiramente diferentes das de C:

    1. Se qualquer operando for um número complexo, o resultado será complexo
    2. Se qualquer operando for um número de ponto flutuante, o resultado será de ponto flutuante
    3. Se todos os operandos forem inteiros, o resultado será inteiro, exceto para a divisão normal (/), que sempre retorna um número de ponto flutuante

    Veja bem, preste atenção!

    Uma diferença significativa em relação ao C é o comportamento da divisão. Em Python 3, a divisão com o operador / sempre resulta em um número de ponto flutuante, mesmo quando os operandos são inteiros. Para obter uma divisão inteira (semelhante à divisão inteira em C), use o operador //.

    print(5 / 2)  # Resulta em 2.5
print(5 // 2) # Resulta em 2

    Isso elimina uma fonte comum de erros que existe em C, onde a divisão de inteiros pode silenciosamente truncar o resultado.

    Operadores lógicos¶

    Python usa palavras-chave em vez de símbolos para operadores lógicos, o que torna o código mais legível.

    Operador Sintaxe Exemplo e/ou observações
    NOT not a Nega o valor de a
    AND a and b Será verdadeiro apenas quando a e b forem verdadeiros
    OR a or b Será falso apenas quando a e b forem falsos

    As tabelas de verdade são idênticas às de C:

    a AND b
    Verdadeiro Verdadeiro Verdadeiro
    Verdadeiro Falso Falso
    Falso Falso Verdadeiro
    Falso Falso Falso
    a OR b
    Verdadeiro Verdadeiro Verdadeiro
    Verdadeiro Verdadeiro Falso
    Falso Verdadeiro Verdadeiro
    Falso Falso Falso
    NOT a
    Falso Verdadeiro
    Verdadeiro Falso

    Assim como em C, Python também implementa avaliação de curto-circuito para os operadores lógicos:

    • Para a and b, se a for falso, b não é avaliado e o resultado é a
    • Para a or b, se a for verdadeiro, b não é avaliado e o resultado é a

    Uma diferença significativa em relação ao C é que os operadores lógicos em Python não retornam necessariamente valores booleanos (True ou False), mas sim o último valor avaliado. Isso permite construções concisas como:

    # Se entrada_do_usuario for vazia, nome será "Anônimo"
nome = entrada_do_usuario or "Anônimo"

    Em Python, os seguintes valores são considerados falsos:

    • False
    • None
    • Zero de qualquer tipo numérico: 0, 0.0, 0j
    • Sequências vazias: '', [], ()
    • Dicionários vazios: {}
    • Conjuntos vazios: set()

    Todos os outros valores são considerados verdadeiros.

    Operadores relacionais¶

    Python oferece os mesmos operadores relacionais que C, com algumas adições úteis.

    Operação Sintaxe Exemplo e/ou observações
    Igual a a == b a igual a b
    Não igual a
    (diferente de)    		 a != b a não igual (diferente) a b
    Maior que a > b a maior que b
    Menor que a < b a menor que b
    Maior ou igual a a >= b a maior ou igual a b
    Menor ou igual a a <= b a menor ou igual a b
    Identidade a is b Verifica se a e b referem-se ao mesmo objeto em memória
    Não identidade a is not b Verifica se a e b não referem-se ao mesmo objeto
    Contém a in b Verifica se a está contido em b (para sequências e coleções)
    Não contém a not in b Verifica se a não está contido em b

    Uma característica poderosa de Python é que os operadores relacionais podem ser encadeados, o que não é possível em C. Por exemplo:

    Encadeamento de operadores relacionais
    # Em Python, isso funciona como esperado
if 10 < n < 50:
    print("n está entre 10 e 50")

# Equivalente a:
if 10 < n and n < 50:
    print("n está entre 10 e 50")

    Os operadores is e is not verificam a identidade do objeto, não o valor. Isso é diferente de == e !=, que verificam a igualdade de valor:

    Identidade vs igualdade
    a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)  # True, pois os valores são iguais
print(a is b)  # False, pois são objetos diferentes em memória
print(a is c)  # True, pois a e c referem-se ao mesmo objeto

    Os operadores in e not in são usados para verificar a pertinência em coleções:

    print(3 in [1, 2, 3, 4])        # True
print('a' in 'python')          # False
print('chave' in {'chave': 42}) # True, verifica as chaves do dicionário

    Veja bem, preste atenção!

    Diferentemente de C, em Python não há confusão possível entre o operador de atribuição (=) e o operador de igualdade (==) em expressões condicionais, pois atribuições não são expressões que retornam valores. Uma atribuição dentro de uma condição resultará em erro de sintaxe:

    # Isso causará um erro de sintaxe em Python
if (a = b):
    print("Isso não funciona em Python")

    Operadores de bit¶

    Python suporta os mesmos operadores de bit que C.

    Operação Sintaxe Exemplo e/ou observações
    NOT ~a Inverte os bits de a
    AND a & b Efetua a operação AND bit-a-bit
    OR a | b Efetua a operação OR bit-a-bit
    XOR a ^ b Efetua a operação XOR bit-a-bit
    Deslocamento à esquerda a << b Desloca os bits para a esquerda
    Deslocamento à direita a >> b Desloca os bits para a direita

    Em Python, esses operadores funcionam primariamente com inteiros, embora alguns como &, |, e ^ também sejam sobrecarregados para trabalhar com o tipo set (conjunto), realizando operações de interseção, união e diferença simétrica, respectivamente.

    Os operadores de deslocamento têm o mesmo efeito de multiplicação e divisão por potências de 2, como em C:

    • a << b é equivalente a a * (2 ** b)
    • a >> b é equivalente a a // (2 ** b)

    Uma diferença notável é que Python suporta inteiros de precisão arbitrária, então você não precisa se preocupar com overflow em operações de deslocamento.

    Operadores de atribuição¶

    Python oferece operadores de atribuição combinada semelhantes aos de C.

    Operação Sintaxe Exemplo e/ou observações
    Atribuição a = b Atribui o valor de b à variável a
    Adição combinada a += b Equivalente a a = a + b
    Subtração combinada a -= b Equivalente a a = a - b
    Multiplicação combinada a *= b Equivalente a a = a * b
    Divisão combinada a /= b Equivalente a a = a / b
    Divisão inteira combinada a //= b Equivalente a a = a // b
    Módulo combinado a %= b Equivalente a a = a % b
    Exponenciação combinada a **= b Equivalente a a = a ** b
    AND bit-a-bit combinado a &= b Equivalente a a = a & b
    OR bit-a-bit combinado a |= b Equivalente a a = a | b
    XOR bit-a-bit combinado a ^= b Equivalente a a = a ^ b
    Deslocamento à esquerda combinado a <<= b Equivalente a a = a << b
    Deslocamento à direita combinado a >>= b Equivalente a a = a >> b

    Python também suporta atribuição múltipla e atribuição de desempacotamento, recursos que não existem em C:

    # Atribuição múltipla
a, b = 1, 2

# Troca de valores sem variável temporária
a, b = b, a

# Desempacotamento de sequência
x, y, z = [1, 2, 3]

# Desempacotamento com resto (Python 3.0+)
primeiro, *resto = [1, 2, 3, 4, 5]  # primeiro = 1, resto = [2, 3, 4, 5]

    Python 3.8 introduziu o operador de atribuição walrus (:=), que permite atribuir valores a variáveis como parte de uma expressão:

    # Sem o operador walrus
data = obter_dados()
if data:
    processar(data)

# Com o operador walrus
if data := obter_dados():
    processar(data)

    Operador de fatiamento¶

    O operador de fatiamento é uma característica poderosa de Python que não existe em C:

    Python
    1
2
3
4
    lista = [0, 1, 2, 3, 4, 5]
print(lista[1:4])     # [1, 2, 3]
print(lista[::2])     # [0, 2, 4]
print(lista[::-1])    # [5, 4, 3, 2, 1, 0] (invertido)

    O operador de fatiamento (a[b:c:d]) funciona selecionando, de a, os elementos de b até antes de c, d a d.

    Em Python, os índices negativos contam a partir do final da sequência. O índice -1 representa o último elemento, -2 o penúltimo e assim sucessivamente. Quando utilizamos estes índices negativos em operações de fatiamento, podemos manipular sequências de formas bastante elegantes. Consideremos o seguinte exemplo:

    texto = "Programação de Redes de Computadores"

# Fatiamento simples com índices negativos
print(texto[-10:])         # Extrai os 10 últimos caracteres
print(texto[-22:-12])      # Extrai uma seção do meio usando índices negativos
print(texto[:-15])         # Do início até 15 caracteres antes do final
print(texto[-20:-5:2])     # Do caractere -20 até -5 pulando de 2 em 2
print(texto[::-1])         # Inverte a string completa

    Computadores
Redes de Co

serodatupmoC ed sedeR ed oãçamargorP

    Os índices negativos são particularmente úteis quando você precisa trabalhar com o final de uma sequência sem conhecer seu tamanho exato, tornando o código mais elegante e adaptável a diferentes entradas.

    Precedência dos operadores¶

    Assim como em C, Python segue uma ordem específica ao avaliar expressões com múltiplos operadores. A tabela abaixo mostra os operadores em ordem decrescente de prioridade (do mais alto para o mais baixo).

    Operador Descrição
    () [] . Chamadas, indexação, atributos
    ** Exponenciação
    +x -x ~x Unários positivo, negativo, NOT bit-a-bit
    * / // % Multiplicação, divisão, div. inteira, módulo
    + - Adição, subtração
    << >> Deslocamentos
    & AND bit-a-bit
    ^ XOR bit-a-bit
    \| OR bit-a-bit
    == != > >= < <= is is not in not in Comparações, igualdade, identidade, pertinência
    not NOT lógico
    and AND lógico
    or OR lógico
    := Atribuição de expressão (Python 3.8+)
    lambda Expressão lambda
    if else Operador condicional
    = += -= etc. Atribuição

    Quando os operadores têm a mesma precedência, a associatividade determina a ordem de avaliação. A maioria dos operadores em Python associa da esquerda para a direita, exceto a exponenciação (**) que associa da direita para a esquerda.

    # Exemplos que demonstram precedência
print(2 + 3 * 4)          # 14 (multiplicação antes da adição)
print((2 + 3) * 4)         # 20 (parênteses alteram a precedência)
print(2 ** 3 ** 2)         # 512 (2 ** 9, a exponenciação associa da direita para a esquerda)
print(not True or False)   # False (NOT tem precedência sobre OR)

    A clara compreensão da precedência de operadores é fundamental para escrever expressões complexas corretamente, mas em caso de dúvida, é sempre recomendável usar parênteses para tornar a intenção explícita – uma prática que também melhora a legibilidade do código.
