    Tipos de Dados em Python¶

    Em Python, os tipos de dados definem as características de armazenamento, operações permitidas e comportamento para valores de dados. Diferentemente de C, Python é uma linguagem com tipagem dinâmica, o que significa que o tipo de uma variável é determinado em tempo de execução e pode mudar ao longo do programa. Além disso, Python não requer declarações explícitas de tipos.

    Mutabilidade¶

    A mutabilidade é um conceito essencial em Python que se refere à capacidade de um objeto ter seu valor alterado após a sua criação. Compreender a distinção entre objetos mutáveis e imutáveis é crucial para evitar erros.

    Em Python, objetos imutáveis são aqueles cujo conteúdo não pode ser alterado após serem criados. Quando tentamos modificar um objeto imutável, o Python na verdade cria um novo objeto com o valor modificado. Por outro lado, objetos mutáveis podem ter seu conteúdo alterado sem criar um novo objeto.

    Tipos numéricos¶

    Tipo Descrição Exemplo
    int Números inteiros de precisão arbitrária 42, -7, 0
    float Números de ponto flutuante (equivalente a double em C) 3.14, -0.001, 2.0
    complex Números complexos com partes real e imaginária 3+4j, 2.5-1j

    Uma diferença fundamental em relação ao C é que os inteiros em Python têm precisão arbitrária, o que significa que eles podem crescer para acomodar qualquer valor inteiro, limitados apenas pela memória disponível. Não há conceitos como short, long ou unsigned como em C.

    Exemplos de uso de tipos numéricos

b = 1 - 2j
c = a * b  # Resulta em (8+j)

    Sequências de escape em strings¶

    Python suporta muitas das mesmas sequências de escape que C para representar caracteres especiais em strings:

    Sequência Significado
    \a Alerta (bipe, sino)
    \b Backspace
    \f Avanço/quebra de página
    \n Avanço de linha
    \r Retorno de carro
    \t Tabulação horizontal
    \v Tabulação vertical
    \\ Barra invertida (backslash)
    \' Apóstrofo, ou aspas simples
    \" Aspas duplas
    \xhh Caractere com valor hexadecimal hh
    \uxxxx Caractere Unicode de 16 bits com valor xxxx
    \Uxxxxxxxx Caractere Unicode de 32 bits com valor xxxxxxxx

    Python tem três formas principais de strings:

    • Strings normais: Delimitadas por aspas simples (') ou duplas (")
    • Strings brutas (raw strings): Prefixadas com r, não processam sequências de escape
    • Strings de múltiplas linhas: Delimitadas por três aspas simples (''') ou três aspas duplas (""")

    Listas (list)¶

    As listas em Python são estruturas de dados poderosas que funcionam como sequências ordenadas e mutáveis. Diferentemente dos arrays em C, as listas em Python possuem um tamanho dinâmico e podem armazenar elementos de diferentes tipos. Além disso, elas oferecem uma série de métodos incorporados que facilitam a manipulação dos dados:

    • Tamanho dinâmico: enquanto arranjos em C possuem um tamanho fixo, as listas em Python podem crescer e diminuir conforme necessário;
    • Armazenamento de diferentes tipos: em C, todos os elementos de um arranjo devem ser do mesmo tipo, enquanto em Python, uma lista pode conter elementos de diferentes tipos (inteiros, strings ou outras listas, por exemplo);
    • Métodos integrados: Python fornece uma grande quantidade de métodos para manipulação de listas, como inserção, remoção, ordenação e busca;
    • Gerenciamento de memória: em C, o programador deve gerenciar a alocação e desalocação de memória, enquanto em Python, o interpretador gerencia automaticamente a memória das listas.
    Manipulando listas
    # Criando uma lista
numeros = [1, 2, 3, 4]

# Tamanho da lista
print(len(numeros))    # 4

# Modificando um elemento
numeros[0] = 10        # [10, 2, 3, 4]

# Adicionando elementos
numeros.append(5)      # [10, 2, 3, 4, 5]
numeros.insert(2, 99)  # Insere 99 na posição 2 -> [10, 2, 99, 3, 4, 5]

# Removendo elementos
numeros.remove(2)      # Remove o primeiro 2 encontrado -> [10, 99, 3, 4, 5]
ultimo = numeros.pop() # Remove e retorna o último elemento -> [10, 99, 3, 4]
segundo = numeros.pop(1) # Remove e retorna o elemento na posição 1 -> [10, 3, 4]

# Ordenação
numeros.sort()         # Ordena a lista em ordem crescente
print(numeros)         # [3, 4, 10]
numeros.sort(reverse=True)  # Ordena em ordem decrescente (o mesmo que numeros.reverse())
print(numeros)         # [10, 4, 3]

# Contagem e busca
quantidade_tres = numeros.count(3) # Conta quantas vezes 3 aparece na lista
indice = numeros.index(4)  # Retorna o índice da primeira ocorrência de 4
print(3 in numeros)  # True
print(100 in numeros)  # False

# Recomeçando
numeros = [1, 2, 3, 4]

# Fatiamento (slicing)
sublista = numeros[1:3]  # Elementos do índice 1 ao 2 [2, 3]
inicio = numeros[:2]     # Primeiros dois elementos [1, 2]
fim = numeros[2:]        # Do terceiro elemento até o final [3, 4]
inverso = numeros[::-1]  # Inverte a lista [4, 3, 2, 1]

    Dicionários (dict)¶

Diferentemente de listas, que são indexadas numericamente, os dicionários utilizam chaves imutáveis (como strings, números e tuplas) para organizar e recuperar informações de maneira eficiente.

    Faixa (range)¶

    O tipo range gera uma sequência imutável de números e é especialmente eficiente para representar grandes sequências de números. Diferentemente de uma lista, um range não armazena todos os valores em memória; em vez disso, ele mantém apenas os parâmetros necessários para calcular os valores conforme necessário. Isso o torna muito mais eficiente em termos de uso de memória.

    O range pode ser criado de três formas:

    • Com um único argumento: define o valor final, assumindo início em 0 e passo de 1;
    • Com dois argumentos: define início e fim, ainda assumindo passo de 1, e;
    • Com três argumentos: define início, fim e passo explicitamente.

r2 = range(2, 6)       # Representa [2, 3, 4, 5]
r3 = range(1, 10, 2)   # Representa [1, 3, 5, 7, 9]
r4 = range(10, 0, -2)  # Representa [10, 8, 6, 4, 2] (passo negativo)

    Se for necessário armazenar todos os valores gerados por um range, podemos convertê-lo em uma lista com list().

    Tuplas (tuple)¶

    As tuplas são similares às listas, mas imutáveis. Esta imutabilidade torna as tuplas úteis para representar coleções de dados que não devem ser alterados, como coordenadas, configurações ou registros.

    Manipulando tuplas
    coordenadas = (10, 20)
# A linha abaixo gerará um erro
# coordenadas[0] = 15

# Para "modificar", criamos uma nova tupla
novas_coordenadas = (15,) + coordenadas[1:]
print(novas_coordenadas)  # Saída: (15, 20)
print(coordenadas)        # A tupla original permanece: (10, 20)

    Conjuntos (set)¶

    Os conjuntos em Python são coleções desordenadas e mutáveis de elementos únicos, ou seja, eles não permitem elementos duplicados. Essa característica os torna extremamente úteis para eliminar repetições em listas e para operações matemáticas como união, interseção e diferença.

    Os conjuntos são ideais quando precisamos garantir unicidade, realizar operações matemáticas entre coleções ou fazer verificações rápidas de pertencimento.

    Diferentemente de listas, conjuntos não garantem a ordem dos elementos e possuem um desempenho superior para verificações de pertencimento (in), pois são implementados internamente como tabelas de dispersão (hash tables), garantindo busca em tempo constante O(1) na média.

    Tipos booleanos e None¶

    None é um objeto especial em Python que representa a ausência de valor ou um valor nulo. É frequentemente usado como valor de retorno padrão para funções.

    Exemplos de valores booleanos e None
    tem_acesso = True
resultado = None

if tem_acesso:
    print("Acesso permitido")

if resultado is None:
    print("Nenhum resultado disponível")

    Em Python, a comparação com None deve ser feita utilizando is em vez de == porque None é um singleton, ou seja, existe apenas uma instância desse objeto em toda a execução do programa.

    O operador is verifica a identidade dos objetos, garantindo que a comparação seja feita diretamente com a única instância de None, enquanto == verifica apenas a equivalência de valores, o que pode ser alterado por classes personalizadas que redefinam o operador de igualdade. Dessa forma, ao usar resultado is None, asseguramos que estamos verificando corretamente se a variável realmente não possui um valor atribuído, evitando possíveis comportamentos inesperados caso resultado seja uma instância de uma classe que sobrecarregue o operador ==.

print(Direcao.NORTE.value)    # 10

# Iteração sobre todos os valores
for d in Direcao:
    print(f"{d.name}: {d.value}")

    from enum import Enum

class Planeta(Enum):
    MERCURIO = (3.303e+23, 2.4397e6)
    VENUS = (4.869e+24, 6.0518e6)
    TERRA = (5.976e+24, 6.37814e6)
    MARTE = (6.421e+23, 3.3972e6)

    def __init__(self, massa, raio):
        self.massa = massa  # kg
        self.raio = raio    # metros

    @property
    def gravidade_superficial(self):
        # F = G * m1 * m2 / r^2
        G = 6.67300E-11  # constante gravitacional
        return G * self.massa / (self.raio * self.raio)

# Uso
print(Planeta.TERRA.gravidade_superficial)  # Aproximadamente 9.8 m/s²

    Ponteiros¶

    Diferentemente de C, Python não tem ponteiros explícitos, e nem operadores de ponteiro como * e &. Todos os objetos em Python são acessados por referência, mas a linguagem gerencia automaticamente a memória e os ponteiros.

    # Em Python, atribuição de objetos mutáveis cria referências
lista1 = [1, 2, 3]
lista2 = lista1  # lista2 agora referencia o mesmo objeto que lista1

lista2.append(4)
print(lista1)  # [1, 2, 3, 4] - lista1 também foi modificada

# Para criar uma cópia independente
lista3 = lista1.copy()  # ou lista1[:]
lista3.append(5)
print(lista1)  # [1, 2, 3, 4] - lista1 não foi modificada
print(lista3)  # [1, 2, 3, 4, 5]

    Compreensão de lista¶

    A compreensão de lista (list comprehension) é uma forma concisa e eficiente de criar listas em Python. Ela permite gerar novas listas a partir de iteráveis, como range, listas existentes ou outras estruturas de dados, utilizando uma sintaxe compacta e legível.

    Essa abordagem substitui loops for tradicionais e chamadas de append(), tornando o código mais elegante e, muitas vezes, mais eficiente.

    A estrutura básica da compreensão de lista é: 

    [expressão for item in iterável]

    Por exemplo, para criar uma lista com os quadrados dos números de 0 a 4: 

    quadrados = [x**2 for x in range(5)]
print(quadrados)  # Saída: [0, 1, 4, 9, 16]

    Podemos adicionar uma condição usando if para filtrar elementos do iterável. 

    pares = [x for x in range(10) if x % 2 == 0]
print(pares)  # Saída: [0, 2, 4, 6, 8]

    Se quisermos modificar os valores com base em uma condição, podemos usar if else dentro da expressão. 

    classificacao = ["par" if x % 2 == 0 else "ímpar" for x in range(5)]
print(classificacao)  # Saída: ['par', 'ímpar', 'par', 'ímpar', 'par']

    Também podemos utilizar múltiplos laços for, permitindo criar listas a partir de combinações de elementos.

    Python
    1

    produtos_cartesianos = [(x, y) for x in range(3) for y in range(2)]

# Saída: [(0, 0), (0, 1), (1, 0), (1, 1), (2, 0), (2, 1)]

    Constantes¶

    Diferentemente de C, Python não tem um mecanismo embutido para declarar constantes que não possam ser alteradas. Por convenção, os programadores Python usam identificadores em LETRAS_MAIÚSCULAS para indicar que uma variável deve ser tratada como constante.
